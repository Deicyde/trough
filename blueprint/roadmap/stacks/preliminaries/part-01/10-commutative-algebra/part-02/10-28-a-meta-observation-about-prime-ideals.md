> For a commutative ring `R`, a principal ideal `J` and an ideal `I` with
> `I ≤ J`, the ideal `I` factors as the product of `J` with the colon ideal
> `(I : J)`.

```lean
theorem ideal_eq_mul_colon_of_isPrincipal {R : Type*} [CommRing R]
    (I J : Ideal R) (hJ : J.IsPrincipal) (hIJ : I ≤ J) :
    I = J * (I.colon J)
```

## Tag 05KB, an example

[Tag 05KB](https://stacks.math.columbia.edu/tag/05KB) in the Stacks Project.

**`Stacks.Algebra.OkaFamily.Ideal.oka_generators_and_isOka_fg`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/Algebra/OkaFamily.lean, line 84](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/Algebra/OkaFamily.lean#L84).

> **Stacks Tag 05KB.** Let `R` be a ring, `I ⊆ R` an ideal and `a ∈ R`. If `(I : a)` is
> generated by `a₁, …, aₙ` and `(I, a)` is generated by `a, b₁, …, bₘ` with `b₁, …, bₘ ∈ I`, then
> `I` is generated by `aa₁, …, aaₙ, b₁, …, bₘ`; and the family of finitely generated ideals is an
> Oka family. The second part is Mathlib's `Ideal.isOka_fg`.

```lean
theorem Ideal.oka_generators_and_isOka_fg (R : Type*) [CommRing R] :
    (∀ (I : Ideal R) (a : R) (n m : ℕ) (α : Fin n → R) (β : Fin m → R),
      I.colon (Ideal.span {a}) = Ideal.span (Set.range α) →
      I ⊔ Ideal.span {a} = Ideal.span (insert a (Set.range β)) → (∀ j, β j ∈ I) →
      I = Ideal.span (Set.range (fun i => a * α i) ∪ Set.range β)) ∧
    _root_.Ideal.IsOka (Submodule.FG (R := R) (M := R))
```

> ideal of `R` contains a nonzerodivisor, then `R` is a domain.
