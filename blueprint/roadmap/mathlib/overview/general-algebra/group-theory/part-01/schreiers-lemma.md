# Schreier's lemma

**Schreier's Lemma**: If `R : Set G` and `H : Subgroup G` are complements with `1 ∈ R`, and if
`G` is generated by `S : Set G`, then `H` is generated by the `Set`
  `(R * S).image (fun g ↦ g * (hR.toRightFun g)⁻¹)`.

```lean
Subgroup.closure_mul_image_eq.{u_1} {G : Type u_1} [Group G] {H : Subgroup G} {R S : Set G}
  (hR : Subgroup.IsComplement (↑H) R) (hR1 : 1 ∈ R) (hS : Subgroup.closure S = ⊤) :
  Subgroup.closure ((fun g => g * (↑(hR.toRightFun g))⁻¹) '' (R * S)) = H
```
