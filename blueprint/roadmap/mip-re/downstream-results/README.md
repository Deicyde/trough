# Downstream results

Potential extensions of the project once the main theorem is in place. They are listed roughly in order of increasing formalization cost. The first two stay within finite-dimensional linear algebra plus elementary functional analysis, while the operator-algebraic consequences require von Neumann algebra infrastructure that largely does not yet exist in Mathlib and would constitute a major sub-project of independent value.

## Uncomputability of the value

Corollary [Uncomputability of the game value](../the-main-theorem/cor-value-uncomputable.md) is already a headline consequence under the main theorem's compression premise: no algorithm can approximate the (synchronous or quantum) value of a nonlocal game to within an additive constant $c < \frac14$, since an estimate of additive error $c$ separates value $1$ from value $\frac12$ exactly when $c < \frac14$ (at $c = \frac14$ the estimate $\frac34$ is consistent with both). The threshold rises to the trivial $\frac12$ once the gap is amplified: repeating the game drives the soundness value below any $\delta > 0$ while preserving value $1$ (Theorem [Direct parallel repetition for entangled strategies](../parallel-repetition/thm-direct-repetition-q.md)), at a cost polynomial in the description, so for every $c < \frac12$ no algorithm approximates the value to within additive error $c$. That stronger form depends on the repetition theorem as well as on the main theorem.

## Upper semidecision through a Positivstellensatz

The Lean proof of Lemma [Upper semidecision of the commuting-operator value](part-01/lem-valco-upper-re.md) does not go through the NPA levels. It works with one object: the quadratic module of the measurement relations in the free $*$-algebra, with POVM generators. Its Archimedean property and a Riesz extension give a noncommutative Positivstellensatz (Theorem [Positivstellensatz for the commuting-operator value](part-01/thm-nc-positivstellensatz.md); compare (HM04)), which turns ${\omega^{\mathrm{co}}}(\mathfrak{G}) < r$ into the existence of an exact sum-of-squares certificate with Gaussian-integer coefficients (Lemma [Exact sum-of-squares certificates](part-01/lem-sos-certificates.md)). The same states and the same GNS construction give compactness of $C_{qc}$ (Lemma [$C_{qc}$ is compact](part-01/lem-cqc-compact.md)). No real-closed-field decision, no dilation to projections, and no semidefinite hierarchy is involved.
