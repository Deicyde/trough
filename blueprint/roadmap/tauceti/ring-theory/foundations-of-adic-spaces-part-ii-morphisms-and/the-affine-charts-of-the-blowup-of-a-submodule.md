# The affine charts of the blowup of a submodule

For a nonempty finite subset `S ⊆ F` with
product `t`, the standard open `D₊(t T^{#S})` of `Proj R(J)` is isomorphic to `Spec C[F/S]`, the
spectrum of the `C`-subalgebra of `B_t` generated by the fractions `f/f'` with `f ∈ F` and
`f' ∈ S`. It is Mathlib's `Proj.basicOpenIsoSpec` followed by the spectrum of
`awayEquivFractionSubalgebra`.

```lean
TauCeti.AlgebraicGeometry.submoduleBlowup.basicOpenIsoSpec.{u} (C : Type u) {B : Type u}
  [CommRing C] [CommRing B] [Algebra C B] {F : Set B} {S : Finset B} (L : Type u) [CommRing L]
  [Algebra C L] [Algebra B L] [IsScalarTower C B L] [IsLocalization.Away (∏ g ∈ S, g) L]
  (hS : ↑S ⊆ F) (hS₀ : S.Nonempty) :
  ↑(AlgebraicGeometry.Proj.basicOpen (TauCeti.AlgebraicGeometry.submoduleBlowup.gradedRing C F)
        (TauCeti.AlgebraicGeometry.submoduleBlowup.monomialProd C hS)) ≅
    AlgebraicGeometry.Spec ↧↥(TauCeti.AlgebraicGeometry.submoduleBlowup.fractionSubalgebra C F S L)
```
