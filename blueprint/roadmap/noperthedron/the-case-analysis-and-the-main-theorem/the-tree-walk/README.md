# The tree walk

- [kcheck](def-kcheck.md)

Splitting halves one radius $h_i$; if $h_i$ is odd, the scale $K$ is first increased by one and all centres and radii are doubled, so that box coordinates stay integers. The halves again satisfy the bounds of Definition [box](../../boxes-and-leaf-certificates/boxes/def-box.md), and so do the root boxes.
