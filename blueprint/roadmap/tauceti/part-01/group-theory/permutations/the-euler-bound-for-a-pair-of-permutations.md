# The Euler bound for a pair of permutations

For permutations `σ` and `τ` of a finite type,
the orbits of `σ`, of `τ` and of `τ * σ` together number at most the number of points plus twice
the number of orbits of the group generated by `σ` and `τ`. For the rotation and edge involution
of a ribbon graph these count vertices, edges and faces, and this is the bound `χ ≤ 2` on each
connected component; equality holds exactly when every component is a sphere.

```lean
Equiv.Perm.orbitCount_add_orbitCount_add_orbitCount_mul_le.{u_1} {α : Type u_1} [Finite α]
  (σ τ : Equiv.Perm α) :
  TauCeti.orbitCount σ + TauCeti.orbitCount τ + TauCeti.orbitCount (τ * σ) ≤
    Nat.card α + 2 * Nat.card (MulAction.orbitRel.Quotient (↥(Subgroup.closure {σ, τ})) α)
```
