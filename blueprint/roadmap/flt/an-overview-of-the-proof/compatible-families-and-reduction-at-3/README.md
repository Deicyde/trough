# Compatible families, and reduction at 3

We now use Khare–Wintenberger to lift $\rho$ to a potentially modular $\ell$-adic Galois representation of conductor 2, and put it into an $\ell$-adic family using the Brauer's theorem trick in (blggt). Finally we look at the 3-adic specialisation of this family. Reducing mod 3 we get a representation which is flat at 3 and tame at 2, so must be reducible because of the techniques introduced in Fontaine's paper on abelian varieties over $\mathbb{Z}$ (an irreducible representation would cut out a number field whose discriminant violates the Odlyzko bounds). One can now go on to deduce that the 3-adic representation must be reducible, which contradicts the irreducibility of $\rho$.
