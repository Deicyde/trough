## Linear code

Let $F$ be a field and $\iota$ an index set, not necessarily finite.
A linear code over $F$ with coordinates indexed by $\iota$ is an $F$-linear subspace of the
space of words, the functions $\iota \to F$.

Formalized by `Cslib.CodingTheory.LinearCode`, an abbreviation declared in [CSLibExt/Coding/LinearCode.lean, line 61](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L61). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#linear-code).

## Encoder of a generator matrix

Let $G$ be a $\kappa \times \iota$ matrix over a field $F$,
with $\kappa$ finite. The encoder of $G$ sends a message $m \in F^\kappa$ to the word
$mG \in F^\iota$ given by $(mG)_j = \sum_{k \in \kappa} m_k G_{kj}$, the combination of the rows
of $G$ with coefficients $m$.

Formalized by `Cslib.CodingTheory.LinearCode.encode`, a definition declared in [CSLibExt/Coding/LinearCode.lean, line 75](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L75). ## Code generated by a matrix

Let $F$ be a field, $\kappa$ a finite index set, $\iota$ any
index set and $G$ a $\kappa \times \iota$ matrix over $F$. The code generated by $G$ is the linear
code of all words $m G$ with $m : \kappa \to F$, the image of the encoder $m \mapsto m G$;
equivalently, the span of the rows of $G$.

## Syndrome

Let $F$ be a field, $\iota$ a finite set and $\rho$ a set. For a matrix
$H \in F^{\rho \times \iota}$ (a parity-check matrix) and a word $y \in F^\iota$, the syndrome of
$y$ is the vector $Hy \in F^\rho$.

## Code with a given parity-check matrix

Let $F$ be a field, $\iota$ a finite index set,
$\rho$ any index set and $H$ a $\rho \times \iota$ matrix over $F$. The code with parity-check
matrix $H$ is the linear code of all words $c : \iota \to F$ whose syndrome $H c$ is zero, that
is, the kernel of $c \mapsto H c$.

## The syndrome depends only on the error

Let $F$ be a field, $\iota$ a finite set and
$H$ a parity-check matrix over $F$ with columns indexed by $\iota$. If $c \in F^\iota$ is a
codeword of the code with parity-check matrix $H$ and $e \in F^\iota$ is any word, then the
received word $c + e$ has the same syndrome as $e$, that is, $H(c + e) = He$.

Formalized by `Cslib.CodingTheory.LinearCode.syndrome_add_of_mem`, a theorem declared in [CSLibExt/Coding/LinearCode.lean, line 108](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L108). ## Generator/parity-check duality

Let $F$ be a field, $\kappa$ and $\iota$ finite index
sets and $\rho$ any index set, and let $G$ be a $\kappa \times \iota$ matrix and $H$ a
$\rho \times \iota$ matrix over $F$. The code generated by $G$ equals the code with parity-check
matrix $H$ if and only if $G H^{\mathsf{T}} = 0$ and $\operatorname{rank} G + \operatorname{rank} H$
equals $|\iota|$, the length of the code.

Formalized by `Cslib.CodingTheory.LinearCode.ofGenerator_eq_ofParityCheck_iff`, a theorem declared in [CSLibExt/Coding/LinearCode.lean, line 150](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L150). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#of-generator-eq-of-parity-check-iff).

## The systematic encoder copies the message

Let $F$ be a field, $\kappa$ a finite set and
$A$ a $\kappa \times \rho$ matrix over $F$. For the systematic generator matrix $G = [I \mid A]$,
whose columns are indexed by the disjoint union $\kappa \sqcup \rho$, the encoding $mG$ of every
message $m \in F^\kappa$ agrees with $m$ on the coordinates in $\kappa$: $(mG)_i = m_i$ for every
$i \in \kappa$.

Formalized by `Cslib.CodingTheory.LinearCode.encode_fromCols_one_inl`, a theorem declared in [CSLibExt/Coding/LinearCode.lean, line 169](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L169). ## Systematic generator and parity-check matrices

Let $F$ be a field, $\kappa$ and $\rho$
finite sets, and $A$ a $\kappa \times \rho$ matrix over $F$. Then the code generated by
$G = [I_\kappa \mid A]$ equals the code with parity-check matrix
$H = [-A^{\mathsf{T}} \mid I_\rho]$, both being codes whose coordinates are indexed by the
disjoint union of $\kappa$ and $\rho$.

## Dot product bilinear form

Let $F$ be a field and $\iota$ a finite set. The dot product
form is the bilinear form on $F^\iota$ that sends a pair of words $(x, y)$ to
$x \cdot y = \sum_{i \in \iota} x_i y_i$.

## Dual code

Let $F$ be a field and $\iota$ a finite set. The dual $C^\perp$ of a linear code
$C \subseteq F^\iota$ is the linear code of all words $x \in F^\iota$ with
$x \cdot c = \sum_{i \in \iota} x_i c_i = 0$ for every codeword $c \in C$.

Formalized by `Cslib.CodingTheory.LinearCode.dual`, a definition declared in [CSLibExt/Coding/LinearCode.lean, line 233](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L233). ## Dimension of the dual code

Let $F$ be a field and $\iota$ a finite set. For every linear
code $C \subseteq F^\iota$, $\dim C + \dim C^\perp = |\iota|$, where $C^\perp$ is the dual code.

## Minimum distance

The minimum distance of a linear code $C$ of finite length is the least
Hamming distance (number of coordinates where they differ) between two distinct codewords of
$C$, taken in $\mathbb{N} \cup \{\infty\}$; it is $\infty$ if $C$ has at most one codeword.

Formalized by `Cslib.CodingTheory.LinearCode.minDist`, a definition declared in [CSLibExt/Coding/LinearCode.lean, line 282](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L282). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#min-dist).

## Minimum weight

The minimum weight of a linear code $C$ of finite length is the least
weight of a nonzero codeword of $C$, where the weight of a word is its number of nonzero
coordinates; it is taken in $\mathbb{N} \cup \{\infty\}$ and is $\infty$ if $C$ has no nonzero
codeword.

Formalized by `Cslib.CodingTheory.LinearCode.minWeight`, a definition declared in [CSLibExt/Coding/LinearCode.lean, line 286](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L286). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#min-weight).

## Hamming distance is the weight of the difference

Let $F$ be a field and $\iota$ a finite
set. For all words $x, y \in F^\iota$, the Hamming distance between $x$ and $y$ (the number of
coordinates where they differ) equals the Hamming weight of $x - y$ (its number of nonzero
coordinates).

Formalized by `Cslib.CodingTheory.hammingDist_eq_hammingNorm_sub`, a theorem declared in [CSLibExt/Coding/LinearCode.lean, line 290](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L290). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#hamming-dist-eq-hamming-norm-sub).

## Minimum distance equals minimum weight

## Syndrome decoding

**Syndrome decoding** with a lookup `table` from syndromes to error patterns: subtract the
error pattern the table assigns to the syndrome of the received word.

Formalized by `Cslib.CodingTheory.LinearCode.syndromeDecode`, a definition declared in [CSLibExt/Coding/LinearCode.lean, line 341](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L341). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#syndrome-decode).

## Syndrome table correct up to a radius

Let $H$ be a $\rho \times \iota$ matrix over a field
$F$, with $\iota$ finite, and let $t$ be a natural number. A syndrome table for $H$, that is, a map
$T$ from syndromes $s \in F^\rho$ to error patterns $T(s) \in F^\iota$, is correct up to radius
$t$ when, for every word $e \in F^\iota$ of Hamming weight at most $t$, the word $T(He)$ has the
same syndrome as $e$, that is $H \, T(He) = He$, and has Hamming weight at most $t$.

This is weaker than asking for minimum-weight coset leaders, and equivalent to it inside the
radius when $2t < d$, where $d$ is the minimum distance of the code with parity-check matrix $H$
(each coset then holds at most one word of weight at most $t$). Outside the radius the table is
unconstrained, so for heavier errors the decoder's output need not even be a codeword.

Formalized by `Cslib.CodingTheory.LinearCode.IsSyndromeTable`, a definition declared in [CSLibExt/Coding/LinearCode.lean, line 349](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L349). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#is-syndrome-table).

## Syndrome decoding corrects every error of weight at most $t$

Let $H$ be a parity-check
matrix over a field $F$, let $C$ be the code with parity-check matrix $H$, let
$d \in \mathbb{N} \cup \{\infty\}$ be its minimum distance, and let $t \in \mathbb{N}$ with
$2t < d$. If a syndrome table is correct up to radius $t$ for $H$, then for every codeword
$c \in C$ and every word $e$ of Hamming weight at most $t$, syndrome decoding with this table
sends the received word $c + e$ to $c$.

The error pattern the table returns differs from the true error by a codeword of weight at most
$2t$, which must be zero.

Formalized by `Cslib.CodingTheory.LinearCode.syndromeDecode_add_of_hammingNorm_le`, a theorem declared in [CSLibExt/Coding/LinearCode.lean, line 356](https://github.com/Deicyde/atlas-lean/blob/a3690dd2ad41e1ad4d871b062779ed7b0452800d/CSLibExt/Coding/LinearCode.lean#L356). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/InformationTheory/error-correcting-codes/linear-codes/index.html#syndrome-decode-add-of-hamming-norm-le).

## Syndrome decoding up to half the minimum distance

Let $H$ be a parity-check matrix over
a field $F$ such that the code $C$ with parity-check matrix $H$ has finite minimum distance $d$,
and let $t = \lfloor (d - 1)/2 \rfloor$. If a syndrome table is correct up to radius $t$ for
$H$, then for every codeword $c \in C$ and every word $e$ of Hamming weight at most $t$,
syndrome decoding with this table sends the received word $c + e$ to $c$.

## Number of codewords of a linear code

If $C$ is a linear code of length $n$ over a finite
field $F$, then exactly $|F|^{\dim C}$ of the $|F|^n$ words of length $n$ lie in $C$, where
$\dim C$ is the dimension of $C$ over $F$.

## Singleton bound for linear codes, dimension form

Let $C$ be a linear code of length $n$
over a finite field $F$, and let $d \le n$ be a natural number that is at most the minimum
distance of $C$. Then $\dim C + d \le n + 1$.

The hypothesis $d \le n$ matters only for the zero code, whose minimum distance is $\infty$.

## Hamming bound for linear codes

Let $F$ be a finite field with $q$ elements and $C$ a
linear code of length $n$ and dimension $k$ over $F$. If $t$ is a natural number such that $2t$ is
less than the minimum distance of $C$, then

$$q^k \sum_{i=0}^{t} \binom{n}{i} (q-1)^i \le q^n.$$
