# Formal Frontier

[Formal Frontier](https://github.com/FormalFrontier) publishes Lean libraries written by AI agents (“Formal Frontier Agents”, as their formalization.yaml files name the authors), with a dashboard at https://formalfrontier.github.io. This chapter maps the 44 libraries in trough's catalog, each read at a pinned commit: a part per subject and a section per library. A library's page quotes its formalization.yaml (its description, scope, review and automation statements), links the Formal Frontier libraries it builds on and those that build on it, quotes the headline results of its README, and lists the main results its formalization.yaml declares.

There are 267 articles: one for each highlight in a library's formalization.yaml (62), and one for each headline result in its README whose declaration link names a declaration that the linked file declares at the pinned commit (205). Of the 948 headline results, 520 link no declaration, 208 link one the linked file is not found to declare, and 15 link one that already has an article, which the library's page links in their place. The first two kinds have no article and stay as quoted text on the library's page. 17 libraries have no articles. The main results are listed on the library's page, not made articles: in several libraries they are close to the whole API.

No Lean is run for this chapter. Whether a file declares a name is read from its source text, following `namespace`, `section` and `end`; a name counts only when a declaration command in that file names it in full under the right namespace, so a name given relative to an open namespace, or one Lean generates (an additive version, a constructor), is left out rather than guessed. Articles have no dependencies: edges between declarations need Lean. A declaration whose text in the file contains `sorry` is marked as stated without proof; a dependency on an unproved declaration elsewhere is not checked.

The quoted text is the libraries', under their Apache-2.0 license, with the repository and commit named where it is quoted.
