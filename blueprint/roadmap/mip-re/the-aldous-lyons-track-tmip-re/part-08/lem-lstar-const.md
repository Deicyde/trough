# The output indicator at constant parameters

Let $p = (\ell, \Delta)$ be fixed. The output indicator reading its parameters from the constant function $p$ has a program computed in polynomial time from the input verifier's calculator and processor and $p$, of size $c_0 + 4|L| + |P| + |p|$ for a constant $c_0$; and there is a constant $E$ such that if the calculator and processor run within $T (|d| + 1)^k$ with $T \leq 2^\tau$, and the input and $p$ have size below $2^\rho$, it accepts what it accepts within $2^{E(k + 1)(\tau + \rho + 1)}$ steps.

## Depends on

- [The output indicator as a program; eq:time_bound_L\*](../part-05/lem-ar-indicator-program.md)

## Proof

The parameters enter the check in one place, so its time bound is a fixed polynomial evaluated at the input size plus $|p|$, and every fixed polynomial is at most $(x + 2)^D$.
