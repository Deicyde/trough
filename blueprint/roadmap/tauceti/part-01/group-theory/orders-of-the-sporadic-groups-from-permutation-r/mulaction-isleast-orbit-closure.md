# MulAction.isLeast_orbit_closure

The orbit of `b` under the subgroup generated by `S` is the least set that contains `b` and is
mapped into itself by every element of `S` and by its inverse.

```lean
MulAction.isLeast_orbit_closure.{u_1, u_2} {G : Type u_1} {α : Type u_2} [Group G] [MulAction G α]
  (S : Set G) (b : α) :
  IsLeast {T | b ∈ T ∧ (∀ g ∈ S, ∀ x ∈ T, g • x ∈ T) ∧ ∀ g ∈ S, ∀ x ∈ T, g⁻¹ • x ∈ T}
    (MulAction.orbit (↥(Subgroup.closure S)) b)
```
