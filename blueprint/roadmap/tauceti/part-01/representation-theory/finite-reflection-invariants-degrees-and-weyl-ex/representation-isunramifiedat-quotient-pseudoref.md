# Representation.isUnramifiedAt_quotient_pseudoreflectionSubgroup_of_height_eq_one

The residual quotient by the pseudoreflection subgroup is unramified at every height-one
prime. The base is the full invariant algebra `Sym(V*)^G`, and the source is `Sym(V*)^H`, where
`H` is generated by the pseudoreflections. No polynomial presentation or characteristic-zero
assumption is required.

```lean
Representation.isUnramifiedAt_quotient_pseudoreflectionSubgroup_of_height_eq_one.{u_1, u_2, u_3}
  {K : Type u_1} {G : Type u_2} {V : Type u_3} [Field K] [Infinite K] [Group G] [Finite G]
  [AddCommGroup V] [_root_.Module K V] (ρ : Representation K G V) (hρ : Function.Injective ⇑ρ) :
  let A := FixedPoints.subalgebra K (SymmetricAlgebra K (Module.Dual K V)) G;
  let this := A.toCommRing;
  let B :=
    FixedPoints.subalgebra (↥A) (SymmetricAlgebra K (Module.Dual K V)) ↥ρ.pseudoreflectionSubgroup;
  let this_1 := B.toCommRing;
  ∀ (P : Ideal ↥B) [inst : P.IsPrime], P.height = 1 → Algebra.IsUnramifiedAt (↥A) P
```
