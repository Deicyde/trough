# Additive content

Let $E$ be a commutative monoid and $\mathcal{A}$ be a family of sets. An *additive content* is a set function $\lambda : \mathcal{A} \to E$ with value $0$ at the empty set which is finitely additive on $\mathcal{A}$ .
