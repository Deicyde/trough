# Non-Sperner Intervals and Exact Deficiency Family in the Permutation Pattern Poset

> Refutes Question 9.5 of McNamara and Steingrímsson (J. Combin. Theory Ser. A 134, 2015, 1–35), which asked whether every interval in the classical permutation pattern poset is Sperner, and constructs an infinite family of principal downsets with unbounded exact additive Sperner deficiency. Proves unconditionally in Lean 4 + Mathlib (standard axioms only, no native_decide): (1) the explicit 19-element closed interval [213, 2574613] has rank sizes 1, 3, 7, 7, 1 (largest rank size 7) and width 8 (via an explicit 8-element antichain and an explicit 8-chain cover), so it is not Sperner; and (2) for every integer k ≥ 1, the two-leader permutation τ_k of length 6k + 4 has principal downset [∅, τ_k] with largest rank size 3k² + 8k + 5 and width 3k² + 9k + 5, via a complete classification of Downset (τ_k) and an explicit 3D box symmetric chain decomposition, giving exact Sperner deficiency k. Exhaustive minimality among intervals with top element of length ≤ 8 is left outside the formalization.
