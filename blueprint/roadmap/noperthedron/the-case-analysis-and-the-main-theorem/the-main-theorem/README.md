# The main theorem

- [Soundness](thm-kernel-sound.md)

The certificate has $245{,}484$ leaves. It is generated by a floating-point search (`cayley/search`) and cut into $28{,}082$ chunks of at most 16 leaves. For each chunk, the statement that the checker accepts it is proved by `Eq.refl true`, so the Lean kernel evaluates the checker on that chunk. The kernel-checked theorems live in `CayleyKernel/Main.lean`; they are not part of the default build, since they need the generated data.
