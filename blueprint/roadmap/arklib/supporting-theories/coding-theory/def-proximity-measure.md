# Proximity Measure

For words $u,v$, a code $\mathcal{C}$ and $d\in\mathbb{N}$, the proximity measure is the number of $r\in\mathbb{F}$ with $\Delta(r u+(1-r)v,\mathcal{C})\le d$.
