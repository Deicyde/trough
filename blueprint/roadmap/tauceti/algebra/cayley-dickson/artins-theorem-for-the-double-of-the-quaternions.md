# Artin's theorem for the double of the quaternions

the subalgebra generated by two elements
`x` and `y` is associative.

```lean
TauCeti.CayleyDickson.mul_assoc_of_mem_adjoin.{u_1} {R : Type u_1} [CommRing R]
  {x y a b c : TauCeti.CayleyDickson (Quaternion R)} (ha : a ∈ NonUnitalAlgebra.adjoin R {1, x, y})
  (hb : b ∈ NonUnitalAlgebra.adjoin R {1, x, y}) (hc : c ∈ NonUnitalAlgebra.adjoin R {1, x, y}) :
  a * b * c = a * (b * c)
```
