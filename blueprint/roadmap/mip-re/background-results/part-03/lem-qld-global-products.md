# Ordered products with global outcome multipliers

Let $(G_A, G_B)$ be the global measurements of Lemma [A global padded polynomial PVM](lem-qld-global-pvm.md), with error $\delta$, in the padded model, whose state is $\Phi$. For an outcome $g$ put $v_g = (G_{A,g} \otimes {I})\Phi$, and for a padded point $u = (x, z, \alpha, \beta, w)$ let $B_u(c)$ sum Bob's expanded ordered products $\widehat M^Z_b \widehat M^X_a$, carried to the padded model by the inert embedding of the register model, over $\alpha a + \beta b = c$. Then, on average over a uniform padded point, $\sum_g \mathbb E_u \|v_g - ({I} \otimes B_u(g(u))) v_g\|^2 \leq 2\delta + 2\kappa$, where $\kappa = 57676416\,\varepsilon$ is the commutator weight of Lemma [Combined $XZ$ point measurements](../part-02/lem-qld-combined-points.md). The estimate holds for every outcome, with the product order reversed ($\widehat M^X_a \widehat M^Z_b$), and with the parties exchanged ($G_B$ against Alice's ordered products, in the padded model with the players exchanged); retaining a subset of outcomes only decreases the left-hand side. These ordered products need not be POVMs. The Lean proves it for a `GlobalPair` in any model into which the register model embeds; the statement above is its tensor-product instance.

## Proof

Write $P_u(c) = \sum_{\alpha a + \beta b = c} \widehat M^Z_b \widehat M^X_a \widehat M^Z_b$ for the sandwich combination the consistency of Lemma [A global padded polynomial PVM](lem-qld-global-pvm.md) is stated against, and split ${I} - B_u(c) = ({I} - P_u(c)) + (P_u(c) - B_u(c))$. Since $0 \leq P_u(c) \leq {I}$, $({I} - P_u(c))^2 \leq {I} - P_u(c)$, so the first part is bounded by $\sum_g \mathbb E_u \langle G_{A,g} \otimes ({I} - P_u(g(u))) \rangle \leq \delta$. For the second, group the outcomes by their value $c = g(u)$ and drop the projector $\sum_{g(u) = c} G_{A,g} \leq {I}$: what remains is $\mathbb E_u \sum_c \|({I} \otimes (P_u(c) - B_u(c)))\Phi\|^2$, the squared norms of the fibre sums, along $(a, b) \mapsto \alpha a + \beta b$, of the deviations $D(a, b) = \widehat M^Z_b \widehat M^X_a \widehat M^Z_b - \widehat M^Z_b \widehat M^X_a$, which sum to zero over $(a, b)$. Parseval over $\mathbb{F}_q$ turns the average over $(\alpha, \beta)$ of the fibre sums into $(1 - 1/q) \sum_{a,b} \|({I} \otimes D(a, b))\Phi\|^2$, with no factor $q$, and each deviation is a contraction of a commutator: $D(a, b) = \widehat M^Z_b [\widehat M^X_a, \widehat M^Z_b]$ for this order and $-({I} - \widehat M^Z_b)[\widehat M^X_a, \widehat M^Z_b]$ for the other. The commutator weight is the one of Lemma [Combined $XZ$ point measurements](../part-02/lem-qld-combined-points.md), read in the padded model, where operators carried along the embedding have their expanded-state norms. Bob's version applies the same argument with the players exchanged.
