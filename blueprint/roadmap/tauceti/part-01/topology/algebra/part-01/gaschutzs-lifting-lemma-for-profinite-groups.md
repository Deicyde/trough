# Gaschütz's lifting lemma for profinite groups

Along a continuous surjection `f : G →* H`
from a profinite group onto a Hausdorff group, an `ι`-tuple that topologically generates `H` lifts
to an `ι`-tuple that topologically generates `G`, provided `G` is topologically generated by some
`ι`-tuple, with `ι` finite.

```lean
TauCeti.exists_comp_eq_and_topologicalClosure_closure_range_eq_top.{u_1, u_2, u_3} {G : Type u_1}
  [Group G] [TopologicalSpace G] [IsTopologicalGroup G] [CompactSpace G]
  [TotallyDisconnectedSpace G] {H : Type u_2} [Group H] [TopologicalSpace H] [IsTopologicalGroup H]
  [T2Space H] {ι : Type u_3} [Finite ι] {f : G →* H} (hf : Continuous ⇑f)
  (hsurj : Function.Surjective ⇑f) {g : ι → G}
  (hg : (Subgroup.closure (Set.range g)).topologicalClosure = ⊤) {h : ι → H}
  (hh : (Subgroup.closure (Set.range h)).topologicalClosure = ⊤) :
  ∃ g', ⇑f ∘ g' = h ∧ (Subgroup.closure (Set.range g')).topologicalClosure = ⊤
```
