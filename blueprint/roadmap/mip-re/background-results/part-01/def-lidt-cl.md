# Seeded CL low individual degree test

For admissible $q$, positive integers $m,d,\mathrm{ldc}$ and $m\mid q$, the *seeded CL test* is the paper's typed low-degree game with parameters $(q,m,d,\mathrm{ldc})$. Each ordered pair of types from $\{\mathtt{Point},\mathtt{ALine},\mathtt{DLine}\}$ has weight $1/9$, with question contents sampled from the corresponding CL distribution. Point questions ask for an element of $\mathbb{F}_q^{\mathrm{ldc}}$. Axis-line questions retain a seed-labelled description $(u_0,s)$ and ask for $\mathrm{ldc}$ degree-$d$ polynomials; diagonal-line questions retain $(u_0,s,v)$ and ask for $\mathrm{ldc}$ degree-$md$ polynomials. The seed selects the direction class, with leading coordinates of the diagonal direction set to zero. The verifier checks the answer format, equality on identical same-type questions, and evaluation agreement for either line type against a point; the other type pairs impose no further check. In particular, different seed descriptions of the same geometric line remain different questions.
