# The Frey curve

Recall that a *Frey package* $(a,b,c,p)$ is simply a prime $p\geq5$ and nonzero pairwise-coprime integers $a,b,c$ satisfying $a^p+b^p=c^p$ and satisfying the congruences $a\equiv3\pmod4$ and $b\equiv0\pmod2$. We have shown above that if Fermat's Last Theorem is false, then a Frey package exists.
