# The Ikeda--Nakayama annihilator criterion, for a left self-injective ring

if every `r`
with `r * a i = 0` for all `i` also satisfies `r * x = 0`, then `x` lies in the right ideal
generated by the `a i`.

```lean
TauCeti.exists_eq_sum_mul_of_forall_mul_eq_zero.{u, w} {R : Type u} [Ring R] {ι : Type w}
  [Fintype ι] {a : ι → R} {x : R} [Module.Injective R R]
  (h : ∀ (r : R), (∀ (i : ι), r * a i = 0) → r * x = 0) : ∃ c, x = ∑ i, a i * c i
```
