# Behrend's construction

Mathlib states this as `Behrend.roth_lower_bound`.

```lean
Behrend.roth_lower_bound {N : ℕ} : ↑N * Real.exp (-4 * √(Real.log ↑N)) ≤ ↑(rothNumberNat N)
```
