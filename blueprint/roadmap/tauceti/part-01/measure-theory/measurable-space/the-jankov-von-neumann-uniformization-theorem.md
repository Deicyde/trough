# The Jankov–von Neumann uniformization theorem

An analytic relation `R ⊆ X × Y`, with `X`
a T₁ space, has a uniformization `f : X → Y` which is measurable for the σ-algebra generated by the
analytic subsets of `X`: `(x, f x) ∈ R` for every `x` in the projection of `R`.

By `TauCeti.MeasureTheory.nullMeasurable_of_measurable_generateFrom_analyticSet`, such an `f` is
null-measurable for every s-finite measure on a metrizable `X`; see
`MeasureTheory.AnalyticSet.exists_measurable_ae_uniformization`.

```lean
MeasureTheory.AnalyticSet.exists_measurable_uniformization.{u_1, u_2} {X : Type u_1} {Y : Type u_2}
  [TopologicalSpace X] [TopologicalSpace Y] [T1Space X] [MeasurableSpace Y] [BorelSpace Y]
  [Nonempty Y] {R : Set (X × Y)} (hR : MeasureTheory.AnalyticSet R) :
  ∃ f, Measurable f ∧ ∀ x ∈ Prod.fst '' R, (x, f x) ∈ R
```
