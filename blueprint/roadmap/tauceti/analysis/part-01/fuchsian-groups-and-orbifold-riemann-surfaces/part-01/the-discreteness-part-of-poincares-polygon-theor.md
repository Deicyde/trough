# The discreteness part of Poincaré's polygon theorem

If a side-paired polygon satisfies
the angle condition at every finite vertex cycle and has parabolic cycle transformations at its
ideal vertices, then the group generated by its side-pairing maps is a cofinite Fuchsian group:
it is discrete and has finite covolume.

```lean
TauCeti.UpperHalfPlane.ConvexPolygon.SidePairing.isCofinite_of_isParabolic {n : ℕ} [NeZero n]
  {P : TauCeti.UpperHalfPlane.ConvexPolygon n} (σ : P.SidePairing)
  (hcyc :
    ∀ (j : Fin n) (z : UpperHalfPlane),
      P.vertex j = Sum.inl z → ↑(orderOf (σ.cycleMap j)) * σ.cycleAngleSum j = 2 * Real.pi)
  (hpar : ∀ (j : Fin n) (ξ : OnePoint ℝ), P.vertex j = Sum.inr ξ → (σ.cycleMap j).IsParabolic) :
  (Subgroup.closure (Set.range σ.map)).IsCofinite
```
