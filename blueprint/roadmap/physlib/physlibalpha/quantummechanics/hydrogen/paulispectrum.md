# Pauli's algebraic derivation of the hydrogen spectrum

The module `PhyslibAlpha.QuantumMechanics.Hydrogen.PauliSpectrum`, [PhyslibAlpha/QuantumMechanics/Hydrogen/PauliSpectrum.lean](https://github.com/leanprover-community/physlib/blob/2a1dfe43134b49b643642f13d33031754021bb5d/PhyslibAlpha/QuantumMechanics/Hydrogen/PauliSpectrum.lean): 24 declarations, 24 with a docstring, 1 listed as significant.

## i. Overview

> Pauli (1926) obtained the bound-state energies of the hydrogen atom from the commutation
> relations of the angular momentum `L`, the Laplace-Runge-Lenz vector `A` and the Hamiltonian
> `H` alone. On an eigenspace of `H` with eigenvalue `E < 0` the rescaled vector
> `K = A / √(-2mE)` makes `J = (L + K) / 2` a copy of `su(2)` (and likewise `(L - K) / 2`).
> By `L · A = 0` and the relation for `A²`, its Casimir is the scalar
> `J² = -(ℏ² + m k² / (2E)) / 4`. Comparing with the Casimir `ℏ² j(j+1)` of `su(2)` gives
> `E = -m k² / (2 ℏ² n²)` with `n = 2j + 1`. The two copies `J₊ = (L + K) / 2` and
> `J₋ = (L - K) / 2` commute and have the same Casimir, so a common highest-weight vector
> generates `n²` linearly independent states: the eigenspace has dimension at least `n²`.
>
> This file formulates the argument abstractly, independently of any functional analysis: the
> operators live on an arbitrary complex vector space and are only required to satisfy the
> relations of `Physlib/QuantumMechanics/Hydrogen/LaplaceRungeLenzVector.lean` at `ε → 0`,
> in dimension `d = 3` (with `Lᵢ = ½ εᵢⱼₖ Lⱼₖ`).

## ii. Key results

> - `PauliSystem` : operators `L`, `A`, `H` with the hydrogen commutation relations.
> - `PauliSystem.exists_energyLevel` : every nonzero finite-dimensional eigenspace of `H` with
>   eigenvalue `E < 0` has `E` equal to a Bohr level.
> - `PauliSystem.exists_energyLevel_le_finrank` : such an eigenspace, at the Bohr level with
>   principal quantum number `n`, has dimension at least `n²`.

```lean
  /-- The angular momentum components `Lᵢ`. -/
  L : Fin 3 → Module.End ℂ V
  /-- The Laplace-Runge-Lenz components `Aᵢ`. -/
  A : Fin 3 → Module.End ℂ V
  /-- The Hamiltonian. -/
  H : Module.End ℂ V
  /-- `[Lᵢ, Lᵢ₊₁] = iℏ Lᵢ₊₂`. -/

  /-- `[Lᵢ, Aᵢ] = 0`. -/
  comm_L_A_self : ∀ i, ⁅L i, A i⁆ = 0
  /-- `[Lᵢ, Aᵢ₊₁] = iℏ Aᵢ₊₂`. -/
  comm_L_A_succ : ∀ i, ⁅L i, A (i + 1)⁆ = (Complex.I * (ℏ : ℝ)) • A (i + 2)
  /-- `[Lᵢ₊₁, Aᵢ] = -iℏ Aᵢ₊₂`. -/
  comm_L_A_pred : ∀ i, ⁅L (i + 1), A i⁆ = -((Complex.I * (ℏ : ℝ)) • A (i + 2))
  /-- `[Aᵢ, Aᵢ₊₁] = -2iℏm H Lᵢ₊₂`. -/
  comm_A_A : ∀ i, ⁅A i, A (i + 1)⁆ = (-2 * Complex.I * (ℏ : ℝ) * Hy.m) • (H * L (i + 2))
  /-- `[H, Lᵢ] = 0`. -/
  comm_H_L : ∀ i, ⁅H, L i⁆ = 0
  /-- `[H, Aᵢ] = 0`. -/
  comm_H_A : ∀ i, ⁅H, A i⁆ = 0
  /-- `A² = 2mH(L² + ℏ²) + m²k²`. -/
  A_sq : ∑ i, A i * A i =
    (2 * Hy.m : ℂ) • (H * (∑ i, L i * L i + ((ℏ : ℝ) ^ 2 : ℂ) • 1)) +
      ((Hy.m : ℂ) ^ 2 * (Hy.k : ℂ) ^ 2) • 1
  /-- `L · A = 0`. -/
  L_dot_A : ∑ i, L i * A i = 0
```

## B. The `su(2)` generated by `L` and `K`

> On a space where `H = E` with `E < 0`, let `κ² = -2mE`, `Kᵢ = Aᵢ / κ` and
> `Jᵢ = (Lᵢ + Kᵢ) / (2ℏ)`. The `Jᵢ` satisfy the angular momentum relations (without `ℏ`), and
> `J² = (-ℏ² - m k² / (2E)) / (4ℏ²)` is a scalar by `L · A = 0` and the relation for `A²`.
> The two square roots `±√(-2mE)` give `J₊ = (L + K) / (2ℏ)` and `J₋ = (L - K) / (2ℏ)`.

## D. The degeneracy

> A common primitive vector of `J₊` and `J₋` has the same highest weight `n` for both, since
> `J₊² = J₋²`, and its lowering grid gives `(n + 1)²` linearly independent vectors.
