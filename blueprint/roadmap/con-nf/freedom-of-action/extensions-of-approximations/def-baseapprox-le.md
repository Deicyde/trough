# BaseApprox.LE

We define a partial order on base approximations by setting $\psi \leq \chi$ when $\psi^{E{\mathcal A}} = \chi^{E{\mathcal A}}$ and $\psi^{\mathcal L} \leq \chi^{\mathcal L}$.
