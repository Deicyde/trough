For any $A>0$ sufficiently small, there is a constant $C>0$ so that
  whenever $1- A / \log^9 |t| \le \sigma < 1$ and $3 < |t|$, we have that:
  $$
  |\zeta(\sigma+it)| \ge C \log^7 |t|.
  $$
\end{lemma}
