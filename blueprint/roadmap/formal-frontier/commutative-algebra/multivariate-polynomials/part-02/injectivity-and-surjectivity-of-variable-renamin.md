# Injectivity and surjectivity of variable renaming

For any commutative
semiring `R` and any map `f : σ → τ`, with the coefficient, source-variable
and target-variable types in independent universes, the canonical renaming
map from the full polynomial semiring `MvPolynomial σ R` to the full
polynomial semiring `MvPolynomial τ R` is injective exactly when `f` is
injective or `R` is subsingleton
([`MvPolynomial.injective_rename_iff`](https://github.com/FormalFrontier/multivariate-polynomials/blob/724d9804aa6e853d9fe34f6a35c5c0d35c7f8c6a/MultivariatePolynomials/Rename.lean)),
and is surjective exactly when `f` is surjective or `R` is subsingleton
([`MvPolynomial.surjective_rename_iff`](https://github.com/FormalFrontier/multivariate-polynomials/blob/724d9804aa6e853d9fe34f6a35c5c0d35c7f8c6a/MultivariatePolynomials/Rename.lean)).
