# Doob-Meyer Theorem

This chapter starts with the derivation of a Komlòs lemma, which is a useful tool to extract converging subsequences from bounded sequences of functions. Then, we give a short review of the properties of the Doob decomposition of an adapted process indexed on a discrete set, and then follows ([Beiglböck et al. 2012](https://doi.org/10.1016/j.spa.2011.12.001)) which gives an elementary and short proof of the Doob-Meyer theorem.
