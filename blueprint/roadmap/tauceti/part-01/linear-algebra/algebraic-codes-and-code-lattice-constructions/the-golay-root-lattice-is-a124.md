# The Golay root lattice is `A₁²⁴`

The zero-code lattice generated by all Golay roots
is isometric to the orthogonal sum of twenty-four copies of the existing `A₁` lattice.
The ambient isometry doubles every coordinate.

```lean
TauCeti.BinaryGolay.rootLatticeIsometry :
  (TauCeti.IntegralLattice.a1.coordinatePower (Fin 24)).Isometry
    (TauCeti.ConstructionA.zeroLattice 2 (Fin 24))
```
