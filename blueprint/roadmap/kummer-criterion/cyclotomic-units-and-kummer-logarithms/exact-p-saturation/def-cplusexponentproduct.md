# CPlusExponentProduct

An *exponent product* is an expression

$$
(-1)^s\prod_{a=2}^{(p-1)/2}\varepsilon_a^{\,e_a}
$$

with integer exponents $s, e_a \in \mathbb{Z}$, packaged together with the element of $C^+$ it represents.
