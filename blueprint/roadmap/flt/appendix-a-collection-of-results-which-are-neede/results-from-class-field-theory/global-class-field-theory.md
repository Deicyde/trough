# global\_class\_field\_theory

If $N$ is a finite extension of $\mathbb{Q}$ then there are two “canonical” isomorphisms of topological groups between the profinite abelian groups $\pi_0(\mathbb{A}_N^\times/N^\times)$ and $\operatorname{Gal}(\overline{N}/N)^{\operatorname{ab}}$; one sends local uniformisers to arithmetic Frobenii and the other to geometric Frobenii; each of the global isomorphisms is compatible with the local isomorphisms above.
