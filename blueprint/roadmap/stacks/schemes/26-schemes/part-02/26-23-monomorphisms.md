**`AlgebraicGeometry.exists_iso_coproduct_spec_of_mono`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/AlgebraicGeometry/Scheme/Immersion/Monomorphism.lean, line 105](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/AlgebraicGeometry/Scheme/Immersion/Monomorphism.lean#L105).

> A monomorphism into a disjoint union of spectra of fields is, over that disjoint union, the
> inclusion of precisely a subset of its components.

```lean
public theorem exists_iso_coproduct_spec_of_mono {ι : Type v} [Small.{u} ι] (k : ι → Type u)
    [∀ i, Field (k i)] {Y : Scheme.{u}}
    (f : Y ⟶ ∐ fun i ↦ Spec (.of (k i))) [Mono f] :
    ∃ J : Set ι, ∃ e : Y ≅ ∐ fun j : J ↦ Spec (.of (k j.1)),
      e.hom ≫ Sigma.desc (fun j : J ↦ Sigma.ι (fun i ↦ Spec (.of (k i))) j.1) = f
```
