# Rational Minkowski–Weyl for cones

a cone is generated by finitely many lattice vectors
exactly when it is cut out by finitely many integral-character inequalities. No salience is
required.

```lean
TauCeti.Toric.IsIntegralLattice.isLatticeRational_iff_exists_dual_image.{u_1, u_2} {N : Type u_1}
  {V : Type u_2} [AddCommGroup N] [AddCommGroup V] [_root_.Module ℝ V] {i : N →+ V}
  {C : PointedCone ℝ V} (h : TauCeti.Toric.IsIntegralLattice i) :
  TauCeti.Toric.IsLatticeRational i C ↔
    ∃ s, C = PointedCone.dual LinearMap.id (⇑h.realCharacter '' ↑s)
```
