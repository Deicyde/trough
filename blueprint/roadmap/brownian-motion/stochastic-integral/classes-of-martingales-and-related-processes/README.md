# Classes of martingales and related processes

The main reference for this part is (he2019semimartingale).

Notations for classes of processes:

- $\mathcal{V}$: finite variation processes (Definition [Finite variation process, $\mathcal{V}$](https://github.com/RemyDegenne/brownian-motion/blob/8fd8dc52830cdd07cf9cc8eadd533e284425fa6f/blueprint/src/chapters/martingale_classes.tex#L82))
- $\mathcal{V}^+$: non-decreasing finite variation processes
- $\mathcal{A}$: adapted processes with integrable variation (Definition [Integrable variation, $\mathcal{A}$](https://github.com/RemyDegenne/brownian-motion/blob/8fd8dc52830cdd07cf9cc8eadd533e284425fa6f/blueprint/src/chapters/martingale_classes.tex#L126))
- $\mathcal{A}^+$: non-decreasing adapted integrable processes
- $\mathcal{M}$: càdlàg martingales (TODO: (he2019semimartingale) add uniform integrability)
- $\mathcal{M}^c$: continuous martingales
- $\mathcal{M}^2$: square-integrable martingales (Definition [Square integrable martingales](square-integrable-martingales/part-01/def-issquareintegrable.md))
- $\mathcal{C}_{\mathrm{loc}}$ for a class $\mathcal{C}$: processes that are locally in $\mathcal{C}$

Note: (he2019semimartingale) use $\mathcal{W}$ for $\mathcal{M} \cap \mathcal{A}$.
