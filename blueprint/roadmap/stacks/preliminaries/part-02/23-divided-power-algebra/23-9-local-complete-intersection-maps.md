**`LocalCompleteIntersection.isCompleteIntersectionHom_iff_forall_goodFactorization`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/LocalCompleteIntersection/CompleteIntersectionHom.lean, line 954](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/RingTheory/LocalCompleteIntersection/CompleteIntersectionHom.lean#L954).

> For a local homomorphism of Noetherian complete local rings, the kernel is generated by a
> regular sequence in one good factorization if and only if it is so generated in every good
> factorization.

```lean
public theorem isCompleteIntersectionHom_iff_forall_goodFactorization
    {A : Type u} {B : Type v} [CommRing A] [CommRing B]
    [IsNoetherianRing A] [IsNoetherianRing B] [IsLocalRing A] [IsLocalRing B]
    [IsAdicComplete (maximalIdeal A) A] [IsAdicComplete (maximalIdeal B) B]
    (h : A →+* B) [IsLocalHom h] :
    IsCompleteIntersectionHom h ↔
      ∀ (S : Type (max u v w)) [CommRing S] [IsNoetherianRing S] [IsLocalRing S]
        (f : A →+* S) (g : S →+* B),
        IsGoodFactorization h f g → (RingHom.ker g).IsGeneratedByRegularSequence
```

> Avramov's characterization for a local homomorphism of Noetherian local rings.

```lean
public theorem isCompleteIntersectionRing_and_eventually_tor_isZero_iff
    {A B : Type u} [CommRing A] [CommRing B]
    [IsNoetherianRing A] [IsNoetherianRing B]
    [IsLocalRing A] [IsLocalRing B]
    (f : A →+* B) [IsLocalHom f] :
    (letI : Algebra A B := f.toAlgebra
     IsCompleteIntersectionRing B ∧
       ∃ n : ℕ, ∀ p : ℕ, n < p →
         IsZero (((Tor (ModuleCat.{u} A) p).obj (ModuleCat.of A B)).obj
           (ModuleCat.of A (ResidueField A)))) ↔
      (IsCompleteIntersectionRing A ∧
        IsCompleteIntersectionHom
          (adicCompletionMap f (maximalIdeal A) (maximalIdeal B)
            (IsLocalRing.map_maximalIdeal_le f)))
```

## Tag 09QD, a lemma

[Tag 09QD](https://stacks.math.columbia.edu/tag/09QD) in the Stacks Project.

**`LocalCompleteIntersection.isGeneratedByRegularSequence_ker_iff_isCompleteIntersectionHom`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/LocalCompleteIntersection/CompletionCriterion.lean, line 503](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/RingTheory/LocalCompleteIntersection/CompletionCriterion.lean#L503).

> In a good factorization `A → S → B`, the kernel of `S → B` is generated by a
> regular sequence if and only if the induced map `A^∧ → B^∧` is a complete intersection
> homomorphism.

```lean
public theorem isGeneratedByRegularSequence_ker_iff_isCompleteIntersectionHom
    {A : Type u} {B : Type v} {S : Type w} [CommRing A] [CommRing B] [CommRing S]
    [IsNoetherianRing A] [IsNoetherianRing B] [IsNoetherianRing S]
    [IsLocalRing A] [IsLocalRing B] [IsLocalRing S]
    (h : A →+* B) (f : A →+* S) (g : S →+* B)
    [IsLocalHom h] (hgood : IsGoodFactorization h f g) :
    (RingHom.ker g).IsGeneratedByRegularSequence ↔
      IsCompleteIntersectionHom
        (adicCompletionMap h (maximalIdeal A) (maximalIdeal B)
          (IsLocalRing.map_maximalIdeal_le h))
```

## Tag 09QE, a lemma

[Tag 09QE](https://stacks.math.columbia.edu/tag/09QE) in the Stacks Project.

**`LocalCompleteIntersection.isLocalCompleteIntersection_iff_forall_isCompleteIntersectionHom`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/LocalCompleteIntersection/FiniteTypeCriterion.lean, line 444](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/RingTheory/LocalCompleteIntersection/FiniteTypeCriterion.lean#L444).

> A finite-type map from a Noetherian ring is a local complete intersection exactly when,
> at each target prime, the map between the completions of the corresponding local rings is a
> complete intersection homomorphism.

```lean
public theorem isLocalCompleteIntersection_iff_forall_isCompleteIntersectionHom
    {A B : Type u} [CommRing A] [CommRing B] [IsNoetherianRing A]
    (f : A →+* B) (hf : f.FiniteType) :
    f.IsLocalCompleteIntersection ↔
      letI := f.toAlgebra
      letI : Algebra.FiniteType A B := hf
      letI : IsNoetherianRing B := Algebra.FiniteType.isNoetherianRing A B
      ∀ (q : Ideal B) [q.IsPrime],
        let p := q.comap f
        let h := Localization.localRingHom p q f rfl
        letI : IsLocalHom h := Localization.isLocalHom_localRingHom p q f rfl
        IsCompleteIntersectionHom
          (adicCompletionMap h (IsLocalRing.maximalIdeal (Localization.AtPrime p))
            (IsLocalRing.maximalIdeal (Localization.AtPrime q))
            (IsLocalRing.map_maximalIdeal_le h))
```

```lean
public theorem isLocalCompleteIntersectionRing_and_hasFiniteTorDimension_iff
    {A B : Type u} [CommRing A] [CommRing B] [IsNoetherianRing A]
    (f : A →+* B) (hf : f.FiniteType)
    (himage : ∀ (m : Ideal A), m.IsMaximal →
      ∃ q : Ideal B, q.IsPrime ∧ q.comap f = m) :
    (letI : Algebra A B := f.toAlgebra
     letI : Algebra.FiniteType A B := hf
     letI : IsNoetherianRing B := Algebra.FiniteType.isNoetherianRing A B
     IsLocalCompleteIntersectionRing B ∧
       ModuleHasFiniteTorDimension
         (CochainComplex.DerivedTensor.canonicalDerivedTensorProduct A).tensor
         (canonicalTensorComparison A) (canonicalTensorIsLeftDerived A)
         (ModuleCat.of A B)) ↔
      (IsLocalCompleteIntersectionRing A ∧ f.IsLocalCompleteIntersection)
```
