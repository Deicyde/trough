# kummerLogRank

Set

$$
r \;=\; \frac{p-3}{2},
$$

the common cardinality of the set of standard generators $\varepsilon_2,\ldots,\varepsilon_{(p-1)/2}$ and of the even index set $\{2j : 1 \le j,\ 2j \le p-3\}$ of Kummer's range.
