# CliffordAlgebra.scalarTrace_conjStar_mul_self_eq_zero_iff_mem_span_radical

For a negative semidefinite real quadratic form, the null set of the negative-metric trace
norm on the complexified Clifford algebra is the two-sided ideal generated by the radical of
`Q_ℂ`.

```lean
CliffordAlgebra.scalarTrace_conjStar_mul_self_eq_zero_iff_mem_span_radical.{u_1} {V : Type u_1}
  [AddCommGroup V] [_root_.Module ℝ V] {Q : QuadraticForm ℝ V} [FiniteDimensional ℝ V]
  (hQ : ∀ (v : V), Q v ≤ 0) (x : CliffordAlgebra (QuadraticForm.baseChange ℂ Q)) :
  (CliffordAlgebra.scalarTrace (QuadraticForm.baseChange ℂ Q))
        ((CliffordAlgebra.conjStar Q) x * x) =
      0 ↔
    x ∈
      TwoSidedIdeal.span
        (⇑(CliffordAlgebra.ι (QuadraticForm.baseChange ℂ Q)) ''
          ↑(QuadraticMap.radical (QuadraticForm.baseChange ℂ Q)))
```
