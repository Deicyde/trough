# The graded character of the coinvariant algebra of a pseudoreflection group

Let a finite
group `G`, whose order is invertible in `K`, act on a finite-dimensional vector space `V` and be
generated by pseudoreflections. For any homogeneous basic invariants `f i` of the polynomial
functions `Sym(V*)`, of degrees `d i`, and every `g`, the graded character of the coinvariant
algebra of `Sym(V*)` satisfies `(∑ⱼ χ_{Cⱼ}(g) tʲ) * det(1 - t g | V*) = ∏ᵢ (1 - t ^ d i)`,
where `det(1 - t g | V*)` is the reverse of the characteristic polynomial of `ρ.dual g`.
No faithfulness assumption is needed.

```lean
Representation.mk_character_coinvariantAlgebraHomogeneous_dual_of_pseudoreflectionSubgroup_eq_top.{u_1,
    u_2, u_4}
  {K : Type u_1} {G : Type u_2} [Field K] {V : Type u_4} [AddCommGroup V] [_root_.Module K V]
  [FiniteDimensional K V] [Group G] [Fintype G] [Invertible ↑(Fintype.card G)]
  (ρ : Representation K G V) (hG : ρ.pseudoreflectionSubgroup = ⊤) {n : ℕ}
  (f : Fin n → ↥ρ.dual.symmetricAlgebraInvariants) (d : Fin n → ℕ)
  (hf :
    ∀ (i : Fin n), ↑(f i) ∈ TauCeti.SymmetricAlgebra.homogeneousSubmodule K (Module.Dual K V) (d i))
  (hbij : Function.Bijective ⇑(MvPolynomial.aeval f)) (g : G) :
  (PowerSeries.mk fun j => (ρ.dual.coinvariantAlgebraHomogeneous j).character g) *
      ↑(ρ.dual g).charpoly.reverse =
    ∏ i, (1 - PowerSeries.X ^ d i)
```
