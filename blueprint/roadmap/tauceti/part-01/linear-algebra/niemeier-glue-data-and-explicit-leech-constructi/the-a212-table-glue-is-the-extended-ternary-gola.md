# The `A₂¹²` table glue is the extended ternary Golay code

The isometry
`a2TwelfthGolayIsometry`, given by the permutation `[0, 4, 7, 10, 9, 5, 1, 8, 6, 11, 3, 2]` and
the scalings `[1, 2, 2, 1, 1, 1, 1, 2, 2, 1, 2, 1]`, carries the subgroup generated by the
pattern `[2(11211122212)]` onto `TauCeti.TernaryGolay.code`.
