# Theillière 2018

The map obtained by corrugation of $f$ in direction $(π, v)$ using $γ$ with oscillation number $N$ is

$$
x ↦ f(x) + \frac1N  ∫_0^{Nπ(x)} \left[γ_x(s) - \overline{γ}_x\right]ds.
$$
