# Mathlib

Mathlib's maintainers keep four curated lists of what the library contains: an overview of its main concepts, an undergraduate curriculum, Freek Wiedijk's 100 theorems, and the theorems of the 1000+ theorems project. This chapter has one article per concept on those lists, read at Mathlib commit [1b1ccf4b](https://github.com/leanprover-community/mathlib4/tree/1b1ccf4b088b32fa3f23f2de1127433254a81e1e) (2026-11-02): 2,056 articles, 886 of them in Mathlib and 1,170 not yet.

An item that names the same declarations in several lists is one article, placed in the first list that has it; the other lists link to it. An article in Mathlib names its declarations, with their documentation and source. One that Mathlib lacks is marked not ready: its statement and prerequisites are still to be written.

Dependency edges come from a GitHub Actions run over Mathlib's declaration graph, which has not reached this page yet.
