# The wiki's articles

each (the format is in `tools/trough/wiki.py`). They are by trough's
contributors and licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), unlike the rest
of the repository, which is Apache-2.0.
