## Weak Sidon set

A set $A \subseteq \mathbb{N}$ is a *weak Sidon set* (or *well spread*) if
sums of two distinct elements of $A$ are distinct: whenever $a, b, c, d \in A$ satisfy $a < b$,
$c < d$ and $a + b = c + d$, then $a = c$.

## Ideal generated by a property

Let $P$ be a property of subsets of $\mathbb{N}$. The ideal
generated by $P$ is the family of all sets $A \subseteq \mathbb{N}$ that are contained in the union
of finitely many sets with property $P$. The empty union is allowed, so the empty set always
belongs to it.

## Sources

## Sets with a property lie in the ideal it generates

Let $P$ be a property of subsets
of $\mathbb{N}$. Every set $A \subseteq \mathbb{N}$ with property $P$ lies in the ideal
generated by $P$, the family of all subsets of finite unions of sets with property $P$.

## Sidon ideal

The Sidon ideal $\mathrm{Si}$ is the ideal on $\mathbb{N}$ generated by the
Sidon sets: it consists of all sets $A \subseteq \mathbb{N}$ contained in a finite union of
Sidon subsets of $\mathbb{N}$.

## Gap-lacunary set

A set $A \subseteq \mathbb{N}$ is *gap-lacunary* (called *lacunary* in
the source) if it is infinite and, writing $A(n)$ for its $n$-th element in increasing order
(counting from $n = 0$), the gaps $A(n+1) - A(n)$ tend to infinity as $n \to \infty$.

This differs from Hadamard lacunarity, where consecutive elements grow by a factor at least
$q > 1$.

## Sources

## Almost thin set

A set $A \subseteq \mathbb{N}$ is *almost thin* if it is infinite and,
writing $A(n)$ for its $n$-th element in increasing order (counting from $n = 0$), there is a
real number $\alpha < 1$ such that $A(n)/A(n+1) \le \alpha$ for all sufficiently large $n$.

Since the ratios $A(n)/A(n+1)$ lie in $[0, 1]$, this is equivalent to
$\limsup_{n \to \infty} A(n)/A(n+1) < 1$.

## Sources

## Van der Waerden ideal

The van der Waerden ideal $W$ consists of the sets
$A \subseteq \mathbb{N}$ for which there is an $n > 0$ such that $A$ contains no arithmetic
progression $a, a + r, \dots, a + (n - 1) r$ of $n$ terms with $a \in \mathbb{N}$ and $r > 0$.

## Positive difference set

For a set $Z \subseteq \mathbb{N}$, the positive difference set
$D(Z)$ is the set of all differences $a - b$ with $a, b \in Z$ and $a > b$.

## The ideal of sets avoiding large difference sets

For a set $Z \subseteq \mathbb{N}$, let
$D(Z) = \{a - b : a, b \in Z,\ b < a\}$ be its set of positive differences. The ideal
$D_{\mathrm{fin}}$ consists of the sets $A \subseteq \mathbb{N}$ for which there is a natural
number $n$ such that $D(Z) \not\subseteq A$ for every $n$-element set $Z \subseteq \mathbb{N}$.

## Sources

## The empty set lies in the difference-set ideal

The empty set belongs to the ideal
$D_{\mathrm{fin}}$ of sets $A \subseteq \mathbb{N}$ for which some natural number $n$ satisfies
$D(Z) \not\subseteq A$ for every $n$-element set $Z \subseteq \mathbb{N}$, where $D(Z)$ is the set
of positive differences $a - b$ with $a, b \in Z$ and $b < a$.

One can take $n = 2$: every two-element set has a positive difference.

## Block sets

For natural numbers $n$, $C$, $M$ and $K$, the block
$\mathrm{Block}(n, C, M, K)$ is the set of natural numbers $M l + C \cdot 2^k$ with
$0 \le k < n$ and $1 \le l \le K$.

## The Sidon ideal is $F_\sigma$

Give the Cantor space $\{0, 1\}^{\mathbb{N}}$ the product
topology and identify each set $A \subseteq \mathbb{N}$ with its indicator function. Then the set
of indicator functions of the members of the Sidon ideal is a countable union of closed subsets
of $\{0, 1\}^{\mathbb{N}}$.

## Positive sets whose elements at least double are Sidon

Let $A \subseteq \mathbb{N}$ with
$0 \notin A$, and write $A(n)$ for the $n$-th element of $A$ in increasing order, counting from
$n = 0$, with $A(n) = 0$ when $A$ has at most $n$ elements. If $2 A(n) \le A(n+1)$ for every
$n \in \mathbb{N}$, then $A$ is a Sidon set.

The hypotheses force $A$ to be empty or infinite, so the source's standing assumption that $A$
is infinite is not needed.

## The Sidon ideal is contained in the lacunary ideal

Call a set $A \subseteq \mathbb{N}$
lacunary if it is infinite and the gaps $A(n + 1) - A(n)$ between consecutive elements tend to
infinity, where $A(n)$ is the $n$-th element of $A$ in increasing order. Every set in the Sidon
ideal is contained in a finite union of lacunary sets, that is, it lies in the ideal
$\mathrm{Lac}$ generated by the lacunary sets.

## Mian–Chowla lower bound for an infinite Sidon set

There exist a Sidon set
$A \subseteq \mathbb{N}$ and a real constant $c > 0$ such that
$|A \cap \{1, \dots, n\}| > c\, n^{1/3}$ for every natural number $n \ge 1$.

## Ajtai–Komlós–Szemerédi lower bound for an infinite Sidon set

There exist a Sidon set
$A \subseteq \mathbb{N}$ and a real constant $c > 0$ such that
$|A \cap \{1, \dots, n\}| > c\, (n \log n)^{1/3}$ for every natural number $n \ge 1$, where $\log$
is the natural logarithm.

## Ruzsa's lower bound for an infinite Sidon set

There is a Sidon set $A \subseteq \mathbb{N}$
such that for every real $\varepsilon > 0$, the inequality
$|A \cap \{1, \dots, n\}| > n^{\sqrt{2} - 1 - \varepsilon}$ holds for all sufficiently large
natural numbers $n$; that is, $|A \cap \{1, \dots, n\}| > n^{\sqrt{2} - 1 - o(1)}$.

## A Sidon set outside the almost thin ideal

There is a Sidon set $A \subseteq \mathbb{N}$
that is not contained in any finite union of almost thin sets; that is, $A$ does not belong to the
ideal generated by the almost thin sets.

## The almost thin ideal is contained in the Sidon ideal

Every set $A \subseteq \mathbb{N}$
that is contained in a finite union of almost thin sets is contained in a finite union of Sidon
sets; that is, the ideal generated by the almost thin sets is contained in the Sidon ideal.

## A block not covered by few Sidon sets

Let $n \ge 1$ and $C \ge 1$ be natural
numbers, and put $M = C \cdot 2^n + 1$ and $K = (n - 1)\binom{n}{2} + 1$. Then the block
$\mathrm{Block}(n, C, M, K) = \{M l + C \cdot 2^k : 0 \le k < n,\ 1 \le l \le K\}$ is not
contained in the union of any $n - 1$ Sidon subsets of $\mathbb{N}$.

## A set in the van der Waerden, lacunary and difference-set ideals outside the Sidon ideal

There is a set $A \subseteq \mathbb{N}$ that belongs to the van der Waerden ideal, is contained in
a finite union of gap-lacunary sets (infinite sets whose gaps between consecutive elements tend to
infinity), and belongs to the ideal $D_{\mathrm{fin}}$ of sets avoiding large difference sets, but
is not contained in any finite union of Sidon sets.
