# TauCeti.IsFreelyIndependent.eqOn_iSup

Freeness determines the joint distribution from the individual ones: two normalised
functionals for which `B` is free and which agree on each `B i` agree on the subalgebra
generated by the `B i`.

```lean
TauCeti.IsFreelyIndependent.eqOn_iSup.{u_1, u_2, u_4} {R : Type u_1} {A : Type u_2} {ι : Type u_4}
  [CommRing R] [Ring A] [Algebra R A] {φ ψ : A →ₗ[R] R} {B : ι → Subalgebra R A} (hφ : φ 1 = 1)
  (hψ : ψ 1 = 1) (hfφ : TauCeti.IsFreelyIndependent φ B) (hfψ : TauCeti.IsFreelyIndependent ψ B)
  (h : ∀ (i : ι), Set.EqOn ⇑φ ⇑ψ ↑(B i)) : Set.EqOn ⇑φ ⇑ψ ↑(⨆ i, B i)
```
