# Homeomorphisms

Homeomorphism between `X` and `Y`, also called topological isomorphism

```lean
Homeomorph.{u_4, u_5} (X : Type u_4) (Y : Type u_5) [TopologicalSpace X] [TopologicalSpace Y] :
  Type (max u_4 u_5)
```
