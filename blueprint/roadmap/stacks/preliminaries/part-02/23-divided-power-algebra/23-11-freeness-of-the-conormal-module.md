> A direct summand of `I/I²` isomorphic to `R/I`, for an ideal `I` of finite projective
> dimension in a Noetherian local ring, is generated by the class of a nonzerodivisor of `R`
> belonging to `I`.

```lean
theorem exists_isRegular_generator_of_isCompl_cotangent
    (R : Type u) [CommRing R] [IsNoetherianRing R] [IsLocalRing R]
    (I : Ideal R) (hI : Module.projectiveDimension R I ≠ ⊤)
    (F : Submodule (R ⧸ I) I.Cotangent)
    (hF : ∃ F' : Submodule (R ⧸ I) I.Cotangent, IsCompl F F')
    (hFfree : Nonempty (F ≃ₗ[R ⧸ I] R ⧸ I)) :
    ∃ (x : R) (hx : x ∈ I), IsRegular x ∧
      Submodule.span (R ⧸ I) {I.toCotangent ⟨x, hx⟩} = F
```

## Tag 0FJR, a lemma

[Tag 0FJR](https://stacks.math.columbia.edu/tag/0FJR) in the Stacks Project.

**`Ideal.exists_isRegular_of_isCompl_cotangent`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/Ideal/ConormalFreeSummand.lean, line 1139](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/RingTheory/Ideal/ConormalFreeSummand.lean#L1139).

> **Stacks Project, Tag 0FJR, with the positive-rank properness correction.** A finite-rank
> free direct summand of `I/I²`, for an ideal `I` of finite projective dimension in a Noetherian
> local ring, lifts to a regular sequence in `I` whose residue classes generate that summand,
> provided `I` is proper when the rank is positive.

```lean
theorem exists_isRegular_of_isCompl_cotangent
    {R : Type u} [CommRing R] [IsNoetherianRing R] [IsLocalRing R]
    (I : Ideal R) (r : ℕ) (F : Submodule (R ⧸ I) I.Cotangent)
    (hproper : r = 0 ∨ I ≠ ⊤)
    (hpd : Module.projectiveDimension R I ≠ ⊤)
    (hcompl : ∃ F' : Submodule (R ⧸ I) I.Cotangent, IsCompl F F')
    (hfree : Nonempty (Module.Basis (Fin r) (R ⧸ I) F)) :
    ∃ x : Fin r → I,
      RingTheory.Sequence.IsRegular R (List.ofFn fun i ↦ (x i : R)) ∧
        Submodule.span (R ⧸ I) (Set.range fun i ↦ I.toCotangent (x i)) = F
```

> Let `A → B` be a perfect ring homomorphism of Noetherian rings. Then the
> naive cotangent complex `NL_{B/A}` has Tor amplitude in `[-1, 0]` if and only if it is a perfect
> object of `D(B)` with Tor amplitude in `[-1, 0]`, if and only if `A → B` is a local complete
> intersection.

```lean
public theorem hasTorAmplitude_tfae_isLocalCompleteIntersection
    (A B : Type u) [CommRing A] [CommRing B] [Algebra A B]
    [IsNoetherianRing A] [IsNoetherianRing B] [Algebra.Perfect A B] :
    List.TFAE
      [HasTorAmplitude
          (CochainComplex.DerivedTensor.canonicalDerivedTensorProduct B).tensor
          (canonicalTensorComparison B) (canonicalTensorIsLeftDerived B)
          (naiveCotangentObject A B) (-1) 0,
        StacksDraft.Perfect.IsPerfect (naiveCotangentObject A B) ∧
          HasTorAmplitude
            (CochainComplex.DerivedTensor.canonicalDerivedTensorProduct B).tensor
            (canonicalTensorComparison B) (canonicalTensorIsLeftDerived B)
```
