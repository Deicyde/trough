# Freudenthal's multiplicity formula

Let `M` be a finite-dimensional module generated by a
highest weight vector of weight `λ`. Then for every linear form `μ` on the Cartan subalgebra,

`(⟨λ + ρ, λ + ρ⟩ - ⟨μ + ρ, μ + ρ⟩) · dim Mμ = 2 ∑_{α > 0} ∑_{j ≥ 1} dim M_{μ + jα} · ⟨μ + jα, α⟩`,

the inner sum running over the `α`-string above `μ` with the rung `μ` itself removed; the double
sum is `TauCeti.freudenthalRHS`.

Together with `dim Mλ = 1` at the top weight this is the recursion for the multiplicities below
`λ`; solved for `dim Mμ` it is `TauCeti.coeff_formalCharacter_eq_freudenthalRHS_div`.

```lean
TauCeti.freudenthal_multiplicity_formula.{u, v, w} {K : Type u} {L : Type v} [Field K] [LieRing L]
  [LieAlgebra K L] {H : LieSubalgebra K L} {M : Type w} [AddCommGroup M] [_root_.Module K M]
  [LieRingModule L M] [LieModule K L M] [CharZero K] [LieAlgebra.IsKilling K L]
  [FiniteDimensional K L] [H.IsCartanSubalgebra] [FiniteDimensional K M] [IsAlgClosed K]
  {b : (LieAlgebra.IsKilling.rootSystem H).Base} {lam : Module.Dual K ↥H} {v : M}
  (hv : TauCeti.IsHighestWeightVector b lam v) (hgen : LieSubmodule.lieSpan K L {v} = ⊤)
  (mu : Module.Dual K ↥H) :
  ((TauCeti.invForm (lam + TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b))
          (lam + TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b) -
        (TauCeti.invForm (mu + TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b))
          (mu + TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b)) *
      ↑(Module.finrank K ↥(LieModule.genWeightSpace M ⇑mu)) =
    2 * TauCeti.freudenthalRHS M b mu
```
