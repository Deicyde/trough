> Let `R` be a commutative ring and `T ⊆ Spec R`. The following are equivalent:
> `T` is closed and a union of connected components of `Spec R`; `T` is an intersection of open and
> closed subsets of `Spec R`; `T = V I` for some ideal `I` generated by idempotents; there is a
> unique such ideal `I`; and `T` is the zero locus of the ideal generated by all idempotents
> vanishing on `T`.

```lean
theorem isClosed_and_biUnion_connectedComponent_eq_tfae (T : Set (PrimeSpectrum R)) :
    [IsClosed T ∧ (⋃ x ∈ T, connectedComponent x) = T,
      ∃ S : Set (Set (PrimeSpectrum R)), (∀ U ∈ S, IsClopen U) ∧ T = ⋂₀ S,
      ∃ I : Ideal R, (∃ s : Set R, (∀ e ∈ s, IsIdempotentElem e) ∧ I = Ideal.span s) ∧
        T = zeroLocus (I : Set R),
      ∃! I : Ideal R, (∃ s : Set R, (∀ e ∈ s, IsIdempotentElem e) ∧ I = Ideal.span s) ∧
        T = zeroLocus (I : Set R),
      T = zeroLocus
        (Ideal.span {e : R | IsIdempotentElem e ∧ T ⊆ zeroLocus {e}} : Set R)].TFAE
```

**`PrimeSpectrum.exists_connectedComponent_eq_zeroLocus_span_isIdempotentElem`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/Spectrum/Prime/ConnectedComponents.lean, line 354](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/RingTheory/Spectrum/Prime/ConnectedComponents.lean#L354).

> **Stacks Tag 00EG.** For any commutative ring `R` and any point `x` of
> `Spec R`, the connected component of `x` is `V(I)` for an ideal `I` generated by
> idempotents such that every idempotent of `R` maps to `0` or `1` in `R/I`.

```lean
theorem PrimeSpectrum.exists_connectedComponent_eq_zeroLocus_span_isIdempotentElem
    (x : PrimeSpectrum R) :
    ∃ I : Ideal R,
      connectedComponent x = PrimeSpectrum.zeroLocus (I : Set R) ∧
      I = Ideal.span {e : R | e ∈ I ∧ IsIdempotentElem e} ∧
      ∀ e : R, IsIdempotentElem e →
        (Ideal.Quotient.mk I e = 0 ∨ Ideal.Quotient.mk I e = 1)
```
