# The Triviality Criterion

Recall that a representation $M$ of a group $G$ has trivial cohomology if for all subgroups $S$ of $G$ and all $n > 0$, the cohomology groups $H^{n}(S,M)$ are zero. We begin with a theorem which will immediately be made redundant by the theorem after.
