The attribute's comment: “Tr(ab) = Tr(ba) in Λ^♮ for a : Λ^⊕m → Λ^⊕n and b : Λ^⊕n → Λ^⊕m, where Λ is a ring that is not assumed commutative and Λ^♮ is Λ modulo the additive subgroup generated by the commutators”.

> **Stacks Project, Tag 03T1.** Given `Λ`-linear maps `a : Λ^⊕m → Λ^⊕n` and
> `b : Λ^⊕n → Λ^⊕m` over a ring `Λ`, the traces of `ab` and of `ba` agree in `Λ^♮`.

```lean
public theorem freeTrace_comp_comm {m n : ℕ} (a : (Fin m → Λ) →ₗ[Λ] (Fin n → Λ))
    (b : (Fin n → Λ) →ₗ[Λ] (Fin m → Λ)) :
    freeTrace (b ∘ₗ a) = freeTrace (a ∘ₗ b)
```
