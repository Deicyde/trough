# The stabilizer of a dominant weight is a standard parabolic subgroup

the one generated by
the simple reflections in the walls through it.

```lean
RootPairing.parabolic_wallIndices_eq_stabilizer.{u, v, w, x} {ι : Type u} {R : Type v} {M : Type w}
  {N : Type x} [CommRing R] [AddCommGroup M] [_root_.Module R M] [AddCommGroup N]
  [_root_.Module R N] (P : RootPairing ι R M N) (b : P.Base) [LinearOrder R] [IsStrictOrderedRing R]
  [Finite ι] [P.IsCrystallographic] [P.IsReduced] [P.flip.IsReduced] {lam : M}
  (hlam : lam ∈ P.dominantChamber b) :
  (TauCeti.weylCoxeterSystem P b).parabolic (P.wallIndices b lam) =
    MulAction.stabilizer (↥P.weylGroup) lam
```
