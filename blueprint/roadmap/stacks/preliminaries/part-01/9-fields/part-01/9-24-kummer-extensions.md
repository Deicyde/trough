> A field extension generated by an `n`-th root is finite Galois when the
> base field contains a primitive `n`-th root of unity. Its Galois group is
> cyclic, its degree divides `n`, and, for a nonzero generator, its Kummer
> character is injective and is given by `σ ↦ σ(b) / b`.

```lean
theorem isGalois_isCyclic_finrank_dvd_and_kummerCharacter_injective_of_adjoin_root_eq_top
    (K : Type uK) (L : Type uL) [Field K] [Field L] [Algebra K L]
    (n : ℕ) (hn : 2 ≤ n) (ζ : K) (hζ : IsPrimitiveRoot ζ n) (b : L)
    (hpow : b ^ n ∈ Set.range (algebraMap K L))
    (hgen : Algebra.adjoin K {b} = ⊤) :
    ∃ hfin : Module.Finite K L,
      letI := hfin
      IsGalois K L ∧ IsCyclic (L ≃ₐ[K] L) ∧ Module.finrank K L ∣ n ∧
        ∀ hb : b ≠ 0,
          Function.Injective
            (kummerCharacter K L n (by omega) ζ hζ b hb hpow) ∧
          ∀ σ : L ≃ₐ[K] L,
            algebraMap K L
                (((kummerCharacter K L n (by omega) ζ hζ b hb hpow σ :
                    rootsOfUnity n K) : Kˣ) : K) =
              σ b / b
```
