# The fundamental-set part of Poincaré's polygon theorem

If a side-paired polygon
satisfies the angle condition at every finite vertex cycle and has parabolic cycle
transformations at its ideal vertices, then it is a measurable fundamental domain for the group
generated by its side-pairing maps.

```lean
TauCeti.UpperHalfPlane.ConvexPolygon.SidePairing.isFundamentalDomain_carrier_of_isParabolic {n : ℕ}
  [NeZero n] {P : TauCeti.UpperHalfPlane.ConvexPolygon n} (σ : P.SidePairing)
  (hcyc :
    ∀ (j : Fin n) (z : UpperHalfPlane),
      P.vertex j = Sum.inl z → ↑(orderOf (σ.cycleMap j)) * σ.cycleAngleSum j = 2 * Real.pi)
  (hpar : ∀ (j : Fin n) (ξ : OnePoint ℝ), P.vertex j = Sum.inr ξ → (σ.cycleMap j).IsParabolic) :
  MeasureTheory.IsFundamentalDomain (↥(Subgroup.closure (Set.range σ.map))) P.carrier
    MeasureTheory.volume
```
