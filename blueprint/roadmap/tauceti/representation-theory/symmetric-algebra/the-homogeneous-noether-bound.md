# The homogeneous Noether bound

The invariants of a finite linear group over a rational
algebra are generated by homogeneous invariants of positive degree at most the group order.
This holds without finite generation or freeness of the underlying module.

```lean
Representation.symmetricAlgebraInvariants_eq_adjoin_homogeneous.{u_1, u_2, u_3} {R : Type u_1}
  {G : Type u_2} {M : Type u_3} [CommRing R] [Group G] [AddCommMonoid M] [_root_.Module R M]
  (ρ : Representation R G M) [Fintype G] [Algebra ℚ R] :
  ρ.symmetricAlgebraInvariants =
    Algebra.adjoin R
      {p |
        p ∈ ρ.symmetricAlgebraInvariants ∧
          ∃ n, 0 < n ∧ n ≤ Fintype.card G ∧ p ∈ TauCeti.SymmetricAlgebra.homogeneousSubmodule R M n}
```
