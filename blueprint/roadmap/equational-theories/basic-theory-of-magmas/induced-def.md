# Induced homomorphism

Given a function $f: X \to G$ from an alphabet $X$ to a magma $G$, the *induced homomorphism* $\varphi_f: M_X \to G$ is the unique extension of $f$ to a magma homomorphism. Similarly, if $\pi \colon X \to Y$ is a function, we write $\pi_* \colon M_X \to M_Y$ for the unique extension of $\pi$ to a magma homomorphism.
