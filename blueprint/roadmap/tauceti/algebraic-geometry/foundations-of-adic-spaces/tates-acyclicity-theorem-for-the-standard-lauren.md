# Tate's acyclicity theorem for the standard Laurent cover of the closed unit disc

Let `K`
be a complete nonarchimedean field and `a, c ∈ K` with `c ≠ 0`. The closed unit disc
`Spa(K⟨T⟩, K⟨T⟩°)` is covered by the closed subdisc `R({T - a, c} / c) = {|T - a| ≤ |c|}` and by
`R({c} / (T - a)) = {|T - a| ≥ |c|}`, the Laurent cover generated by `c⁻¹ (T - a)`. The augmented
Čech complex of the structure presheaf, as a presheaf of abelian groups, for this cover is exact
in every degree.

```lean
TauCeti.ValuationSpectrum.quasiIso_cechAugmentation_closedDisc_spaBasicOpen.{u} {K : Type u}
  [NormedField K] [IsUltrametricDist K] [NonarchimedeanRing K] [CompleteSpace K]
  [TauCeti.Huber.IsTateRing K] (P : TauCeti.Huber.PairOfDefinition K)
  [DecidableEq ↥(TauCeti.Huber.weightedRestrictedSubring (fun x => {1}) ⋯)] (a : K) {c : K}
  (hc : c ≠ 0) :
  QuasiIso
    (TauCeti.CategoryTheory.cechAugmentation
      ![⟨TauCeti.ValuationSpectrum.spaBasicOpen
            (TauCeti.Huber.powerBoundedSubring
              ↥(TauCeti.Huber.weightedRestrictedSubring (fun x => {1}) ⋯))
            {TauCeti.Huber.weightedX (fun x => {1}) ⋯ 0 -
                (TauCeti.Huber.weightedC (fun x => {1}) ⋯) a,
              (TauCeti.Huber.weightedC (fun x => {1}) ⋯) c}
            ((TauCeti.Huber.weightedC (fun x => {1}) ⋯) c),
          ⋯⟩,
        ⟨TauCeti.ValuationSpectrum.spaBasicOpen
            (TauCeti.Huber.powerBoundedSubring
              ↥(TauCeti.Huber.weightedRestrictedSubring (fun x => {1}) ⋯))
            {(TauCeti.Huber.weightedC (fun x => {1}) ⋯) c}
            (TauCeti.Huber.weightedX (fun x => {1}) ⋯ 0 -
              (TauCeti.Huber.weightedC (fun x => {1}) ⋯) a),
          ⋯⟩]
      CategoryTheory.Limits.isTerminalTop
      (TauCeti.ValuationSpectrum.presentationLimitAddCommGrpPresheaf (P.weighted ⋯)
        (TauCeti.Huber.powerBoundedSubring
          ↥(TauCeti.Huber.weightedRestrictedSubring (fun x => {1}) ⋯))
        ⊤))
```
