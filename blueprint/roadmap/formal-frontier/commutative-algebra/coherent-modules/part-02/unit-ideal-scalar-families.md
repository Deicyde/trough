# Unit-ideal scalar families

For an arbitrary family of scalars generating
the unit ideal in a semiring `S`,
[`Ideal.existsUnique_smul_eq_of_span_range_eq_top`](https://github.com/FormalFrontier/coherent-modules/blob/b670b34e8741624c22b88375b9086d6d393cbbc3/CoherentModules/Algebra/Module/Coprime.lean)
gives a unique common parameter for compatible elements of an `S`-semimodule
whose scalar actions commute. The index type need not be finite or nonempty,
and no subtraction or additive cancellation is needed.
