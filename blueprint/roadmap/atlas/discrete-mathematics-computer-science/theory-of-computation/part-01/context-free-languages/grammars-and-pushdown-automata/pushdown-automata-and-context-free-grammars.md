# Pushdown automata and context-free grammars

18 results, all proved, quoted from [Deicyde/atlas-lean](https://github.com/Deicyde/atlas-lean) at commit [035e1808](https://github.com/Deicyde/atlas-lean/tree/035e1808ca0c8983682b74153a02628d616d77ce); [its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/pushdown-automata-and-context-free-grammars/index.html).

## Transitions of the grammar-simulating pushdown automaton

Let $g$ be a context-free
grammar over an alphabet $T$. To the single state, an input option (a letter of $T$, or none for
an $\varepsilon$-transition) and a popped symbol of $g$ (a terminal or a nonterminal), this
assigns a finite set of pairs of the state and a list of symbols of $g$ to push. Popping a
nonterminal $A$ with no input gives, for each production of $g$ with left-hand side $A$, the pair
pushing its right-hand side. Popping a terminal $b$ while reading the letter $a$ gives the single
pair pushing nothing if $a = b$, and the empty set otherwise. Popping a nonterminal while reading
a letter, or a terminal with no input, gives the empty set.

Formalized by `Cslib.Language.cfgStep`, a definition declared in [CSLibExt/Computability/Languages/ContextFree/PDA.lean, line 48](https://github.com/Deicyde/atlas-lean/blob/035e1808ca0c8983682b74153a02628d616d77ce/CSLibExt/Computability/Languages/ContextFree/PDA.lean#L48). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/pushdown-automata-and-context-free-grammars/index.html#cfg-step).

## The pushdown automaton simulating a context-free grammar

For a context-free grammar $g$
over an alphabet $T$, this is the pushdown automaton with input alphabet $T$, a single state, the
terminals and nonterminals of $g$ as stack alphabet, and the initial nonterminal of $g$ as initial
stack symbol. Popping a nonterminal $A$ on an $\varepsilon$-transition, it may push the right-hand
side of any production of $g$ with left-hand side $A$ (whose first symbol becomes the new top);
popping a terminal $a$ while reading the input letter $a$, it pushes nothing. It has no other
transitions.

Formalized by `Cslib.Language.cfgPDA`, a definition declared in [CSLibExt/Computability/Languages/ContextFree/PDA.lean, line 57](https://github.com/Deicyde/atlas-lean/blob/035e1808ca0c8983682b74153a02628d616d77ce/CSLibExt/Computability/Languages/ContextFree/PDA.lean#L57). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/pushdown-automata-and-context-free-grammars/index.html#cfg-pda).

## The grammar-simulating pushdown automaton accepts the grammar's language

For every
context-free grammar $g$ over an alphabet $T$, the language accepted by empty stack by the
one-state pushdown automaton simulating $g$ equals the language generated by $g$.

## Context-free languages are accepted by pushdown automata

$L$ over an alphabet $T$ there are a context-free grammar $g$ over $T$ and a pushdown automaton
with input alphabet $T$, a single state, and the terminals and nonterminals of $g$ as stack
alphabet, whose language accepted by empty stack is $L$.

## The grammar-simulating pushdown automaton is finitely supported

For every context-free
grammar $g$ over an alphabet $T$, the one-state pushdown automaton simulating $g$ is finitely
supported.

The finite sets witnessing this are the set containing the single state, the set of stack
symbols consisting of the initial nonterminal of $g$ and all symbols occurring in right-hand
sides of productions of $g$, and the set of terminals occurring in right-hand sides of
productions of $g$.

## Chain of triple nonterminals

Write $(p, \gamma, q)$ for the nonterminal symbol given by
states $p, q$ and a stack symbol $\gamma$ (the nonterminals of the triple grammar are these
triples and one extra initial nonterminal). The chain form of a list $\gamma_1 \cdots \gamma_k$
of stack symbols along a nonempty list $s_0, s_1, \dots, s_m$ of states is the word
$(s_0, \gamma_1, s_1)(s_1, \gamma_2, s_2) \cdots (s_{j-1}, \gamma_j, s_j)$ with $j = \min(k, m)$:
consecutive states bracket each stack symbol. Along the empty list of states the chain form is
the empty word. In the intended use $m = k$, so every stack symbol is bracketed.

Formalized by `Cslib.Language.chainForm`, a definition declared in [CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean, line 48](https://github.com/Deicyde/atlas-lean/blob/035e1808ca0c8983682b74153a02628d616d77ce/CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean#L48). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/pushdown-automata-and-context-free-grammars/index.html#chain-form).

## Chain forms consist of nonterminals

For every list of stack symbols and every list of
states, every symbol of their chain form is a nonterminal.

## Lists of states of a given length

For a finite set $\sigma$ of states and a natural
number $n$, this is the finite set of all lists of length $n$ with entries in $\sigma$. It is
built recursively: for $n = 0$ it contains only the empty list, and for $n + 1$ it consists of
the lists obtained by putting a state $p \in \sigma$ in front of a list from the set for $n$.

Formalized by `Cslib.Language.stateLists`, a definition declared in [CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean, line 131](https://github.com/Deicyde/atlas-lean/blob/035e1808ca0c8983682b74153a02628d616d77ce/CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean#L131). ## Terminal word of an optional input letter

As a word of grammar symbols (terminals and
triple nonterminals), an input that is a letter $a$ contributes the one-symbol word consisting of
the terminal $a$, and the empty input $\varepsilon$ contributes the empty word.

## Production of the triple grammar for a transition

Let $p$ and $r$ be states, $\gamma$ a
stack symbol, $a$ an optional input letter, $\varepsilon_1 \cdots \varepsilon_k$ a list of stack
symbols and $s_1, \dots, s_m$ a list of states. Write $s_0 = r$ and let $q = s_m$ be the last
state of the list $s_0, s_1, \dots, s_m$ (so $q = r$ when $m = 0$). The production has
left-hand side the nonterminal $(p, \gamma, q)$, and its right-hand side is the letter $a$
(nothing if $a$ is absent) followed by the nonterminals $(s_{i-1}, \varepsilon_i, s_i)$ for
$i = 1, \dots, \min(k, m)$ in order.

It encodes a transition that in state $p$, reading $a$ (or no letter), pops $\gamma$, moves to
state $r$ and pushes $\varepsilon_1 \cdots \varepsilon_k$; the triple grammar uses it with
$m = k$.

Formalized by `Cslib.Language.stepRule`, a definition declared in [CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean, line 160](https://github.com/Deicyde/atlas-lean/blob/035e1808ca0c8983682b74153a02628d616d77ce/CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean#L160). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/pushdown-automata-and-context-free-grammars/index.html#step-rule).

## Triple grammar of a pushdown automaton

Let $M$ be a pushdown automaton over the alphabet
$T$ with a finite set $\sigma$ of states, a finite stack alphabet $\Gamma$, start state $q_0$
and initial stack symbol $Z_0$, and let $T_0$ be a finite set of letters. The triple grammar of
$M$ and $T_0$ is the context-free grammar over $T$ whose nonterminals are an initial
nonterminal $S$ and the triples $(p, \gamma, q)$ with $p, q \in \sigma$ and $\gamma \in \Gamma$.
Its productions are the start productions $S \to (q_0, Z_0, q)$ for every state $q$, and the
transition productions: for every state $p$, stack symbol $\gamma$, input $a$ that is
$\varepsilon$ or a letter of $T_0$, transition of $M$ from $p$ on $a$ popping $\gamma$ that
moves to a state $r$ and pushes $\gamma_1 \cdots \gamma_k$, and all states $s_1, \dots, s_k$,
writing $s_0 = r$, the production

$$(p, \gamma, s_k) \to a\,(s_0, \gamma_1, s_1)(s_1, \gamma_2, s_2) \cdots (s_{k-1}, \gamma_k, s_k)$$

where $a$ is omitted when it is $\varepsilon$ (for $k = 0$ this is $(p, \gamma, r) \to a$).

The nonterminal $(p, \gamma, q)$ is meant to derive the words that take $M$ from state $p$ with
stack $\gamma$ to state $q$ with empty stack; transitions on letters outside $T_0$ are not
used.

Formalized by `Cslib.Language.pdaGrammar`, a definition declared in [CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean, line 181](https://github.com/Deicyde/atlas-lean/blob/035e1808ca0c8983682b74153a02628d616d77ce/CSLibExt/Computability/Languages/ContextFree/PDAEquiv.lean#L181). [Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/TheoryOfComputation/context-free-languages/grammars-and-pushdown-automata/pushdown-automata-and-context-free-grammars/index.html#pda-grammar).

## Start productions of the triple grammar

Let $M$ be a pushdown automaton with a finite
set of states, a finite stack alphabet, start state $q_0$ and initial stack symbol $Z_0$, and let
$T_0$ be a finite set of input letters. For every state $q$, the triple grammar of $M$ and $T_0$
contains the production $S \to (q_0, Z_0, q)$, where $S$ is its initial nonterminal.

## Transition productions of the triple grammar

Let $M$ be a pushdown automaton with a
finite set of states and a finite stack alphabet, and let $T_0$ be a finite set of input
letters. Let $a$ be either $\varepsilon$ or a letter in $T_0$, and suppose that $M$ has a
transition from state $p$ on $a$ popping the stack symbol $\gamma$ that moves to state $r$ and
pushes $\gamma_1 \cdots \gamma_k$. Then for all states $s_1, \dots, s_k$, writing $s_0 = r$,
the triple grammar of $M$ and $T_0$ contains the production

$$(p, \gamma, s_k) \to a\,(s_0, \gamma_1, s_1)(s_1, \gamma_2, s_2) \cdots (s_{k-1}, \gamma_k, s_k)$$

where $a$ is omitted when it is $\varepsilon$.

## Productions of the triple grammar

Let $M$ be a pushdown automaton with a finite set of
states, a finite stack alphabet, start state $q_0$ and initial stack symbol $Z_0$, and let $T_0$
be a finite set of input letters. Every production of the triple grammar of $M$ and $T_0$ is of
one of two kinds. Either it is a start production $S \to (q_0, Z_0, q)$ for some state $q$,
where $S$ is the initial nonterminal; or there are states $p$ and $r$, a stack symbol $\gamma$,
an input $a$ that is a letter or $\varepsilon$, a transition of $M$ from $p$ on $a$ popping
$\gamma$ that moves to $r$ and pushes $\gamma_1 \cdots \gamma_k$, and states
$s_1, \dots, s_k$ such that, writing $s_0 = r$, the production is

$$(p, \gamma, s_k) \to a\,(s_0, \gamma_1, s_1)(s_1, \gamma_2, s_2) \cdots (s_{k-1}, \gamma_k, s_k)$$

where $a$ is omitted when it is $\varepsilon$ (for $k = 0$ the production is
$(p, \gamma, r) \to a$).

## The triple grammar generates the accepted language

Let $M$ be a pushdown automaton with
a finite set of states and a finite stack alphabet, and let $T_0$ be a finite set of input
letters such that $M$ has no transition, from any state and popping any stack symbol, that
consumes a letter outside $T_0$. Then the language generated by the triple grammar of $M$ and
$T_0$ equals the language accepted by $M$ by empty stack.

## Finite pushdown automata accept context-free languages

Let $M$ be a pushdown automaton
with a finite set of states and a finite stack alphabet, and suppose that there is a finite set
$T_0$ of input letters such that $M$ has no transition, from any state and popping any stack
symbol, that consumes a letter outside $T_0$. Then the language accepted by $M$ by empty stack
is context-free.

## Context-free languages are exactly the languages of finite pushdown automata

A language
$L$ over an alphabet $T$ is context-free if and only if there are a pushdown automaton $M$ over
$T$ with a finite set of states and a finite stack alphabet, and a finite set $T_0$ of input
letters such that $M$ has no transition, from any state and popping any stack symbol, that
consumes a letter outside $T_0$, for which the language accepted by $M$ by empty stack is $L$.

Here the alphabet, the states and the stack alphabet are types in the lowest universe.
