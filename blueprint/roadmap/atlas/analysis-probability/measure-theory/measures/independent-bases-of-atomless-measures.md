## Convex measure

A measure $\mu$ on a measurable space $X$ is convex (in Fréchet's sense,
"sans singularités") if $\mu(X) = 1$ and every measurable set $A$ with $\mu(A) > 0$ contains a
measurable subset $B$ with $0 < \mu(B) < \mu(A)$.

## Stochastically independent class of sets

Let $\mu$ be a measure on a measurable space
$X$. A class $B$ of subsets of $X$ is stochastically independent with respect to $\mu$ if for
every finite collection of distinct sets $A_1, \dots, A_n$ in $B$, including the empty one,
$\mu(A_1 \cap \dots \cap A_n) = \mu(A_1) \cdots \mu(A_n)$. The empty intersection is $X$ and the
empty product is $1$, so this forces $\mu(X) = 1$. The sets in $B$ need not be measurable; on
such sets $\mu$ is the outer measure.

## Base of a measure

Let $\mu$ be a measure on a measurable space $X$. A class $B$ of
subsets of $X$ is a base of $\mu$ if every set in $B$ is measurable, $B$ is stochastically
independent with respect to $\mu$, and every measurable set $A \subseteq X$ agrees up to a null
set with a set $C$ in the $\sigma$-algebra generated by $B$, that is, $\mu(A \triangle C) = 0$.

## The claim of Szpilrajn's Problem 191

The proposition, Szpilrajn's Problem 191 from the
Scottish Book in its original form, that for every measurable space $X$, every convex measure
$\mu$ on $X$ has a base, that is, some class $B$ of subsets of $X$ is a base of $\mu$.

## Szpilrajn's Problem 191 has a negative answer

The claim of Szpilrajn's Problem 191 is false:
not every convex measure possesses a base. That is, there are a measurable space $X$ and a convex
measure $\mu$ on $X$ such that no class of subsets of $X$ is a base of $\mu$.

A non-atomic (convex) measure has a base if and only if its
measure algebra is homogeneous, and the direct sum of Lebesgue measure
spaces gives a counterexample whose measure algebra is not homogeneous.
