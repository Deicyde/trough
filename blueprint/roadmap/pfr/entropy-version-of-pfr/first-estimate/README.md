# First estimate

We continue the assumptions from the preceding section.

Let $X_1, X_2, \tilde X_1, \tilde X_2$ be independent random variables, with $X_1,\tilde X_1$ copies of $X_1$ and $X_2,\tilde X_2$ copies of $X_2$. (This is possible thanks to [Existence of independent copies](../../entropic-ruzsa-calculus/part-01/independent-exist.md).)

We also define the quantity

$$
I_1 :=  I [X_1+X_2 : \tilde X_1 + X_2 | X_1+X_2+\tilde X_1+\tilde X_2].
$$
