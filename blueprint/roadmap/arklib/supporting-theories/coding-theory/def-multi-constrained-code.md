# Multi-constrained Code

The multi-constrained code for weights $\hat{w}_0,\ldots,\hat{w}_{t-1}$ and targets $\sigma_0,\ldots,\sigma_{t-1}$ consists of the codewords of $\mathrm{RS}[\mathbb{F},\mathcal{L},2^m]$ that satisfy every one of the $t$ weight constraints.
