# The congruence description of the Picard group

A ray class of the conductor maps to the
trivial Picard class exactly when it is the ray class of an ideal of `𝓞 K` generated by an element
of the order.

```lean
TauCeti.GlobalNumberFields.NumberFieldOrder.mem_ker_rayClassToPic.{u_1} {K : Type u_1} [Field K]
  [NumberField K] (O : TauCeti.GlobalNumberFields.NumberFieldOrder K)
  {c : TauCeti.GlobalNumberFields.RayClassGroup O.conductorModulus} :
  c ∈ O.rayClassToPic.ker ↔
    ∃ J,
      (TauCeti.GlobalNumberFields.idealClass O.conductorModulus) J = c ∧
        ∃ β ∈ O.toRingOfIntegers, ↑J = Ideal.span {β}
```
