# VonNeumannAlgebra.image_ofCLM_adjoin_eq_closure

The von Neumann algebra generated by `s` is the weak operator closure of the star algebra
generated by `s`.

```lean
VonNeumannAlgebra.image_ofCLM_adjoin_eq_closure.{u_1} {H : Type u_1} [NormedAddCommGroup H]
  [InnerProductSpace ℂ H] [CompleteSpace H] (s : Set (H →L[ℂ] H)) :
  ContinuousLinearMapWOT.ofCLM '' ↑(VonNeumannAlgebra.adjoin s) =
    closure (ContinuousLinearMapWOT.ofCLM '' ↑(StarAlgebra.adjoin ℂ s))
```
