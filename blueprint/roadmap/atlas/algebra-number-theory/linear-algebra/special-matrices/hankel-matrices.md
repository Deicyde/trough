# Hankel matrices

## Infinite Hankel matrix

For a sequence $s \colon \mathbb{N} \to \alpha$ with values in a
set $\alpha$, the infinite Hankel matrix generated by $s$ has rows and columns indexed by
$\mathbb{N}$ and $(i, j)$ entry $s_{i+j}$.

[Its page on the ATLAS site](https://deicyde.github.io/atlas-lean/roadmap/LinearAlgebra/special-matrices/hankel-matrices/index.html#hankel).

## Finite Hankel matrix

For $n \in \mathbb{N}$ and a sequence $s \colon \mathbb{N} \to \alpha$
with values in a set $\alpha$, the $n \times n$ Hankel matrix generated by $s$ has rows and columns
indexed by $\{0, \dots, n-1\}$ and $(i, j)$ entry $s_{i+j}$, where $i + j$ is the sum in
$\mathbb{N}$.
