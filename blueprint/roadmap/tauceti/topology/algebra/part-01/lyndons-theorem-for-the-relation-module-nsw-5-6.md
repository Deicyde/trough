# Lyndon's theorem for the relation module (NSW (5.6.6))

For a finite group `G` generated by
the family `g : ι → G`, the maximal abelian pro-`p` quotient `R^ab(p)` of the kernel `R` of
`lift g : F → G` is isomorphic to the relation module `relationModule ℤ_[p] G g`. The isomorphism
sends the class of `r ∈ R` to its Fox derivative
(`coe_abelianizationProPEquivRelationModule_ofMul`), it is `ℤ_p`-linear
(`abelianizationProPEquivRelationModule_padicPow`), and it is equivariant
(`abelianizationProPEquivRelationModule_smul`).

```lean
TauCeti.freeProfiniteGroup.abelianizationProPEquivRelationModule.{u} (p : ℕ) [Fact (Nat.Prime p)]
  {G : Type u} [Group G] [Finite G] [TopologicalSpace G] [DiscreteTopology G] {ι : Type u}
  {g : ι → G} (hg : Subgroup.closure (Set.range g) = ⊤) [DecidableEq ι] [Fintype ι] :
  Additive
      (TauCeti.abelianizationProP p (↑(TauCeti.freeProfiniteGroup ι).toProfinite.toTop)
        (↑(TauCeti.freeProfiniteGroup.lift g)).ker) ≃+
    ↥(TauCeti.MonoidAlgebra.relationModule ℤ_[p] G g)
```
