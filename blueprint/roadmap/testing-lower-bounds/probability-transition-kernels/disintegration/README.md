# Disintegration

A kernel $\eta : \mathcal X \times \mathcal Y \rightsquigarrow \mathcal Z$ is said to disintegrate a kernel $\kappa : \mathcal X \rightsquigarrow \mathcal Y \times \mathcal Z$ if $\kappa = \kappa_{Y} \otimes \eta$.
