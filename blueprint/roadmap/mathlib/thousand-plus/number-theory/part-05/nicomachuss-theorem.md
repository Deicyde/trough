# Nicomachus's theorem

Not yet in Mathlib: its 1000+ list names no declaration for this theorem.

Nicomachus's theorem states that the sum of the first n cubes is the square of the nth triangular number. This follows from Faulhaber's formula, formalized in mathlib as `sum_Ico_pow`, which provides a geeneral formula for sums of powers using Bernoulli numbers.
