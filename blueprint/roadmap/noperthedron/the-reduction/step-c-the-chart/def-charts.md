# charts

The *chart bases* are $B_0 = I$, $B_1 = \mathrm{diag}(1, -1, -1)$, $B_2 = \mathrm{diag}(-1, 1, -1)$, $B_3 = \mathrm{diag}(-1, -1, 1)$ (the Klein four-group) and $B_4 = \tau$. In chart $j$ the relative rotation with coordinates $r \in \operatorname{\mathbb{R}}^3$ is $Q_j(r) = B_j\, \mathrm{Cay}(r)$.
