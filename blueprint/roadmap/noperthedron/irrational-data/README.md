# Irrational data

The vertices of $\operatorname{\mathbf{P}}$ and the symmetries $g_k$ involve $\cos(2\pi k/15)$ and $\sin(2\pi k/15)$. The checker works with dyadic approximations of these numbers; this chapter bounds the approximation errors. Nothing else in the proof is irrational.

- [theta1](lem-theta1.md)
- [sin_wedge](lem-sin-wedge.md)
- [trig_table](lem-trig-table.md)
- [vertex_approx](lem-vertex-approx.md)
- [group_approx](lem-group-approx.md)

The pairing used in the blow-up of chart 4 is exact: $\tau$ maps true vertices to true vertices (Lemma [tau_pair](../the-reduction/step-b-the-relative-rotation/lem-tau-pair.md)), and the blow-up bracket $L$ is linear in $S$, so the same vertex error bound applies to it.
