# MeasureTheory.addEquivAddHaarChar\_smul\_integral\_comap

If $f:A\to\mathbb{R}$ is a Borel measurable function then $d_A(\phi)\int f(x)d\mu(x)=\int f(x)d\phi^*\mu(x)$.
