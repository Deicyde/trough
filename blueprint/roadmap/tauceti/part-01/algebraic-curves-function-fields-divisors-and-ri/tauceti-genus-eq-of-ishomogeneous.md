# TauCeti.genus_eq_of_isHomogeneous

**The genus of a smooth projective plane curve** (Fulton, *Algebraic Curves*, Section 8.3): let
`G ∈ k[X₀, X₁, X₂]` be homogeneous of degree `d`, with every point of `G = 0` over an algebraically
closed extension `K` of `k` nonsingular. Let `F / k` be generated by a transcendental `x` and an
element `y` with `G(x, y, 1) = 0`. Then `F` has genus `(d - 1)(d - 2) / 2`.

Nonsingularity makes `G(X₀, X₁, 1)` irreducible over `K`, so `k` is the exact constant field of
`F` (`TauCeti.isIntegrallyClosedIn_of_irreducible_map`).

```lean
TauCeti.genus_eq_of_isHomogeneous.{u_1, u_2, u_3} {k : Type u_1} [Field k] {F : Type u_2} [Field F]
  [Algebra k F] {K : Type u_3} [Field K] [IsAlgClosed K] [Algebra k K] {G : MvPolynomial (Fin 3) k}
  {d : ℕ} (hG : G.IsHomogeneous d)
  (hsm :
    ∀ (b : Fin 3 → K),
      b ≠ 0 →
        (MvPolynomial.aeval b) G = 0 → ∃ l, (MvPolynomial.aeval b) ((MvPolynomial.pderiv l) G) ≠ 0)
  {x y : F} (hx : Transcendental k x) (hgen : k⟮x, y⟯ = ⊤)
  (h : (MvPolynomial.aeval ![x, y, 1]) G = 0) : TauCeti.genus k F = (d - 1) * (d - 2) / 2
```
