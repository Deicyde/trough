# QHat.IsCoprime

If $N\in\mathbb{N}^+$ and $z\in\widehat{\mathbb{Z}}$ then we say that $N$ and $z$ are *coprime* if $z_N\in(\mathbb{Z}/N\mathbb{Z})^\times$. We write $z/N$ as notation for the element $\frac{1}{N}\otimes_tz$.
