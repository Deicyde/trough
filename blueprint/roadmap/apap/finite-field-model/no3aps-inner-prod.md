# no3aps_inner_prod

If $A\subseteq G$ has no non-trivial three-term arithmetic progressions and $G$ has odd order then

$$
\langle \mu_A\ast \mu_A,\mu_{2\cdot A}\rangle = 1/\left\lvert A\right\rvert^2.
$$
