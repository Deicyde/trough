# A counterexample to Scottish Book Problem 155

> A Lean proof that there are real Banach spaces X and Y and a bijection U from X to Y which preserves every pairwise distance on every closed ball of radius one quarter while failing to be a global isometry. This gives a counterexample to Scottish Book Problem 155.
