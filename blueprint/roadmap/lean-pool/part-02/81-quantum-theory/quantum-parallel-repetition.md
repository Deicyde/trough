# Quantum parallel repetition

> Proves a quantitative parallel-repetition theorem for finite two-player quantum games: whenever the entangled value is below one, the entangled values of parallel repetitions decay exponentially, with an explicit universal exponent in the game gap and answer-alphabet sizes.
