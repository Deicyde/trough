> **Stacks 0GSS.** Let `f` be a nonzerodivisor and let `M` and `N` be bounded complexes of
> finite free modules representing isomorphic objects of the derived category. If `m` and `n`
> are nonnegative integers such that
> `m + ∑_{j ≥ i} (-1)^(j-i) rank(Mʲ) = n + ∑_{j ≥ i} (-1)^(j-i) rank(Nʲ)`,
> then `fᵐ I_i(M, f) = fⁿ I_i(N, f)` as ideals.

```lean
public theorem pow_mul_idealI_eq_of_derived_iso
    {A : Type*} [CommRing A] (f : A) (hf : f ∈ nonZeroDivisors A)
    (M N : BoundedComplex A) (i : ℤ) (m n : ℕ)
    (hMN : Nonempty ((DerivedCategory.Q).obj M.toCochainComplex ≅
      (DerivedCategory.Q).obj N.toCochainComplex))
    (hEuler : (m : ℤ) + M.tailEulerCharacteristic i =
      (n : ℤ) + N.tailEulerCharacteristic i) :
    Ideal.span {f ^ m} * idealI M f i = Ideal.span {f ^ n} * idealI N f i
```

> **Stacks Tag 0GSU (Lemma 15.98.3).** Let `φ : A → B` be a ring map, `f` a
> nonzerodivisor in `A`, `C = M^•` a bounded complex of finite free `A`-modules,
> and assume `g = φ(f)` is a nonzerodivisor in `B`. Then for every `i ∈ ℤ`, the
> extension of `I_i(M^•, f)` along `φ` equals `I_i(M^• ⊗_A B, g)`.

```lean
theorem map_idealI_eq_idealI_baseChange {A B : Type*} [CommRing A] [CommRing B] (φ : A →+* B)
    (f : A) (C : BoundedComplex A) (i : ℤ) :
    Ideal.map φ (idealI C f i) = idealI (C.baseChange φ) (φ f) i
```

## Tag 0F7W, a lemma

[Tag 0F7W](https://stacks.math.columbia.edu/tag/0F7W) in the Stacks Project.

**`EtaPow.LocallyFree.etaTerm_finite_projective_and_split_of_idealI_isPrincipal`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/Homology/Eta/Perfect/LocallyFree.lean, line 443](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/Homology/Eta/Perfect/LocallyFree.lean#L443).

> **Stacks 0F7W.** Let `f` be a nonzerodivisor and let `C` be a bounded complex of finite
> free modules. If the ideal generated by the maximal minors of `(f, dⁱ)` is principal, then the
> degree-`i` eta term is finite locally free of rank `rank C i`. Its natural map `x ↦ (x, dⁱx)`
> into `fⁱ Cⁱ × fⁱ⁺¹ Cⁱ⁺¹` admits a linear retraction, and hence includes it as a direct
> summand.

```lean
public theorem etaTerm_finite_projective_and_split_of_idealI_isPrincipal
    {A : Type*} [CommRing A] (C : BoundedComplex A) (f : A) (hf : IsRegular f) (i : ℤ)
    (hI : (idealI C f i).IsPrincipal) :
    let d := (C.d i).mulVecLin
    let E := fetaTerm f d i
    let P := fpowSub f (Fin (C.rank i) → A) i
    let Q := fpowSub f (Fin (C.rank (i + 1)) → A) (i + 1)
    let inclusion : E →ₗ[A] P × Q := LinearMap.prod
      (LinearMap.codRestrict P E.subtype (fun x => x.2.1))
      (LinearMap.codRestrict Q ((fLoc f d).comp E.subtype) (fun x => x.2.2))
    (∃ hfin : Module.Finite A E,
      letI := hfin
      ∃ hproj : Module.Projective A E,
        letI := hproj
        Module.rankAtStalk (R := A) E = fun _ => C.rank i) ∧
      ∃ retraction : P × Q →ₗ[A] E,
        retraction.comp inclusion = LinearMap.id
```

**`Stacks.Eta.LocallyFreeTerms.eta_baseChange_of_idealI_isPrincipal`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/Homology/Eta/Perfect/LocallyFree.lean, line 702](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/Homology/Eta/Perfect/LocallyFree.lean#L702).

> **Stacks 0F7X.** Let `A → B` be a ring map, let `f` be a nonzerodivisor of `A` whose image
> is a nonzerodivisor of `B`, and let `C` be a bounded complex of finite free `A`-modules. If
> every determinantal ideal `Iᵢ(C, f)` is principal, then base change of the eta construction
> agrees in every degree with the eta construction of the base-changed complex. The equality
> takes place inside the localization of the finite free `B`-module after applying the canonical
> localization--base-change and finite-free base-change identifications.

```lean
public theorem eta_baseChange_of_idealI_isPrincipal
    {A B : Type*} [CommRing A] [CommRing B] [Algebra A B]
    (C : BoundedComplex A) (f : A) (hf : IsRegular f)
    (hg : IsRegular (algebraMap A B f))
    (hI : ∀ i : ℤ, (idealI C f i).IsPrincipal) :
    ∀ i : ℤ,
      let freeBaseChange := TensorProduct.piScalarRight A B B (Fin (C.rank i))
      let ambientMap :=
        ((LocalizedModule.map (Submonoid.powers (algebraMap A B f))
            freeBaseChange.toLinearMap).restrictScalars B).comp
          (Stacks.Eta.BaseChange.psiEquiv f (Fin (C.rank i) → A)).toLinearMap
      Submodule.map ambientMap
          (Submodule.baseChange B (fetaTerm f (C.d i).mulVecLin i)) =
        fetaTerm (algebraMap A B f)
          ((C.baseChange (algebraMap A B)).d i).mulVecLin i
```

> **Theorem (Stacks Tag 0F80, Lemma 15.98.7).**
> Let `A` be a commutative ring, let `M`, `N₁`, `N₂` be finite projective
> `A`-modules, and let `s : M → N₁ × N₂` be a split injection. Then there exists
> a finitely generated ideal `J ⊆ A` such that, for every commutative ring `B`
> and every ring map `A → B`, the map `A → B` factors through `A/J`
> (`J ≤ ker(A → B)`) if and only if the base-changed map `s_B` identifies `M_B`
> with a direct sum of submodules of `N_{1,B} ⊕ N_{2,B}` (Definition 4).

```lean
theorem main_theorem_0f80
    [Module.Finite A M] [Module.Projective A M]
    [Module.Finite A N₁] [Module.Projective A N₁]
    [Module.Finite A N₂] [Module.Projective A N₂]
    (s : M →ₗ[A] (N₁ × N₂)) (hs : IsSplitInjective s) :
    ∃ J : Ideal A, J.FG ∧
      ∀ (B : Type v) [CommRing B] [Algebra A B],
        (J ≤ RingHom.ker (algebraMap A B)) ↔ IdentifiesDirectSum s B
```

> **Stacks 0F81.** The sum of the degreewise direct-sum obstruction ideals is finitely
> generated.  Its quotient is a finitely presented closed immersion, the ideal vanishes at primes
> where cycles lift (equivalently, where the localized Bockstein operators vanish), primes where
> all localized cohomology modules are free belong to this locus, and after quotienting by the
> obstruction ideal all cohomology modules of the eta complex are finite projective.

```lean
public theorem exists_fg_obstructionIdeal_with_finiteProjective_etaHomology
    {A : Type u} [CommRing A] (C : BoundedComplex A) (f : A) (hf : IsRegular f)
    (hI : ∀ i : ℤ, (idealI C f i).IsPrincipal) :
    let R := A ⧸ Ideal.span {f}
    let M := associatedComplex C
    ∃ (Jᵢ : ℤ → Ideal R) (J : Ideal R),
      (∀ i, (Jᵢ i).FG) ∧
      (∀ i : ℤ, ∀ (B : Type v) [CommRing B] [Algebra R B],
        Jᵢ i ≤ RingHom.ker (algebraMap R B) ↔
          Stacks.SplitInjectionDirectSum.IdentifiesDirectSum (etaReductionMap C f i) B) ∧
      (∀ i, C.rank i = 0 → C.rank (i + 1) = 0 → Jᵢ i = ⊥) ∧
      (J = ⨆ i, Jᵢ i) ∧
      J.FG ∧
      Function.Surjective (Ideal.Quotient.mk J) ∧
      RingHom.FinitePresentation (Ideal.Quotient.mk J) ∧
      ({p : Ideal A | ∃ hp : p.IsPrime, CyclesLiftAt C f p hp} =
        {p : Ideal A | ∃ hp : p.IsPrime, BocksteinVanishesAt C f p hp}) ∧
      (∀ (p : Ideal A) [hp : p.IsPrime], CyclesLiftAt C f p hp →
        Subsingleton (LocalizedModule p.primeCompl J)) ∧
      (∀ (p : Ideal A) [hp : p.IsPrime], f ∈ p →
        (∀ i : ℤ, Module.Free (Localization.AtPrime p)
          ((associatedComplex (C.baseChange
            (algebraMap A (Localization.AtPrime p)))).homology i)) →
        CyclesLiftAt C f p hp) ∧
      let S := R ⧸ J
      let φ : A →+* S := (Ideal.Quotient.mk J).comp (Ideal.Quotient.mk (Ideal.span {f}))
      let ηM := ((ModuleCat.extendScalars φ).mapHomologicalComplex
        (ComplexShape.up ℤ)).obj (EtaComplex.etaObject f M)
      ∀ i : ℤ,
        ∃ hfin : Module.Finite S (ηM.homology i),
          letI := hfin
          Module.Projective S (ηM.homology i)
```
