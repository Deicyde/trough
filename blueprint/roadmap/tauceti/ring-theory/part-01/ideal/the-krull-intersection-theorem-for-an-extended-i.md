# The Krull intersection theorem for an extended ideal

If `R` is Noetherian and `A` is a
finite `R`-module, an element of every power of the two-sided ideal of `A` generated by `I` is
fixed by multiplication by some scalar in `I`.

```lean
Ideal.mem_iInf_map_algebraMap_pow_iff.{u_1, u_2} {R : Type u_1} {A : Type u_2} [CommRing R] [Ring A]
  [Algebra R A] [IsNoetherianRing R] [Module.Finite R A] (I : Ideal R) (x : A) :
  x ∈ ⨅ n, Ideal.map (algebraMap R A) I ^ n ↔ ∃ r ∈ I, (algebraMap R A) r * x = x
```
