# pre-Brownian process

Let $\Omega = \mathbb{R}^{\mathbb{R}_+}$ and consider the probability space $(\Omega, P_B)$ (where $P_B$ is the measure defined in Definition [gaussianLimit](../../projective-family-of-the-brownian-motion/projective-family-of-gaussian-measures/def-gaussianlimit.md)). The identity on that space is a function $\Omega \to \mathbb{R}_+ \to \mathbb{R}$. We reorder the arguments to define a stochastic process $X : \mathbb{R}_+ \to \Omega \to \mathbb{R}$, which we call the pre-Brownian process.
