# Noether's degree bound

If a family `x`, finite or not, generates a commutative algebra `A`
over a `ℚ`-algebra `R`, then the invariants of a finite group `G` acting on `A` are generated by the
orbit sums `∑_{g ∈ G} g • x^d` of the monomials `x^d` of total degree at most `|G|`.

```lean
TauCeti.FixedPoints.subalgebra_eq_adjoin_sum_smul_prod_pow.{u_1, u_2, u_3, u_4} {R : Type u_1}
  {A : Type u_2} {G : Type u_3} [CommRing R] [Algebra ℚ R] [CommRing A] [Algebra R A] [Fintype G]
  {ι : Type u_4} [Group G] [MulSemiringAction G A] [SMulCommClass G R A] (x : ι → A)
  (hx : Algebra.adjoin R (Set.range x) = ⊤) :
  FixedPoints.subalgebra R A G =
    Algebra.adjoin R
      ((fun d => ∑ g, g • d.prod fun i n => x i ^ n) '' {d | Finsupp.degree d ≤ Fintype.card G})
```
