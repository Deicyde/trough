> Every affine open has a finite standard open cover each of whose members is also a standard
> open in a member of a given affine open cover of the ambient scheme.

```lean
theorem exists_isStandardOpenCover_basicOpen_eq_of_iSup_eq_top
    (X : Scheme.{u}) {ι : Type v} (U : ι → X.Opens)
    (hU : ∀ i, IsAffineOpen (U i)) (hUcover : ⨆ i, U i = ⊤)
    (V : X.Opens) (hV : IsAffineOpen V) :
    ∃ (n : ℕ) (f : Fin n → Γ(X, V)) (i : Fin n → ι)
      (g : ∀ j, Γ(X, U (i j))),
      PrimeSpectrum.IsStandardOpenCoverOfSpectrum f ∧
        (⨆ j, X.basicOpen (f j)) = V ∧
        ∀ j, X.basicOpen (f j) = X.basicOpen (g j)
```

The attribute's comment: “equivalence of (2) and (3)”.

> A presheaf on the affine-open basis is a sheaf exactly when its section set on the
> empty open is a singleton and compatible sections glue uniquely across every standard
> two-open cover of an affine open.

```lean
theorem isSheafOnAffineBasis_iff_standardPairs (X : Scheme.{u})
    (F : PresheafOnBasis X.affineOpens) :
    IsSheafOnBasis X.affineOpens F ↔
      ((∃! _s : F.obj (op (affineBasisOpen X ⟨⊥, isAffineOpen_bot X⟩)), True) ∧
      ∀ (U : X.affineOpens) (f g : Γ(X, U.1))
        (_hcov : U.1 = X.basicOpen f ⊔ X.basicOpen g)
        (s : F.obj (op (affineBasisOpen X (X.affineBasicOpen f))))
        (t : F.obj (op (affineBasisOpen X (X.affineBasicOpen g)))),
        (F.restrictMap X.affineOpens
            (show (affineBasisOpen X (X.affineBasicOpen (f * g))).obj ≤
                (affineBasisOpen X (X.affineBasicOpen f)).obj by
              change X.basicOpen (f * g) ≤ X.basicOpen f
              rw [X.basicOpen_mul]
              exact inf_le_left) s =
          F.restrictMap X.affineOpens
            (show (affineBasisOpen X (X.affineBasicOpen (f * g))).obj ≤
                (affineBasisOpen X (X.affineBasicOpen g)).obj by
              change X.basicOpen (f * g) ≤ X.basicOpen g
              rw [X.basicOpen_mul]
              exact inf_le_right) t) ↔
        ∃! r : F.obj (op (affineBasisOpen X U)),
          (F.restrictMap X.affineOpens (by exact (X.affineBasicOpen_le f)) r = s) ∧
          (F.restrictMap X.affineOpens (by exact (X.affineBasicOpen_le g)) r = t))
```

The attribute's comment: “valuation ring with the specified prime spectrum”.

> There is a valuation ring whose spectrum is a countable strictly increasing chain
> of prime ideals, with one further maximal ideal above all of them.

```lean
theorem exists_valuationRing_with_spectrum_chain :
    ∃ (R : Type u) (ring : CommRing R),
      letI : CommRing R := ring
      ∃ (domain : IsDomain R),
        letI : IsDomain R := domain
        ∃ (localRing : IsLocalRing R),
          letI : IsLocalRing R := localRing
          IsValuationRing R ∧
            ∃ p : ℕ → PrimeSpectrum R,
              ((p 0).asIdeal = ⊥) ∧
                (∀ n, (p n).asIdeal < (p (n + 1)).asIdeal) ∧
                (∀ q : PrimeSpectrum R,
                  (q = IsLocalRing.closedPoint R) ∨ (∃ n, q = p n))
```
