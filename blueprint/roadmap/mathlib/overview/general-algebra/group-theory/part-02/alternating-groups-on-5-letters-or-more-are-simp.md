# Alternating groups on 5 letters or more are simple

When `α` has at least 5 elements, then `alternatingGroup α` is a simple group.

```lean
alternatingGroup.isSimpleGroup.{u_1} {α : Type u_1} [DecidableEq α] [Fintype α]
  (hα : 5 ≤ Nat.card α) : IsSimpleGroup ↥(alternatingGroup α)
```
