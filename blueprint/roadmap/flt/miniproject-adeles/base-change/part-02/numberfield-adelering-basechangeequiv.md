# NumberField.AdeleRing.baseChangeEquiv

If $K\to L$ is a ring homomorphism between two number fields then there is a natural isomorphism (both topological and algebraic) $L\otimes_K\mathbb{A}_K\cong\mathbb{A}_L$.
