# WeierstrassCurve.ker_aeval_c₄_c₆_Δ

For any Weierstrass curve `W` whose invariants `c₄` and `c₆` are algebraically independent over
`ℤ`, the kernel of the evaluation `ℤ[C₄, C₆, D] → R` at `W.c₄`, `W.c₆`, `W.Δ` is generated by
`C₄³ - C₆² - 1728D`.

```lean
WeierstrassCurve.ker_aeval_c₄_c₆_Δ.{u_1} {R : Type u_1} [CommRing R] [Algebra ℤ R]
  (W : WeierstrassCurve R) (hind : AlgebraicIndependent ℤ ![W.c₄, W.c₆]) :
  RingHom.ker (MvPolynomial.aeval ![W.c₄, W.c₆, W.Δ]) =
    Ideal.span {MvPolynomial.X 0 ^ 3 - MvPolynomial.X 1 ^ 2 - 1728 * MvPolynomial.X 2}
```
