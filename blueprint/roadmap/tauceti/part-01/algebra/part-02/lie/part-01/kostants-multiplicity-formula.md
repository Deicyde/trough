# Kostant's multiplicity formula

The multiplicity of the weight `mu` in a finite-dimensional
module generated by a highest weight vector of weight `lam` is the alternating sum
`∑_{w ∈ W} sgn(w) P(w(lam + ρ) - (mu + ρ))` of values of the Kostant partition function.

```lean
TauCeti.finrank_weightSpace_eq_kostantMultiplicity.{u, v, w} {K : Type u} {L : Type v} [Field K]
  [CharZero K] [IsAlgClosed K] [LieRing L] [LieAlgebra K L] [LieAlgebra.IsKilling K L]
  [FiniteDimensional K L] {H : LieSubalgebra K L} [H.IsCartanSubalgebra] {M : Type w}
  [AddCommGroup M] [_root_.Module K M] [LieRingModule L M] [LieModule K L M] [FiniteDimensional K M]
  [Fintype ↥(LieAlgebra.IsKilling.rootSystem H).weylGroup]
  {b : (LieAlgebra.IsKilling.rootSystem H).Base} {lam : Module.Dual K ↥H} {v : M}
  (hv : TauCeti.IsHighestWeightVector b lam v) (hgen : LieSubmodule.lieSpan K L {v} = ⊤)
  (mu : Module.Dual K ↥H) :
  ↑(Module.finrank K ↥(LieModule.weightSpace M ⇑mu)) =
    (LieAlgebra.IsKilling.rootSystem H).kostantMultiplicity b lam mu
```
