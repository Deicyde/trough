# Reed-Solomon Code

For an injective map $\mathcal{L}\hookrightarrow\mathbb{F}$ and $d\in\mathbb{N}$, $\mathrm{RS}[\mathbb{F},\mathcal{L},d]$ is the image of the polynomials of degree less than $d$ under evaluation on $\mathcal{L}$.
