# JBlaschke

Let $0 < r < R<1$. If $f:\mathbb{C}\to\mathbb{C}$ is a function analytic on neighborhoods of points in $\overline{\mathbb{D}_1}$ with $f(0)=1$, define $L_f(z)=J_{B_f}(z)$ where $J$ is from Theorem [LogOfAnalyticFunction](logofanalyticfunction.md) and $B_f$ is from Definition [BlaschkeB](blaschkeb.md).
