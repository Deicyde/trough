# Austin implications

We now broaden the discussion to consider not only the implications to [E2](https://teorth.github.io/equational_theories/implications/?2) $({x = y})$, but also between any pair of equational laws. Many implications for finite magmas rely on the fact that if $f, g:X \to X$ are functions on a finite set $X$, then $f \circ g = I$ if and only if $g \circ f = I$.
