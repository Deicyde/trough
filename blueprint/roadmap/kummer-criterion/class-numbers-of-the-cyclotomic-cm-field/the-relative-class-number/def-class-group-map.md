# class-group-map

The inclusion $\mathcal O_{K^+}\subseteq\mathcal O_K$ induces, by extension of fractional ideals, the class-group homomorphism

$$
\mathrm{Cl}(\mathcal O_{K^+})\longrightarrow \mathrm{Cl}(\mathcal O_K).
$$
