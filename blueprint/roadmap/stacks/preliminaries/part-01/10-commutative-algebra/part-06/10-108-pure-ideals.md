**`Ideal.pure_tfae`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/Ideal/Pure.lean, line 427](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/Ideal/Pure.lean#L427).

> **Characterizations of pure ideals.** For an ideal `I` of a commutative ring `R` the following
> are equivalent: (1) `I` is pure, i.e. `R ⧸ I` is flat over `R`; (2) `I ⊓ J = I * J` for every
> ideal `J`; (3) the same for every finitely generated `J`; (4) the same for every principal `J`;
> (5) every `x ∈ I` satisfies `x = x * y` for some `y ∈ I`; (6) finitely many elements of `I` admit
> a common such `y`; (7) `I` localizes to `⊥` or to `⊤` at every prime; (8) the support of `I` is the
> complement of `V(I)`; (9) `I` is the kernel of `R → (1 + I)⁻¹R`; (10) `R ⧸ I` is `R`-algebra
> isomorphic to a localization of `R`; (11) `R ⧸ I` is `R`-algebra isomorphic to `(1 + I)⁻¹R`.

```lean
public theorem Ideal.pure_tfae {R : Type*} [CommRing R] (I : Ideal R) :
    List.TFAE
      [I.Pure,
       ∀ J : Ideal R, I ⊓ J = I * J,
       ∀ J : Ideal R, J.FG → I ⊓ J = I * J,
       ∀ x : R, I ⊓ Ideal.span {x} = I * Ideal.span {x},
       ∀ x ∈ I, ∃ y ∈ I, x = x * y,
       ∀ s : Finset R, (s : Set R) ⊆ I → ∃ y ∈ I, ∀ x ∈ s, x = x * y,
       ∀ p : PrimeSpectrum R,
         I.map (algebraMap R (Localization.AtPrime p.asIdeal)) = ⊥ ∨
           I.map (algebraMap R (Localization.AtPrime p.asIdeal)) = ⊤,
       Module.support R I = (PrimeSpectrum.zeroLocus (I : Set R))ᶜ,
       RingHom.ker (algebraMap R
         (Localization (Submonoid.comap (Ideal.Quotient.mk I).toMonoidHom ⊥))) = I,
       ∃ S : Submonoid R, Nonempty ((R ⧸ I) ≃ₐ[R] Localization S),
       Nonempty ((R ⧸ I) ≃ₐ[R]
         Localization (Submonoid.comap (Ideal.Quotient.mk I).toMonoidHom ⊥))]
```

## Tag 04PU, a lemma

[Tag 04PU](https://stacks.math.columbia.edu/tag/04PU) in the Stacks Project.

**`bijOn_zeroLocus_isPure`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/Ideal/Pure.lean, line 868](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/Ideal/Pure.lean#L868).

> (Stacks 04PU) The map `I ↦ V(I)` is a bijection between the set of pure
> ideals of `R` and the set of closed subsets of `Spec(R)` that are closed under
> generalizations. This packages the three claims above as a single `Set.BijOn`
> statement.

```lean
theorem bijOn_zeroLocus_isPure {R : Type*} [CommRing R] :
    Set.BijOn (fun I : Ideal R => zeroLocus (I : Set R))
      {I : Ideal R | I.IsPure}
      {Z : Set (PrimeSpectrum R) | IsClosed Z ∧ StableUnderGeneralization Z}
```

## Tag 05KK, a lemma

[Tag 05KK](https://stacks.math.columbia.edu/tag/05KK) in the Stacks Project.

**`pure_fg_tfae`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/Ideal/Pure.lean, line 938](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/Ideal/Pure.lean#L938).

> For an ideal `I` of a commutative ring `R`, the following are equivalent: `I` is pure and
> finitely generated; `I` is generated by an idempotent; `I` is pure with open vanishing locus;
> `R ⧸ I` is a projective `R`-module.

```lean
theorem pure_fg_tfae (R : Type*) [CommRing R] (I : Ideal R) :
    [ -- (1) `I` is pure and finitely generated
      I.IsPure ∧ I.FG,
      -- (2) `I` is generated by an idempotent
      ∃ e : R, e ^ 2 = e ∧ I = Ideal.span {e},
      -- (3) `I` is pure and `V(I)` is open in `Spec(R)`
      I.IsPure ∧ IsOpen (PrimeSpectrum.zeroLocus (I : Set R)),
      -- (4) `R/I` is a projective `R`-module
      Module.Projective R (R ⧸ I) ].TFAE
```

## Tag 052U, a lemma

[Tag 052U](https://stacks.math.columbia.edu/tag/052U) in the Stacks Project.

The attribute's comment: “Finite local freeness is spelled `Module.Projective`; see the module docstring.”.

> Let `R` be a commutative ring. Every closed subset of `Spec(R)` that is stable under
> generalization is open if and only if every finite flat `R`-module is finite locally free, the
> latter being spelled "finite projective" (Stacks 00NX (2) `⇔` (7)).

```lean
public theorem forall_isOpen_of_isClosed_of_stableUnderGeneralization_iff_forall_projective
    (R : Type u) [CommRing R] :
    (∀ Z : Set (PrimeSpectrum R), IsClosed Z → StableUnderGeneralization Z → IsOpen Z) ↔
      ∀ (M : Type u) [AddCommGroup M] [Module R M] [Module.Finite R M] [Module.Flat R M],
        Module.Projective R M
```
