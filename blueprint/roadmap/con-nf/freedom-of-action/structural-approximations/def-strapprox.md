# StrApprox

For a type index $\beta$, a *$\beta$-approximation* is a $\beta$-tree of base approximations. We define the partial order on $\beta$-approximations branchwise. We define an action of $\beta$-approximations $\psi$ on $\beta$-supports $S$ by $(\psi(S))_A = \psi_A(S_A)$.
