# Happel's theorem

The stable category of a Frobenius exact category, with the shift
generated by stable suspension and the triangles generated by conflations, is triangulated.

```lean
TauCeti.ExactStructure.IsFrobenius.stableIsTriangulated.{v, u} {C : Type u}
  [CategoryTheory.Category.{v, u} C] [CategoryTheory.Preadditive C]
  [CategoryTheory.Limits.HasZeroObject C] [CategoryTheory.Limits.HasBinaryBiproducts C]
  {E : TauCeti.ExactStructure C} (hE : E.IsFrobenius) :
  CategoryTheory.IsTriangulated E.ProjectiveStableCategory
```
