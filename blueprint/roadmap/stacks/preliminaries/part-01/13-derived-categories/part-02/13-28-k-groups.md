The attribute's comment: “stated for a pretriangulated category: the free abelian group and its relations use only the class of distinguished triangles, never the octahedron axiom”. References: SGA 6 I (6.3), “triangulated case”; SGA 6 IV (1.1), “the group k(C)”.

> The **zeroth `K`-group** `K₀(C)` of a pretriangulated category `C`: the free abelian group
> on the objects of `C` modulo the subgroup generated by the elements `[Y] - [X] - [Z]`, one for
> each distinguished triangle `X ⟶ Y ⟶ Z ⟶ X⟦1⟧` of `C`. The class of an object `X` is
> `QuotientAddGroup.mk (FreeAbelianGroup.of X)`.

```lean
abbrev K0 (C : Type u) [Category.{v} C] [HasZeroObject C] [HasShift C ℤ] [Preadditive C]
    [∀ n : ℤ, (CategoryTheory.shiftFunctor C n).Additive] [Pretriangulated C] : Type u
```

## Tag 0FCP, a lemma

[Tag 0FCP](https://stacks.math.columbia.edu/tag/0FCP) in the Stacks Project.

**`DerivedCategory.Bounded.exists_addEquiv_K0`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/Algebra/Homology/DerivedCategory/KGroup.lean, line 658](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/Algebra/Homology/DerivedCategory/KGroup.lean#L658).

> **The zeroth `K`-group of `D^b(A)` is that of `A`**: for an abelian category `A` there is a
> group isomorphism from the zeroth `K`-group of `A` (the free abelian group on the objects of `A`
> modulo `[X₂] - [X₁] - [X₃]` for every short exact sequence `0 ⟶ X₁ ⟶ X₂ ⟶ X₃ ⟶ 0`) to the zeroth
> `K`-group of the bounded derived category of `A`, sending the class of `X` to the class of `X`
> viewed as a complex in degree `0`. Such an isomorphism is unique, since the classes of objects
> generate `K₀(A)`.

```lean
theorem DerivedCategory.Bounded.exists_addEquiv_K0 {A : Type u} [Category.{v} A]
    [Abelian A] [HasDerivedCategory.{w} A] :
    ∃ e : KZero A ≃+ Pretriangulated.K0 (DerivedCategory.Bounded A),
      ∀ X : A, e (KZero.mk A X) =
        QuotientAddGroup.mk (FreeAbelianGroup.of
          (⟨(DerivedCategory.singleFunctor A 0).obj X,
            ⟨⟨0, inferInstance⟩, ⟨0, inferInstance⟩⟩⟩ : DerivedCategory.Bounded A))
```

> **Stacks Lemma 13.28.4 (tag `0FCR`).** Let `H : D → A` be a homological
> functor from a triangulated category to an abelian category, such that for every
> object `X` of `D` only finitely many of the objects `H(X[i])`, `i ∈ ℤ`, are
> nonzero. Then there is a well-defined group homomorphism `K_0(D) → K_0(A)`
> characterized by `[X] ↦ ∑_{i ∈ ℤ} (-1)^i [H(X[i])]`.

```lean
theorem K0_homomorphism_of_homological (H : D ⥤ A) (hH : H.IsHomological)
    (hfin : ∀ X : D, {i : ℤ | ¬ IsZero (H.obj ((shiftFunctor D i).obj X))}.Finite) :
    ∃ φ : K0 D →+ KZero A, ∀ X : D, φ (K0.cls X) = eulerClass D A H X
```

> **The zeroth `K`-group of `D^b_B(A)` is that of `B`**: for a weak Serre subcategory `B` of an
> abelian category `A` there is a group isomorphism from the zeroth `K`-group of `B` (the free
> abelian group on the objects of `B` modulo `[X₂] - [X₁] - [X₃]` for every short exact sequence
> `0 ⟶ X₁ ⟶ X₂ ⟶ X₃ ⟶ 0` of `B`) to the zeroth `K`-group of the triangulated subcategory
> `D^b_B(A) ⊆ D(A)` of bounded objects with all cohomology objects in `B`, sending the class of `X`
> to the class of `X` viewed as a complex in degree `0`. Such an isomorphism is unique, since the
> classes of objects generate `K₀(B)`.

```lean
theorem DerivedCategory.exists_addEquiv_K0_of_isWeakSerreClass
    {A : Type u} [Category.{v} A] [Abelian A] [HasDerivedCategory.{w} A]
    (B : ObjectProperty A) [B.IsWeakSerreClass]
    {P : ObjectProperty (DerivedCategory A)}
    (hP : P = (DerivedCategory.TStructure.t (C := A)).bounded ⊓
      fun X ↦ ∀ n : ℤ, B ((DerivedCategory.homologyFunctor A n).obj X))
    [P.IsTriangulated] :
    ∃ e : KZero B.FullSubcategory ≃+ Pretriangulated.K0 P.FullSubcategory,
      (∀ X : B.FullSubcategory, ∃ Y : P.FullSubcategory,
          Nonempty (P.ι.obj Y ≅ (DerivedCategory.singleFunctor A 0).obj (B.ι.obj X))) ∧
        ∀ (X : B.FullSubcategory) (Y : P.FullSubcategory),
          (P.ι.obj Y ≅ (DerivedCategory.singleFunctor A 0).obj (B.ι.obj X)) →
            e (KZero.mk B.FullSubcategory X) =
```

## Tag 0FCT, a lemma

[Tag 0FCT](https://stacks.math.columbia.edu/tag/0FCT) in the Stacks Project.

**`CategoryTheory.Pretriangulated.K0.exists_bilinear_of_bifunctor`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/CategoryTheory/Triangulated/KGroup/Basic.lean, line 661](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/CategoryTheory/Triangulated/KGroup/Basic.lean#L661).

> **Stacks Tag 0FCT (Lemma 13.28.6).**
> Let `D`, `D'`, `D''` be triangulated categories and let `F : D ⥤ (D' ⥤ D'')` be a
> (curried) bifunctor `⊗ : D × D' → D''`.  Assume that
>
> 1. for each object `X` of `D`, the partial functor `X ⊗ - = F.obj X : D' → D''`
>    is an exact functor of triangulated categories (it admits a shift-commutation
>    structure `csR X` and is triangulated for it), and
> 2. for each object `X'` of `D'`, the partial functor `- ⊗ X' = F.flip.obj X' : D → D''`
>    is an exact functor of triangulated categories (it admits a shift-commutation
>    structure `csL X'` and is triangulated for it).
>
> Then `⊗` induces a bilinear map `K_0(D) × K_0(D') → K_0(D'')` sending the pair of
> classes `([X], [X'])` to `[X ⊗ X']`.
>
> The bilinear map is encoded as `b : K0 D →+ (K0 D' →+ K0 D'')`: additivity of `b`
> in the second variable is built into the `AddMonoidHom` codomain, and additivity
> in the first variable is built into `b` itself being an `AddMonoidHom`.

```lean
theorem exists_bilinear_of_bifunctor
    (F : D ⥤ (D' ⥤ D''))
    (csR : ∀ X : D, (F.obj X).CommShift ℤ)
    (hR : ∀ X : D, letI := csR X; (F.obj X).IsTriangulated)
    (csL : ∀ X' : D', (F.flip.obj X').CommShift ℤ)
    (hL : ∀ X' : D', letI := csL X'; (F.flip.obj X').IsTriangulated) :
    ∃ b : K0 D →+ (K0 D' →+ K0 D''),
      ∀ (X : D) (X' : D'), b (cls X) (cls X') = cls ((F.obj X).obj X')
```
