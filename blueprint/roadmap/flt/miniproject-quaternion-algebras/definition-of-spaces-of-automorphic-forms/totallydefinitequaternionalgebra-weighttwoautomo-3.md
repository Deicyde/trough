# TotallyDefiniteQuaternionAlgebra.WeightTwoAutomorphicForm.module

If $R$ is a commutative ring then pointwise scalar multiplication $(r\cdot f)(g):= r\cdot(f(g))$ makes $S^D(R)$ into an $R$-module.
