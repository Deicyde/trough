Thus $(u,v)$ records the direction from which the outer polyhedron is viewed: $(0,0)$ gives the positive $z$-axis, and $u^2+v^2=1$ gives horizontal views. The rotation $s(u,v)$ chooses a particular orientation of the shadow in the screen; any other rotation with the same view differs only by a rotation of the screen (Lemma [Same view](../../the-reduction/moves-that-preserve-rupert-pairs/lem-outer-unique.md)).
