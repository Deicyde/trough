**`exists_separating_exponents`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/NoetherNormalization/Basic.lean, line 232](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/NoetherNormalization/Basic.lean#L232).

> For a finite set `N ⊆ ℕ^n`, there is an exponent tuple `e ∈ ℕ^n` such that
> `e · ν = e · ν' ↔ ν = ν'` for all `ν, ν' ∈ N`.

```lean
theorem exists_separating_exponents {n : ℕ} (N : Finset (Fin n → ℕ)) :
    ∃ e : Fin n → ℕ, ∀ ν ∈ N, ∀ ν' ∈ N, (e ⬝ᵥ ν = e ⬝ᵥ ν' ↔ ν = ν')
```

## Tag 051N, a lemma

[Tag 051N](https://stacks.math.columbia.edu/tag/051N) in the Stacks Project.

**`exists_substitution_with_constant_leadingCoeff_of_nonconstant`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/NoetherNormalization/Basic.lean, line 454](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/NoetherNormalization/Basic.lean#L454).

> Let `g` be a nonconstant polynomial in `MvPolynomial (Fin (n+1)) R`, that is one
> not in the image of the constant inclusion `MvPolynomial.C : R → …`. Then there
> exist exponents `e` with `e 0 = 1`, encoding `e_n = 1`, a positive integer `d`,
> and an element `a ∈ R` such that:
>
> 1. `a` is one of the nonzero coefficients of `g`: there is a multi-index `ν` in
>    the support of `g` with `a = g.coeff ν`, so in particular `a ≠ 0`.
>
> 2. Viewing `f = subst n e g` as a polynomial in the distinguished variable `X 0`
>    via `finSuccEquiv R n`, its degree in that variable is `d` and its leading
>    coefficient is the *constant* `MvPolynomial.C a`, the image of `a ∈ R` inside
>    `S = MvPolynomial (Fin n) R`.

```lean
theorem exists_substitution_with_constant_leadingCoeff_of_nonconstant
    (n : ℕ) (g : MvPolynomial (Fin (n + 1)) R)
    (hg : ¬ ∃ r : R, g = MvPolynomial.C r) :
    ∃ (e : Fin (n + 1) → ℕ) (d : ℕ) (a : R),
      e 0 = 1 ∧
      (∃ ν ∈ g.support, a = g.coeff ν) ∧
      0 < d ∧
      (finSuccEquiv R n (subst n e g)).natDegree = d ∧
      (finSuccEquiv R n (subst n e g)).leadingCoeff = MvPolynomial.C a
```

## Tag 00OX, a lemma

[Tag 00OX](https://stacks.math.columbia.edu/tag/00OX) in the Stacks Project.

**`Stacks.RingTheory.NagataNormalization.exists_isIntegral_aeval`**, a lemma in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/NoetherNormalization.lean, line 152](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/NoetherNormalization.lean#L152).

> **Stacks 00OX**, in the form the induction uses. If the generators `x 0, …, x n` of a
> `k`-algebra `S` satisfy a nonzero polynomial relation `f`, then `S` is integral over the
> subalgebra generated by the `n` elements `y i = x (i + 1) - x 0 ^ D ^ (i + 1)`, where
> `D = f.totalDegree + 2`; these lie in the `ℤ`-subalgebra generated by the `x i`.

```lean
lemma exists_isIntegral_aeval {k : Type*} [Field k] {n : ℕ} {S : Type*} [CommRing S]
    [Algebra k S] (x : Fin (n + 1) → S) (hx : Algebra.adjoin k (Set.range x) = ⊤)
    {f : MvPolynomial (Fin (n + 1)) k} (hf : f ≠ 0) (hfx : MvPolynomial.aeval x f = 0) :
    ∃ y : Fin n → S, (∀ i, y i ∈ Algebra.adjoin ℤ (Set.range x)) ∧
      (MvPolynomial.aeval y : MvPolynomial (Fin n) k →ₐ[k] S).toRingHom.IsIntegral
```

> **Stacks 00OY** (Noether normalization). Let `k` be a field and let `S` be a nonzero
> commutative `k`-algebra generated by a finite set `s`. Then there are `r : ℕ` and `y : Fin r → S`
> with every `y i` in the `ℤ`-subalgebra of `S` generated by `s`, such that the `k`-algebra map
> `MvPolynomial (Fin r) k →ₐ[k] S` sending `X i` to `y i` is injective and finite; the number `r`
> is the Krull dimension of `S`.

```lean
public theorem exists_finite_inj_aeval_ringKrullDim_eq_of_adjoin_eq_top (k : Type*) {S : Type*}
    [Field k] [CommRing S] [Nontrivial S] [Algebra k S] {s : Set S} (hs : s.Finite)
    (hgen : Algebra.adjoin k s = ⊤) :
    ∃ (r : ℕ) (y : Fin r → S), (∀ i, y i ∈ Algebra.adjoin ℤ s) ∧
      Function.Injective (MvPolynomial.aeval y : MvPolynomial (Fin r) k →ₐ[k] S) ∧
      (MvPolynomial.aeval y : MvPolynomial (Fin r) k →ₐ[k] S).Finite ∧
      ringKrullDim S = r
```

## Tag 00OZ, a lemma

[Tag 00OZ](https://stacks.math.columbia.edu/tag/00OZ) in the Stacks Project.

**`noether_normalization_at_point`**, a theorem in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/NoetherNormalization/Basic.lean, line 178](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/NoetherNormalization/Basic.lean#L178).

> Noether normalization at a point: for a field `k`, a finite type `k`-algebra `S`, and a
> prime ideal `q` of `S` corresponding to a point `x` of `X = Spec(S)`, there exist an element
> `g ∉ q`, a natural number `d`, and a `k`-algebra homomorphism `ψ : k[y_1, …, y_d] → S_g`, where
> `k[y_1, …, y_d] = MvPolynomial (Fin d) k`, such that `d = dim(S_g) = dim_x(X)` and `ψ` is
> injective and finite.

```lean
theorem noether_normalization_at_point
    {k S : Type*} [Field k] [CommRing S] [Algebra k S] [Algebra.FiniteType k S]
    (q : Ideal S) [q.IsPrime] :
    ∃ (g : S) (_ : g ∉ q) (d : ℕ)
      (ψ : MvPolynomial (Fin d) k →ₐ[k] Localization.Away g),
      (d : WithBot ℕ∞) = ringKrullDim (Localization.Away g) ∧
      (d : WithBot ℕ∞) = localDimAtPrime k q ∧
      Function.Injective ψ ∧
      ψ.toRingHom.Finite
```

> **Stacks 07NA** (Noether normalization over a domain). Let `R` be a domain and let `S` be an
> `R`-algebra of finite type with `R → S` injective. Then there are an integer `d`, an `R`-subalgebra
> `S'` of `S`, elements `y_1, …, y_d ∈ S'` and a nonzero `f ∈ R` such that the `R`-algebra map
> `R[Y_1, …, Y_d] → S'`, `Y_i ↦ y_i`, is injective and makes `S'` a finite module over
> `R[Y_1, …, Y_d]`, and such that every element of `S` lies in `S'` after multiplication by a power
> of `f`; the last condition says precisely that `S'_f ≅ S_f`.

```lean
public theorem exists_subalgebra_finite_inj_aeval_pow_smul_mem (R S : Type*) [CommRing R]
    [IsDomain R] [CommRing S] [Algebra R S] [FaithfulSMul R S] [Algebra.FiniteType R S] :
    ∃ (d : ℕ) (S' : Subalgebra R S) (y : Fin d → S') (f : R), f ≠ 0 ∧
      Function.Injective (MvPolynomial.aeval y : MvPolynomial (Fin d) R →ₐ[R] S') ∧
      (MvPolynomial.aeval y : MvPolynomial (Fin d) R →ₐ[R] S').Finite ∧
      ∀ x : S, ∃ n : ℕ, f ^ n • x ∈ S'
```
