# The modular Artin induction theorem (NSW (7.3.4), Milne ADT I Lemma 2.10)

In
characteristic `p`, every class in `G₀(k[G])` has a positive multiple in
`TauCeti.indCyclicCoprimeK0`, the subgroup generated by the classes induced from cyclic subgroups
of order prime to `p`; the multiplier `|G|` works for every class.

```lean
TauCeti.modularArtin_exists_nsmul_mem_indCyclicCoprimeK0.{u} {k G : Type u} [Field k] [Group G]
  [Finite G] (p : ℕ) [Fact (Nat.Prime p)] [CharP k p]
  (x : TauCeti.ExactK0 (TauCeti.finiteModulesExactStructure (MonoidAlgebra k G))) :
  ∃ N, 0 < N ∧ N • x ∈ TauCeti.indCyclicCoprimeK0 k G p
```
