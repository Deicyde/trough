# 854 does not not imply 413

There is an 854 magma which does not satisfy the 413 law $x = x \diamond (x \diamond (x \diamond (y \diamond x)))$.

## Depends on

Its statement uses no other node of the blueprint.

## Proof

Create a partial magma by imposing the laws $1 \diamond 0 = 2$, $0 \diamond 2 = 3$, $2 \diamond 0 = 2$, $3 \diamond 2 = 3$. One can check that this is a partial magma. We then extend it to a global magma using [854 extension](extend-854.md). We claim that we have the 413 violation

$$
0 \diamond (0 \diamond (0 \diamond (1 \diamond 0))) = 0
$$

or equivalently

$$
0 \diamond (0 \diamond 3) = 0.
$$

Indeed this is immediate from the auxiliary law.
