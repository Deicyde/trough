# The order of a group from sifting checks

A form of `natCard_eq_prod_length_of_sift` whose
finite hypotheses are the checks `TauCeti.transversalCheck` and `TauCeti.siftCheck`, which `decide`
can run, and in which `H` is generated by the elements of a list `gens` that sift through
`T 0, …, T (k - 1)`.

```lean
Subgroup.natCard_eq_prod_length_of_siftCheck.{u_1, u_2} {G : Type u_1} {α : Type u_2} [Group G]
  [MulAction G α] {H : Subgroup G} {b : ℕ → α} [DecidableEq α] [DecidableEq G] {T : ℕ → List G}
  {k : ℕ} {gens : List G} (hT : ∀ i < k, ∀ r ∈ T i, r ∈ H)
  (hH : H ≤ Subgroup.closure {g | g ∈ gens}) (htrans : TauCeti.transversalCheck b T k = true)
  (hgens : gens.all (TauCeti.sift b T 0 k 1) = true)
  (hsift : ∀ i < k, TauCeti.siftCheck b T k i = true) :
  Nat.card ↥H = ∏ i ∈ Finset.range k, (T i).length
```
