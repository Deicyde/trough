# Complex analysis

> Complex Fréchet differentiability on open subsets of finite-dimensional complex normed spaces implies local analyticity for maps into complete complex normed spaces. The proof uses an iterated polydisc Cauchy formula, analytic continuous-function-valued kernels, and bounded vector-valued integration. The integration API is independently importable.
