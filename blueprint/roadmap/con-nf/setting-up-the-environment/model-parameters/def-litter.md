# litter

A *litter* is a triple $L = (\nu, \beta, \gamma) : \mu \times \lambda^\bot \times \lambda$ where $\beta \neq \gamma$. The type of all litters is denoted ${\mathcal L}$, and $\#{\mathcal L} = \#\mu$.
