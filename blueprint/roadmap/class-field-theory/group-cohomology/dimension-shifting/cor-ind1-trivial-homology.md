# ind₁' trivial homology

The representation $\mathrm{ind}_1'(M)$ has trivial homology.

## Depends on

- [ind₁' iso ind₁](lem-ind1-iso-ind1.md)
- [ind₁ trivial homology](../coinduction-and-induction/lem-ind1-trivial-homology.md)

## Proof

We've shown that $\mathrm{ind}_1'(M)$ is isomorphic to $\mathrm{ind}_1(M)$, which is already known to have trivial homology by [ind₁ trivial homology](../coinduction-and-induction/lem-ind1-trivial-homology.md).
