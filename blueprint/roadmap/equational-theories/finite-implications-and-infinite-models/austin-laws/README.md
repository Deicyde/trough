# Austin laws

The singleton or empty magma satisfies all equational laws. It is natural to ask whether an equational law admits nontrivial finite or infinite models. If no model exists, then the law is equivalent to [E2](https://teorth.github.io/equational_theories/implications/?2) $({x = y})$. An *Austin law* is a law which admits infinite models, but no nontrivial finite models: the law is equivalent to [E2](https://teorth.github.io/equational_theories/implications/?2) for finite magmas. Austin \[austin\] established the first such law, namely the order $9$ law

$$
(((1 \diamond 1) \diamond 1) \diamond 0) \diamond (((1 \diamond 1) \diamond ((1 \diamond 1) \diamond 1)) \diamond 2) \simeq 0.
$$
