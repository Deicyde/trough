# Order of an element

The **order of an element** $g$ of a [group](../../../overview/general-algebra/group-theory/part-01/group.md) is the smallest positive
integer $n$ such that $g^n = e$, where $e$ is the identity; if no positive power of
$g$ equals $e$, the element has infinite order. The order records how long the
sequence of powers $g, g^2, g^3, \dots$ runs before it returns to the identity, and it
equals the number of elements of the [subgroup generated by $g$](../../../overview/general-algebra/group-theory/part-01/subgroup-generated-by-a-subset.md).
It is a basic numerical invariant of a single element, and through
[Lagrange's theorem](../../../overview/general-algebra/group-theory/part-02/lagranges-theorem.md) it links the structure of
individual elements to the size of the group.

## Definition

Let $G$ be a group with identity $e$ and let $g \in G$. If some positive power of $g$
equals $e$, then [the order of $g$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf), written $\operatorname{ord}(g)$, is the least positive integer $n$ with $g^n = e$; otherwise $g$ has infinite
order. Thus, for $n \ge 1$,
[$g$ has order $n$ exactly when $g^n = e$ and $g^m \neq e$ for every $m$ with $0 < m < n$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_eq_iff).
The definition uses only the multiplication and the identity, so it makes sense in
any monoid. In additive notation, used for abelian groups such as the integers
modulo $n$, the condition $g^n = e$ becomes $ng = 0$.

Equivalently, [the order of $g$ is the number of elements of the cyclic subgroup $\langle g \rangle = \{g^k : k \in \mathbb{Z}\}$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Data/ZMod/QuotientGroup.html#Nat.card_zpowers),
an infinite order corresponding to an infinite subgroup. When $g$ has order $n$, the
powers $e, g, \dots, g^{n-1}$ are distinct and make up all of $\langle g \rangle$; when
$g$ has infinite order, its powers are pairwise distinct.

## Examples

- The identity is the only element of order $1$:
  [$\operatorname{ord}(g) = 1$ if and only if $g = e$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_eq_one_iff).
- In the additive group [$\mathbb{Z}/n\mathbb{Z}$](../../ring-theory/divisibility-in-integral-domains/z-n-z-and-its-invertible-elements.md) with
  $n \ge 1$, [the class of $1$ has order $n$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Data/ZMod/Basic.html#ZMod.addOrderOf_one), and more
  generally [the class of a natural number $a$ has order $n/\gcd(n, a)$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Data/ZMod/Basic.html#ZMod.addOrderOf_coe).
  In the [integers](../../../overview/general-algebra/numbers/integer.md) themselves every nonzero element has infinite order.
- In any nontrivial [ring](../../../overview/general-algebra/rings/ring.md),
  [$-1$ has multiplicative order $2$, unless the ring has characteristic $2$, where $-1 = 1$ has order $1$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_neg_one).
  In a linearly ordered ring such as $\mathbb{R}$,
  [every $x$ with $|x| \neq 1$ has infinite multiplicative order](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_abs_ne_one),
  so $1$ and $-1$ are the only real numbers of finite order.
- For $n \ge 1$, [a complex number is a primitive $n$-th root of unity exactly when its multiplicative order is $n$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/RingTheory/RootsOfUnity/PrimitiveRoots.html#IsPrimitiveRoot.iff_orderOf);
  for instance $\exp(2\pi i k/n)$ has order $n$ whenever $\gcd(k, n) = 1$ (see
  [primitive complex roots of unity](../abelian-group/primitive-complex-roots-of-unity.md)).
- Among the [permutations](../../../overview/general-algebra/group-theory/part-02/permutation-group-of-a-type.md) of a finite set,
  [a cycle has order equal to the number of points it moves](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Perm/Cycle/Basic.html#Equiv.Perm.IsCycle.orderOf),
  and [the order of any permutation is the least common multiple of the lengths of the cycles in its decomposition into disjoint cycles](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Perm/Cycle/Type.html#Equiv.Perm.lcm_cycleType)
  (see [decomposition into cycles](../permutation-group/decomposition-into-cycles-with-disjoint-support.md)). For example,
  the permutation $(1\,2)(3\,4\,5)$ of $\{1, \dots, 5\}$ has order $6$.

## Properties

Let $g$ be an element of a group $G$ with finite order $n$.

- **Powers.** For every integer $m$,
  [$g^m = e$ if and only if $n$ divides $m$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_dvd_iff_zpow_eq_one). More
  generally, for integers $a$ and $b$,
  [$g^a = g^b$ if and only if $a \equiv b \pmod n$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#zpow_eq_zpow_iff_modEq), so a
  power of $g$ depends only on the residue of its exponent modulo $n$.
- **Orders of powers.** For $k \ge 1$,
  [the power $g^k$ has order $n/\gcd(n, k)$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_pow'). In particular $g^k$
  generates the same cyclic subgroup as $g$ exactly when $\gcd(n, k) = 1$.
- **Inverses and conjugates.** [The inverse $g^{-1}$ has the same order as $g$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_inv),
  and [if $ag = g'a$ for some $a$, that is, if $g' = aga^{-1}$ is a conjugate of $g$, then $g$ and $g'$ have the same order](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#SemiconjBy.orderOf_eq).
  Order is therefore constant on [conjugacy classes](conjugacy-classes.md).
- **Homomorphisms.** For a [homomorphism](../../../overview/general-algebra/group-theory/part-01/group-morphism.md) $\varphi$,
  [the order of $\varphi(g)$ divides the order of $g$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_map_dvd), and
  [an injective homomorphism preserves the order](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_injective).
- **Lagrange.** If $G$ is finite, with $|G|$ elements (the order of $G$),
  [the order of $g$ divides $|G|$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_dvd_natCard), by Lagrange's
  theorem applied to $\langle g \rangle$; hence [$g^{|G|} = e$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#pow_card_eq_one').
- **Products.** [If $g$ and $h$ commute and have coprime orders, then $\operatorname{ord}(gh) = \operatorname{ord}(g)\operatorname{ord}(h)$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#Commute.orderOf_mul_eq_mul_orderOf_of_coprime).
  Without commutativity the orders of $g$ and $h$ say little about that of $gh$: in the
  infinite dihedral group, two reflections of order $2$ can have a product of infinite
  order. In a [direct product](direct-product-of-groups.md),
  [the order of $(a, b)$ is $\operatorname{lcm}(\operatorname{ord}(a), \operatorname{ord}(b))$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#Prod.orderOf_mk).

## Related concepts

- **[Cyclic groups](../../../overview/general-algebra/group-theory/part-01/cyclic-group.md).**
  [A finite group is cyclic exactly when it has an element whose order equals the order of the group](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/SpecificGroups/Cyclic/Subgroup.html#isCyclic_iff_exists_orderOf_eq_natCard).
- **[Cauchy's theorem](../../../thousand-plus/algebra/20-group-theory-and-generalizations/cauchys-theorem-group-theory.md).** Lagrange's theorem has
  a partial converse for element orders:
  [every prime dividing the order of a finite group is the order of some element](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Perm/Cycle/Type.html#exists_prime_orderOf_dvd_card).
- **Exponent.** [The exponent of $G$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Exponent.html#Monoid.exponent) is the least positive
  integer $n$ with $g^n = e$ for every $g \in G$, when one exists.
  [The order of every element divides the exponent](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Exponent.html#Monoid.order_dvd_exponent),
  and for a finite group
  [the exponent is the least common multiple of the orders of the elements](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Exponent.html#Monoid.lcm_orderOf_eq_exponent).

## In Mathlib

Mathlib defines the order of an element of any monoid, not only of a group, and
returns a natural number, using $0$ for infinite order:
[the order of $g$ is $0$ exactly when no positive power of $g$ equals the identity](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#orderOf_eq_zero_iff').
The definition is the minimal period of the identity under left multiplication by
$g$, a special case of the minimal period of a [periodic point](../../../overview/dynamics/general-theory/periodic-points.md)
of a map, which is likewise $0$ for a point that is not periodic. With this convention
many statements above hold for every element: "$0$ divides $m$" means $m = 0$,
congruence modulo $0$ is equality, an infinite subgroup has size $0$ as a natural
number, and every number divides $0$, so the divisibility by the order of the group
holds trivially for infinite groups. Likewise
[the exponent is $0$ exactly when no positive $n$ satisfies $g^n = e$ for every $g$](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/Exponent.html#Monoid.exponent_eq_zero_iff),
so every order divides it in that case too. [The additive order](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#addOrderOf), used
for the integers modulo $n$, is a separate notion generated automatically from the
multiplicative one, and [having finite order](https://leanprover-community.github.io/mathlib4_docs/Mathlib/GroupTheory/OrderOfElement.html#IsOfFinOrder) is a separate
predicate on elements.
