# The Jacobian criterion

Over a domain `R` of characteristic zero, if every generator
`ι (b j)` is algebraic over the subalgebra generated by the family `f`, then the Jacobian of `f`
is nonzero. This applies to a system of basic invariants of a finite group, over which the
polynomial algebra is integral.

```lean
SymmetricAlgebra.jacobian_ne_zero.{u_1, u_2, u_3} {R : Type u_1} {M : Type u_2} [CommRing R]
  [AddCommGroup M] [_root_.Module R M] {n : Type u_3} [Fintype n] [DecidableEq n]
  (b : Module.Basis n R M) [IsDomain R] [CharZero R] {f : n → SymmetricAlgebra R M}
  (hf :
    ∀ (j : n), IsAlgebraic (↥(Algebra.adjoin R (Set.range f))) ((SymmetricAlgebra.ι R M) (b j))) :
  SymmetricAlgebra.jacobian b f ≠ 0
```
