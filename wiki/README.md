# The wiki's articles

`mathlib/` holds the articles written for trough's Mathlib chapter, one concept
each (the format is in `tools/trough/wiki.py`); `unplaced/` holds those a new
Mathlib pin left without a page. They are by trough's contributors and licensed
under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), unlike the
rest of the repository, which is Apache-2.0.
