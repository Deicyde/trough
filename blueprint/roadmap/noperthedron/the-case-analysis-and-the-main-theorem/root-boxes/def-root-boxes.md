# root_boxes

There are 15 root boxes, all with $(u, v) \in [0, 1] \times [0, \frac12]$:

- charts $1, 2, 3$ with $r \in [-1, 1]^3$;
- chart $0$, one box for each face $f$, with $(s_0, s_1) \in [-1,1]^2$ and $\rho \in [0, 1]$;
- chart $4$, one box for each face $f$, with $(s_0, s_1) \in [-1,1]^2$ and $\rho \in [0, 2]$.
