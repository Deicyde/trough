# TauCeti.Amenable

A topological group `G` is amenable when `UCB G` carries a left-invariant mean.

```lean
TauCeti.Amenable.{u_1} (G : Type u_1) [Group G] [TopologicalSpace G] [IsTopologicalGroup G] : Prop
```
