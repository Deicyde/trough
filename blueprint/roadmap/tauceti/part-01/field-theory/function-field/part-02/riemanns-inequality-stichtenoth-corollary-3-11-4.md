# Riemann's inequality (Stichtenoth, Corollary 3.11.4)

if `F / k` has exact constants and
is generated by two transcendental elements `x` and `y`, then
`g ≤ ([F : k(x)] - 1) ([F : k(y)] - 1)`.

The powers `1, y, …, y^{m - 1}`, `m = [F : k(x)]`, are a basis of `F / k(x)` in
`L((m - 1) (y)_∞)`, so this is the case `F₀ = k(x)` of
`TauCeti.genus_le_one_add_finrank_mul_genus_sub_one_add_degree`.

```lean
TauCeti.genus_le_finrank_sub_one_mul_finrank_sub_one.{u_1, u_3} {k : Type u_1} {F : Type u_3}
  [Field k] [Field F] [Algebra k F] (hF : TauCeti.IsFunctionField k F)
  (hex : IsIntegrallyClosedIn k F) {x y : F} (hx : Transcendental k x) (hy : Transcendental k y)
  (hxy : k⟮x, y⟯ = ⊤) :
  TauCeti.genus k F ≤ (Module.finrank (↥k⟮x⟯) F - 1) * (Module.finrank (↥k⟮y⟯) F - 1)
```
