## Tag 07HA, an equation

[Tag 07HA](https://stacks.math.columbia.edu/tag/07HA) in the Stacks Project.

**`Crystalline.dividedPowerEnvelope_factorization`**, a lemma in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/AlgebraicGeometry/Crystalline/DividedPowerEnvelope/Quotient.lean, line 287](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/AlgebraicGeometry/Crystalline/DividedPowerEnvelope/Quotient.lean#L287).

> The divided power envelope `D` of an ideal `J ⊆ B` factors the quotient map of `B` by `J`
> as `B ⟶ D ⟶ B ⧸ J` through maps over `A`: the canonical map from `B` carries `J` into the
> divided power ideal of `D`, and that ideal is precisely the kernel of the second map, which is
> the unique ring map to `B ⧸ J` with those two properties.

```lean
public lemma dividedPowerEnvelope_factorization (A : DividedPowerRing.{u}) {B : Type v}
    [CommRing B] (f : A →+* B) (J : Ideal B) (hJ : A.ideal.map f ≤ J)
    (D : DividedPowerEnvelope A f J hJ) :
    J.map D.algebraMap.toRingHom ≤ D.object.ideal ∧
      ∃ p : D.object.carrier →+* B ⧸ J,
        p.comp D.algebraMap.toRingHom = Ideal.Quotient.mk J ∧
        p.comp D.structureMap.toRingHom = (Ideal.Quotient.mk J).comp f ∧
        Function.Surjective p ∧
        RingHom.ker p = D.object.ideal ∧
        ∀ p' : D.object.carrier →+* B ⧸ J,
          p'.comp D.algebraMap.toRingHom = Ideal.Quotient.mk J →
          D.object.ideal ≤ RingHom.ker p' → p' = p
```

## Tag 07HB, a lemma

**`Crystalline.dividedPowerEnvelope_quotient`**, a lemma in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/AlgebraicGeometry/Crystalline/DividedPowerEnvelope/Quotient.lean, line 381](https://github.com/AxiomMath/Stacks/blob/c496df0d9beea9deaeabcea8492605f9a0a2313b/StacksFrontier/AlgebraicGeometry/Crystalline/DividedPowerEnvelope/Quotient.lean#L381).

> For a surjection `B' → B`, the canonical map from the divided power envelope of the
> inverse image of `J` to the divided power envelope of `J` is surjective, and its kernel is
> generated by the positive divided powers of the original kernel.

```lean
public lemma dividedPowerEnvelope_quotient
    (A : DividedPowerRing) {B' B : Type u} [CommRing B'] [CommRing B]
    (f' : A →+* B') (f : A →+* B) (phi : B' →+* B)
    (hphi : phi.comp f' = f) (hphi_surjective : Function.Surjective phi)
    (J : Ideal B) (hJ : A.ideal.map f ≤ J)
    (D : DividedPowerEnvelope A f J hJ)
    (D' : DividedPowerEnvelope A f' (J.comap phi) (by
      rw [← Ideal.map_le_iff_le_comap, Ideal.map_map, hphi]
      exact hJ)) :
    ∃ q : DividedPowers.DPMorphism D'.object.dividedPowers D.object.dividedPowers,
      q.comp D'.structureMap = D.structureMap ∧
      q.toRingHom.comp D'.algebraMap.toRingHom = D.algebraMap.toRingHom.comp phi ∧
      Function.Surjective q ∧
      D'.object.ideal.map q.toRingHom = D.object.ideal ∧
      RingHom.ker q.toRingHom = dividedPowerKernelIdeal phi D' ∧
      (∀ q' : DividedPowers.DPMorphism D'.object.dividedPowers D.object.dividedPowers,
        q'.comp D'.structureMap = D.structureMap →
        q'.toRingHom.comp D'.algebraMap.toRingHom = D.algebraMap.toRingHom.comp phi →
        q' = q)
```

> The quotient presentation of a divided power envelope after extension of its
> coefficient ring. The formula on pure tensors identifies the displayed equivalence
> with the canonical base-change map.

```lean
public theorem dividedPowerEnvelope_tensor_equiv_quotient
    (B : DividedPowerRing.{u}) (T : Type w)
    (J : Ideal B) (hJ : B.ideal.map (RingHom.id B) ≤ J)
    (f : T → B) (hf : J = B.ideal ⊔ Ideal.span (Set.range f))
    (D : DividedPowerEnvelope B (RingHom.id B) J hJ)
    (B' : Type v) [CommRing B'] [Algebra B B'] :
    letI : Algebra B D.object := D.algebraMap.toRingHom.toAlgebra
    let ψ := (surjectiveDividedPowerPolynomialMap B T J hJ f hf D).1
    let F := setIndexedDividedPowerPolynomialAlgebra B T
    let F' := setIndexedDividedPowerPolynomialAlgebra B' T
    let baseChange : F →+* F' :=
      (DividedPowerAlgebra.map B'
        (Finsupp.mapRange.linearMap (α := T) (Algebra.linearMap B B'))).toRingHom
    let K' : Ideal F' := (RingHom.ker ψ.toRingHom).map baseChange
    ∃ e : (D.object ⊗[B] B') ≃+* (F' ⧸ K'),
      ∀ (p : F) (b' : B'),
        e (TensorProduct.tmul B (ψ p) b') =
          Ideal.Quotient.mk K' (baseChange p * algebraMap B' F' b')
```
