# Principal distinguished kernel of Fontaine's `θ` on `P.plus` (Scholze, *Étale cohomology of diamonds*, Lemma 3.14(ii))

The kernel of `θ : W(PreTilt P.plus p) → P.plus` is principal,
generated by a distinguished Witt vector, and an element of `ker θ` generates `ker θ` if and only
if it is distinguished.

```lean
TauCeti.Perfectoid.ker_fontaineTheta.{u_1} {p : ℕ} [Fact (Nat.Prime p)] {R : Type u_1} [CommRing R]
  [UniformSpace R] [IsUniformAddGroup R] [IsTopologicalRing R] [TauCeti.Huber.IsTateRing R]
  [CompleteSpace R] [T2Space R] [TauCeti.Perfectoid.IsPerfectoidTateRing p R]
  (P : TauCeti.Huber.Pair R) [Fact ¬IsUnit ↑p] :
  (∃ ξ, ξ.IsDistinguished ∧ RingHom.ker (WittVector.fontaineTheta (↥P.plus) p) = Ideal.span {ξ}) ∧
    ∀ ξ ∈ RingHom.ker (WittVector.fontaineTheta (↥P.plus) p),
      RingHom.ker (WittVector.fontaineTheta (↥P.plus) p) = Ideal.span {ξ} ↔ ξ.IsDistinguished
```
