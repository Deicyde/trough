# Classification of abelian simple groups

Mathlib states this as `CommGroup.is_simple_iff_prime_card`.

```lean
CommGroup.is_simple_iff_prime_card.{u_1} {α : Type u_1} [CommGroup α] :
  IsSimpleGroup α ↔ Nat.Prime (Nat.card α)
```
