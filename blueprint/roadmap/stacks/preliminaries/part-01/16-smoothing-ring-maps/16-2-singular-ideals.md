> **Stacks 07C6.** If a finite polynomial presentation of `A` over `R` is smooth at a prime `q`
> (Definition 00TB), then some element `a ∈ A` outside `q` is a multiple of a `c × c` Jacobian minor
> `det(∂f_j/∂x_i)_{j ∈ V, i ∈ U}` on sets `U`, `V` of `c` variables and `c` relations, and, modulo
> the square of the full relation ideal, every lift of `a` carries every relation into the ideal
> generated by the relations indexed by `V`.

```lean
theorem exists_notMem_eq_mul_jacobianMinorOn_of_smoothAt
    {R : Type u} [CommRing R] {A : Type v} [CommRing A] [Algebra R A]
    (P : _root_.Presentation R A) (q : Ideal A) [q.IsPrime]
    (hq : Algebra.SmoothAt R A q) :
    ∃ (a : A), a ∉ q ∧
      ∃ (c : ℕ) (U : Finset (Fin P.n)) (V : Finset (Fin P.m))
        (_hcn : c ≤ P.n) (_hcm : c ≤ P.m) (hU : U.card = c) (hV : V.card = c),
        ∃ a' : A,
          a = a' * P.lift (P.jacobianMinorOn c U V hU hV) ∧
          (∀ (ℓ : Fin P.m) (ã : MvPolynomial (Fin P.n) R), P.IsLift a ã →
            ã * P.f ℓ ∈ P.selectedRelIdeal V + P.relIdeal ^ 2)
```

> A strictly standard equation supplies a left inverse to its Jacobian map. Only the equation
> 16.2.3.3 is used; the relation-ideal condition 16.2.3.4 is not needed.

```lean
theorem exists_comp_eq_lsmul_of_eq_sum_jacobianMinor
    (P : Presentation R A) (a : A) (c : ℕ) (hcm : c ≤ P.m)
    (ha : ∃ aI : Finset (Fin P.n) → A,
      a = ∑ s ∈ Finset.powersetCard c (Finset.univ : Finset (Fin P.n)),
        aI s * P.lift (if h : s.card = c then P.jacobianMinor c hcm s h else 0)) :
    ∃ ψ : (Fin P.n → A) →ₗ[A] (Fin c → A),
      ψ.comp (Matrix.toLin' (jacobianMatrix P c hcm)) =
        LinearMap.lsmul A (Fin c → A) a
```

> A left inverse to the Jacobian expresses the corresponding power as a sum of Jacobian minors
> (the equation of Stacks 07ER). This also holds for `c = 0`, when the empty minor is `1`; the
> relation-ideal condition of Stacks 07ES is a separate requirement.

```lean
theorem exists_pow_eq_sum_jacobianMinor_of_comp_eq_lsmul
    (P : Presentation R A) (a : A) (c : ℕ) (hcm : c ≤ P.m)
    (ψ : (Fin P.n → A) →ₗ[A] (Fin c → A))
    (hψ : ψ.comp (Matrix.toLin' (jacobianMatrix P c hcm)) =
      LinearMap.lsmul A (Fin c → A) a) :
    ∃ aI : Finset (Fin P.n) → A,
      a ^ c = ∑ s ∈ Finset.powersetCard c (Finset.univ : Finset (Fin P.n)),
        aI s * P.lift (if h : s.card = c then P.jacobianMinor c hcm s h else 0)
```

> Given ring maps `R → A → Λ` with `A` of finite presentation over `R`, if the image of the
> singular ideal `H_{A/R}` generates the unit ideal of `Λ`, then `A → Λ` factors as
> `A → B → Λ` with `B` smooth over `R`.

```lean
theorem exists_smooth_factorization_of_singularIdeal_map_eq_top
    (R : Type u) (A : Type v) (Λ : Type w) [CommRing R] [CommRing A] [CommRing Λ]
    [Algebra R A] [Algebra A Λ] [Algebra R Λ] [IsScalarTower R A Λ]
    [Algebra.FinitePresentation R A]
    (h : Ideal.map (algebraMap A Λ) (singularIdeal R A) = ⊤) :
    ∃ (B : Type (max v w)) (_ : CommRing B) (_ : Algebra R B) (_ : Algebra A B)
      (_ : Algebra B Λ),
      IsScalarTower R A B ∧ IsScalarTower A B Λ ∧ IsScalarTower R B Λ ∧ Algebra.Smooth R B
```
