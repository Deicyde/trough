In the case of finite magmas, there are some non-trivial positive implications:

- [467](https://teorth.github.io/equational_theories/implications/?467) implies 2847.
- [906](https://teorth.github.io/equational_theories/implications/?906) implies 3862.
- [1516](https://teorth.github.io/equational_theories/implications/?1516) implies 255.
- [1441](https://teorth.github.io/equational_theories/implications/?1441) implies 4067.
- [1443](https://teorth.github.io/equational_theories/implications/?1443) implies 3055.
- [1681](https://teorth.github.io/equational_theories/implications/?1681) implies 3877.
- [1701](https://teorth.github.io/equational_theories/implications/?1701) implies 1035.
- [1113](https://teorth.github.io/equational_theories/implications/?1113) implies 1167.
- [1167](https://teorth.github.io/equational_theories/implications/?1167) implies 1096.

There are also some tricky negative implications:

- [476](https://teorth.github.io/equational_theories/implications/?476) does not imply 359, 4065.
- [503](https://teorth.github.io/equational_theories/implications/?503) does not imply 4065, 3862.
- [854](https://teorth.github.io/equational_theories/implications/?854) does not imply 107, 1248, 1251.
- [1076](https://teorth.github.io/equational_theories/implications/?1076) does not imply 2234, 2294, 4435.
- [1518](https://teorth.github.io/equational_theories/implications/?1518) does not imply 47, 817.
- [3352](https://teorth.github.io/equational_theories/implications/?3352) does not imply 4065.
- [3475](https://teorth.github.io/equational_theories/implications/?3475) does not imply 3659.

Finally, we have some open questions:

- Does [677](https://teorth.github.io/equational_theories/implications/?677) imply 255?
