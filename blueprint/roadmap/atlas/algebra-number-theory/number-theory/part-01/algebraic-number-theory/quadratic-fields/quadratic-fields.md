## Stark–Heegner theorem

Let $d$ be a positive squarefree integer and let $K$ be a number
field of degree $2$ over $\mathbb{Q}$ that contains an element $x$ with $x^2 = -d$, so that
$K = \mathbb{Q}(\sqrt{-d})$. Then $K$ has class number $1$ if and only if
$d \in \{1, 2, 3, 7, 11, 19, 43, 67, 163\}$.

## Units of the ring generated by the golden ratio

Let $\alpha = (1 + \sqrt{5})/2$ and
let $\mathbb{Z}[\alpha]$ be the subring of $\mathbb{R}$ generated by $\alpha$. A real number is
a unit of $\mathbb{Z}[\alpha]$ if and only if it equals $\alpha^n$ or $-\alpha^n$ for some
integer $n$.
