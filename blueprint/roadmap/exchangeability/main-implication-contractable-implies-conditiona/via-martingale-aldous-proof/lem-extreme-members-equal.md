# Extreme members equal on tail

For any measurable $B$: $\mathbb{E}[\mathbf{1}_{X_m \in B} \mid \mathcal{T}] = \mathbb{E}[\mathbf{1}_{X_0 \in B} \mid \mathcal{T}]$ a.s.
