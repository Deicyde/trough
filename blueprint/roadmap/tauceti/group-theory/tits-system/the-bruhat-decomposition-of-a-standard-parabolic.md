# The Bruhat decomposition of a standard parabolic

an element lies in `P_J` exactly
when its Bruhat cell is indexed by the Weyl subgroup generated by `J`.

```lean
TauCeti.TitsSystem.mem_standardParabolic_iff.{u} {G : Type u} [Group G] (T : TauCeti.TitsSystem G)
  {J : Set ↑T.simple} {g : G} :
  g ∈ T.standardParabolic J ↔ ∃ w ∈ Subgroup.closure (Subtype.val '' J), g ∈ T.bruhatCell w
```
