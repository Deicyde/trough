# The routine of the answer reduction, fixed

For constants with $E_2 \geq 1$ the parameters of Definition [The parameters of the answer reduction](../part-08/def-ar-params.md) form a parameter routine: a closed program computes them from $((\lambda, \mu, \sigma), n)$ in polynomial time in the sense of Definition [A parameter routine in polynomial time](../part-08/def-ar-par-time.md), and the circuit function computing the padded descriptions of Lemma [The honest PCPs' hypotheses at the parameters](../part-08/lem-ar-honest-hyp.md) is a polynomial-time function. Its circuits satisfy the honest PCPs' hypotheses for every input within the input budget.

## Proof

The program reuses the budget stage of the MIP\* answer reduction for $Q$, writes $Q$, $\mu$, $\sigma$, $r$, $s$ and $2^j$ in unary, and computes the rest by polynomial-time functions; each written number is at most a polynomial in $(\lambda n + 1)^\mu + \sigma + \lambda + n$ raised to $\mu + 1$. The circuit function reads $K$ and $\sigma'$ from the parameters' data.
