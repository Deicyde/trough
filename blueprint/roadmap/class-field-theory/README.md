# Class field theory

[kbuzzard/ClassFieldTheory](https://github.com/kbuzzard/ClassFieldTheory) says in its README:

> An ongoing project to formalize the main theorems of local and global class field theory in the Lean theorem prover.

Its blueprint, by Kevin Buzzard, Richard Hill and others, read at commit [1e7f5dbe](https://github.com/kbuzzard/ClassFieldTheory/tree/1e7f5dbe38358bd37a0643bb0db2dd3a436e6cb7) (2026-11-13): one article for each of its 52 nodes whose Lean declarations it names and marks formalized, or in Mathlib. Its other 68 nodes have no article, and a section of only those is left out: the map records what the project contains, not what it plans. A statement for which the blueprint marks no proof `\leanok` says so. Dependencies are the blueprint's `\uses`: a statement's under *Depends on*, a proof's under *Proof depends on*.

The text is the blueprint's, under its Apache-2.0 license: each page has a section's prose, remarks and examples in the blueprint's order, with each node's statement and proof where the node stands.
