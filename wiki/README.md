# The wiki's articles

`mathlib/` holds the articles written for trough's Mathlib chapter, one concept
each, as its text (`<name>.md`) and its literature-links annotations
(`<name>.jsonl`): which concept it is about and what each citation cites. The
format is in `tools/trough/wiki.py`. `unplaced/` holds those a new Mathlib pin
left without a page. Both files of an article are by trough's contributors and
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), unlike the
rest of the repository, which is Apache-2.0.
