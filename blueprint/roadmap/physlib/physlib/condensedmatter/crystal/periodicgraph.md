# Periodic graphs of crystals

The module `Physlib.CondensedMatter.Crystal.PeriodicGraph`, [Physlib/CondensedMatter/Crystal/PeriodicGraph.lean](https://github.com/leanprover-community/physlib/blob/2a1dfe43134b49b643642f13d33031754021bb5d/Physlib/CondensedMatter/Crystal/PeriodicGraph.lean): 22 declarations (1 instance with no name), 22 with a docstring.

> A finite set of bonds, repeated in every unit cell, gives the connections of a crystal.

## i. Overview

> A crystal is a set of sites with a translation action. Connections between sites, such as the
> nearest-neighbor links of a square lattice, give it a graph. Since the crystal is periodic, so is
> its graph: translating both ends of a connection preserves adjacency,
>
> `Adj (a +ᵥ x) (a +ᵥ y) ↔ Adj x y`.
>
> It is enough to list the connections once. A finite set of bonds gives a periodic graph, and
> conversely every periodic graph in which each site has finitely many neighbors comes from finitely
> many bonds.

## ii. Key results

> - `PeriodicGraph` : a graph on the sites that is invariant under translation and has finitely
>   many neighbors at each site.
> - `PeriodicGraph.ofBonds` : the periodic graph generated by a finite set of bonds.
> - `PeriodicGraph.eq_ofBonds` : every periodic graph is generated by finitely many bonds.
> - `PeriodicGraph.degree_vadd` : every copy of a site has the same number of neighbors.
> - `PeriodicGraph.graphAutomorphisms` : the adjacency-preserving permutations of the sites.

## iv. References

> * F. Göhmann, *Introduction to Solid State Physics*, lecture L3, Section 3.1, for the standard
>   description of a crystal. [ref: goehmann\_solid\_state\_2021]
