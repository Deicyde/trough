# Gluing module homomorphisms

Suppose `R → S` is faithfully flat and induces an
isomorphism modulo the ideal generated by `G`. An `S`-linear map on the base changes and maps
on the localizations at the generators come from a unique `R`-linear map if their localization
squares commute. Neither module needs to be finitely generated.

```lean
LinearMap.existsUnique_formalGlueing_lift.{u_1, u_2, u_3, u_4} {R : Type u_1} {S : Type u_2}
  {M : Type u_3} {N : Type u_4} [CommRing R] [CommRing S] [Algebra R S] [AddCommGroup M]
  [_root_.Module R M] [AddCommGroup N] [_root_.Module R N] [Module.FaithfullyFlat R S]
  {G : Finset R} (fS : TensorProduct R S M →ₗ[S] TensorProduct R S N)
  (fg :
    (g : ↥G) →
      LocalizedModule (Submonoid.powers ↑g) M →ₗ[R] LocalizedModule (Submonoid.powers ↑g) N)
  (hI :
    Function.Bijective
      ⇑(Ideal.quotientMap (Ideal.map (algebraMap R S) (Ideal.span ↑G)) (algebraMap R S) ⋯))
  (hcompat :
    ∀ (g : ↥G),
      (IsLocalizedModule.map (Submonoid.powers ↑g)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) (TensorProduct R S M))
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) (TensorProduct R S N)))
            (↑R fS) ∘ₗ
          (IsLocalizedModule.map (Submonoid.powers ↑g)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) M)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) (TensorProduct R S M)))
            ((TensorProduct.mk R S M) 1) =
        (IsLocalizedModule.map (Submonoid.powers ↑g)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) N)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) (TensorProduct R S N)))
            ((TensorProduct.mk R S N) 1) ∘ₗ
          fg g) :
  ∃! f,
    LinearMap.baseChange S f = fS ∧
      ∀ (g : ↥G),
        (IsLocalizedModule.map (Submonoid.powers ↑g)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) M)
              (LocalizedModule.mkLinearMap (Submonoid.powers ↑g) N))
            f =
          fg g
```
