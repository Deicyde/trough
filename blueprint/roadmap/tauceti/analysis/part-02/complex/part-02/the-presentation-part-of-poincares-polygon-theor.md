# The presentation part of Poincaré's polygon theorem

If a side-paired polygon satisfies
the angle condition at every finite vertex cycle and has parabolic cycle transformations at its
ideal vertices, then evaluating the side generators at the side-pairing maps is an isomorphism
from the group presented by the side relations and the finite vertex cycle relations onto the
group generated by the side-pairing maps.

```lean
TauCeti.UpperHalfPlane.ConvexPolygon.SidePairing.relatorQuotientTo_bijective_of_isParabolic {n : ℕ}
  [NeZero n] {P : TauCeti.UpperHalfPlane.ConvexPolygon n} (σ : P.SidePairing)
  (hcyc :
    ∀ (j : Fin n) (z : UpperHalfPlane),
      P.vertex j = Sum.inl z → ↑(orderOf (σ.cycleMap j)) * σ.cycleAngleSum j = 2 * Real.pi)
  (hpar : ∀ (j : Fin n) (ξ : OnePoint ℝ), P.vertex j = Sum.inr ξ → (σ.cycleMap j).IsParabolic) :
  Function.Bijective ⇑(σ.relatorQuotientTo ⋯)
```
