> Let `A` be a Noetherian complete local ring.  The kernel of every surjection onto `A` from
> a regular local ring is generated by a regular sequence if and only if this holds for one such
> surjection.

```lean
public theorem forall_regularPresentation_iff_exists
    (A : Type u) [CommRing A] [IsNoetherianRing A] [IsLocalRing A]
    [IsAdicComplete (maximalIdeal A) A] :
    (∀ (R : Type u) [CommRing R] [IsRegularLocalRing R] (f : R →+* A),
      Function.Surjective f →
        ∃ rs : List R, RingTheory.Sequence.IsRegular R rs ∧
          Ideal.ofList rs = RingHom.ker f) ↔
      ∃ (R : Type u) (_ : CommRing R) (_ : IsRegularLocalRing R) (f : R →+* A),
        Function.Surjective f ∧
          ∃ rs : List R, RingTheory.Sequence.IsRegular R rs ∧
            Ideal.ofList rs = RingHom.ker f
```

References: EGA IV (19.3.2), “reg seq ⇒ CI”.

> **Stacks 09Q0.** If `R` is regular, `p` is a prime of `R`, and `rs` is a regular
> sequence contained in `p`, then the completion of `Rₚ/(rs)Rₚ` at its maximal ideal is a complete
> intersection.

```lean
public theorem isCompleteIntersectionCompleteLocalRing_adicCompletion_quotientAtPrime
    (R : Type u) [CommRing R] [IsRegularRing R] (p : Ideal R) [p.IsPrime] (rs : List R)
    (hrs : IsRegular R rs) (hmem : ∀ x ∈ rs, x ∈ p) :
    let Rp := Localization.AtPrime p
    let rs' : List Rp := rs.map (algebraMap R Rp)
    let I : Ideal Rp := Ideal.ofList rs'
    let A := Rp ⧸ I
    IsCompleteIntersectionCompleteLocalRing
      (AdicCompletion ((maximalIdeal Rp).map (Ideal.Quotient.mk I)) A)
```

## Tag 09Q1, a lemma

[Tag 09Q1](https://stacks.math.columbia.edu/tag/09Q1) in the Stacks Project.

**`LocalCompleteIntersection.quotient_regular_ring_tfae`**, a lemma in StacksFrontier (drafted, not yet reviewed), declared in [StacksFrontier/RingTheory/LocalCompleteIntersection/Basic.lean, line 608](https://github.com/AxiomMath/Stacks/blob/5ed82d14634e8d9576bb844c7bd4e3da66d450e7/StacksFrontier/RingTheory/LocalCompleteIntersection/Basic.lean#L608). References: EGA IV (19.3.2).

> For a quotient of the localization of a regular ring at a prime, the completion is a complete
> intersection if and only if the extended ideal is generated by a regular sequence, if and only if
> its conormal module can be generated by the codimension number of elements.

```lean
public lemma quotient_regular_ring_tfae
    {R : Type u} [CommRing R] [IsRegularRing R]
    (p : Ideal R) [p.IsPrime] (I : Ideal R) (hIp : I ≤ p)
    (Rp : Type u) [CommRing Rp] [Algebra R Rp] [IsLocalization.AtPrime Rp p]
    (A : Type v) [CommRing A] [IsLocalRing A]
    (q : Rp →+* A) (hq : Function.Surjective q)
    (hker : RingHom.ker q = I.map (algebraMap R Rp)) :
    List.TFAE
      [IsCompleteIntersectionCompleteLocalRing
          (AdicCompletion (maximalIdeal A) A),
        ∃ rs : List Rp, IsRegular Rp rs ∧
          Ideal.ofList rs = I.map (algebraMap R Rp),
    ∃ c : ℕ,
          ringKrullDim A + (c : WithBot ℕ∞) = ringKrullDim Rp ∧
            (⊤ : Submodule
              (Rp ⧸ (I.map (algebraMap R Rp)))
              (I.map (algebraMap R Rp)).Cotangent).spanFinrank ≤ c]
```

> **Stacks 09Q2.** For a flat local homomorphism `A → B` of Noetherian local rings, the
> completion of `B` is a complete intersection if and only if the completion of `A` and the
> completion of the closed fibre `B / 𝔪_A B` both are.

```lean
theorem isCompleteIntersectionCompleteLocalRing_adicCompletion_iff_of_flat
    (A : Type u) (B : Type v) [CommRing A] [CommRing B]
    [IsNoetherianRing A] [IsNoetherianRing B] [IsLocalRing A] [IsLocalRing B]
    [Algebra A B] [IsLocalHom (algebraMap A B)] [Module.Flat A B] :
    let I := (maximalIdeal A).map (algebraMap A B)
    let _ : Nontrivial (B ⧸ I) :=
      Ideal.Quotient.nontrivial_iff.mpr
        (IsLocalRing.map_maximalIdeal_lt_top (algebraMap A B)).ne
    let _ : IsLocalHom (Ideal.Quotient.mk I) :=
      IsLocalHom.of_surjective _ Ideal.Quotient.mk_surjective
    let _ : IsLocalRing (B ⧸ I) :=
      IsLocalRing.of_surjective _ Ideal.Quotient.mk_surjective
    IsCompleteIntersectionCompleteLocalRing (AdicCompletion (maximalIdeal B) B) ↔
      (IsCompleteIntersectionCompleteLocalRing (AdicCompletion (maximalIdeal A) A) ∧
        IsCompleteIntersectionCompleteLocalRing
          (AdicCompletion (maximalIdeal (B ⧸ I)) (B ⧸ I)))
```

theorem isCompleteIntersectionRing_iff_of_flat :
