# Uniform monomial-evaluation kernels

For any map from a finite variable type to a commutative monoid, one finite set of same-product exponent pairs gives coefficient-one monomial differences spanning the kernel of monomial evaluation in MvPolynomial over every commutative coefficient ring, including empty variable types and zero rings, with all three universes independent.
