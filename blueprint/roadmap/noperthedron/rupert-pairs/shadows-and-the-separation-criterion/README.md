# Shadows and the separation criterion

From now on $\operatorname{\mathbf{P}}$ denotes the Noperthedron (Definition [noperthedron](../../the-noperthedron/definition-of-the-noperthedron/def-noperthedron.md)).

- [shadow](def-shadow.md)
- [exists_rup_pair](lem-exists-rup-pair.md)

For $w = (w_0, w_1) \in \operatorname{\mathbb{R}}^2$ write $\langle w, x \rangle = w_0 x_0 + w_1 x_1$ for $x \in \operatorname{\mathbb{R}}^3$ (only the screen coordinates enter).

- [Separation criterion](thm-separation.md)

Only a non-strict inequality is needed, so poses in which the two shadows touch need no special treatment.
