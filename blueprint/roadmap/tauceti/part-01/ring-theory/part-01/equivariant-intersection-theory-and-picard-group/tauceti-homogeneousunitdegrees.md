# TauCeti.homogeneousUnitDegrees

The degrees of the homogeneous units of a graded ring: the subgroup of the degree group
generated by the degrees `d` such that some unit lies in `𝒜 d`. For a grading by a group, every
element of this subgroup is itself the degree of a homogeneous unit
(`mem_homogeneousUnitDegrees_iff`).

```lean
TauCeti.homogeneousUnitDegrees.{u_1, u_2, u_3} {ι : Type u_1} {A : Type u_2} {σ : Type u_3}
  [AddGroup ι] [Monoid A] [SetLike σ A] (𝒜 : ι → σ) : AddSubgroup ι
```
