# ContMDiffMap.manifoldStrongWhitneyTopology

The strong Whitney topology on vector-valued `C^n` maps, generated by the strong `C^k`
neighbourhoods `ContMDiffMap.StrongCkControl.ball` of all finite orders `k ≤ n`.

```lean
ContMDiffMap.manifoldStrongWhitneyTopology.{u, u_1, u_2, u_3, u_4} {𝕜 : Type u_1}
  [NontriviallyNormedField 𝕜] {E : Type u_2} [NormedAddCommGroup E] [NormedSpace 𝕜 E] {H : Type u_3}
  [TopologicalSpace H] {I : ModelWithCorners 𝕜 E H} {M : Type u} [TopologicalSpace M]
  [ChartedSpace H M] {F : Type u_4} [NormedAddCommGroup F] [NormedSpace 𝕜 F] {n : WithTop ℕ∞}
  [IsManifold I n M] : TopologicalSpace (ContMDiffMap I (modelWithCornersSelf 𝕜 F) M F n)
```
