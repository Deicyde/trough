# Hadamard's lemma

On a finite-dimensional space, the smooth functions vanishing at `x`
form the ideal generated by the coordinate functions of `b`, each taken relative to its value at
`x`.

```lean
Module.Basis.smoothVanishingIdeal_eq_span.{u_1, u_2} {E : Type u_1} [NormedAddCommGroup E]
  [NormedSpace ℝ E] [FiniteDimensional ℝ E] {ι : Type u_2} [Finite ι] (b : Module.Basis ι ℝ E)
  (x : E) :
  TauCeti.smoothVanishingIdeal (modelWithCornersSelf ℝ E) x =
    Ideal.span
      (Set.range fun i =>
        b.smoothCoord i -
          (algebraMap ℝ (ContMDiffMap (modelWithCornersSelf ℝ E) (modelWithCornersSelf ℝ ℝ) E ℝ ↑⊤))
            ((ContMDiffMap.evalAlgHom x) (b.smoothCoord i)))
```

**Hadamard's lemma in coordinates.** Formalized in Tau Ceti as [`ContMDiffMap.exists_hadamard_coords`](https://taucetiproject.org/docs/TauCeti/Geometry/Manifold/ContMDiffMap/Hadamard.html#ContMDiffMap.exists_hadamard_coords).

```lean
ContMDiffMap.exists_hadamard_coords.{u_1, u_2} {E : Type u_1} [NormedAddCommGroup E]
  [NormedSpace ℝ E] {ι : Type u_2} [Fintype ι]
  (f : ContMDiffMap (modelWithCornersSelf ℝ E) (modelWithCornersSelf ℝ ℝ) E ℝ ↑⊤) (x : E)
  (b : Module.Basis ι ℝ E) :
  ∃ a,
    (∀ (i : ι), (a i) x = (fderiv ℝ (⇑f) x) (b i)) ∧
      ∀ (y : E), f y - f x = ∑ i, (a i) y * ((b.coord i) y - (b.coord i) x)
```
