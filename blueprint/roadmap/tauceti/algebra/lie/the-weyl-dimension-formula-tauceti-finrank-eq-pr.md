# The Weyl dimension formula (`TauCeti.finrank_eq_prod_coweightPairing_div`)

For a finite-dimensional module `M` generated by a highest
weight vector of weight `lam`,

`dim M = ∏_{α>0} ⟨lam + ρ, α^∨⟩ / ⟨ρ, α^∨⟩`,

the product running over the positive roots, with `ρ` the Weyl vector of the base and
`⟨·, α^∨⟩` the integer coroot pairing `TauCeti.coweightPairing`. Such an `M` is irreducible, so
this is the dimension of `L(lam)` for every dominant integral weight `lam` at which `L(lam)` is
nonzero.

```lean
TauCeti.finrank_eq_prod_coweightPairing_div.{u, v, w} {K : Type u} {L : Type v} [Field K]
  [CharZero K] [IsAlgClosed K] [LieRing L] [LieAlgebra K L] [LieAlgebra.IsKilling K L]
  [FiniteDimensional K L] {H : LieSubalgebra K L} [H.IsCartanSubalgebra] {M : Type w}
  [AddCommGroup M] [_root_.Module K M] [LieRingModule L M] [LieModule K L M] [FiniteDimensional K M]
  {b : (LieAlgebra.IsKilling.rootSystem H).Base} {lam : Module.Dual K ↥H} {v : M}
  (hv : TauCeti.IsHighestWeightVector b lam v) (hgen : LieSubmodule.lieSpan K L {v} = ⊤) :
  ↑(Module.finrank K M) =
    ∏ i ∈ TauCeti.posRootsFinset (LieAlgebra.IsKilling.rootSystem H) b,
      ↑(TauCeti.coweightPairing (lam + TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b)
            i) /
        ↑(TauCeti.coweightPairing (TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b) i)
```

**The Weyl dimension formula, division-free.** Formalized in Tau Ceti as [`TauCeti.finrank_mul_prod_coweightPairing_weylVector_eq`](https://taucetiproject.org/docs/TauCeti/Algebra/Lie/HighestWeight/Weyl/Dimension.html#TauCeti.finrank_mul_prod_coweightPairing_weylVector_eq).

```lean
TauCeti.finrank_mul_prod_coweightPairing_weylVector_eq.{u, v, w} {K : Type u} {L : Type v} [Field K]
  [CharZero K] [IsAlgClosed K] [LieRing L] [LieAlgebra K L] [LieAlgebra.IsKilling K L]
  [FiniteDimensional K L] {H : LieSubalgebra K L} [H.IsCartanSubalgebra] {M : Type w}
  [AddCommGroup M] [_root_.Module K M] [LieRingModule L M] [LieModule K L M] [FiniteDimensional K M]
  {b : (LieAlgebra.IsKilling.rootSystem H).Base} {lam : Module.Dual K ↥H} {v : M}
  (hv : TauCeti.IsHighestWeightVector b lam v) (hgen : LieSubmodule.lieSpan K L {v} = ⊤) :
  ↑(Module.finrank K M) *
      ∏ i ∈ TauCeti.posRootsFinset (LieAlgebra.IsKilling.rootSystem H) b,
        TauCeti.coweightPairing (TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b) i =
    ∏ i ∈ TauCeti.posRootsFinset (LieAlgebra.IsKilling.rootSystem H) b,
      TauCeti.coweightPairing (lam + TauCeti.weylVector (LieAlgebra.IsKilling.rootSystem H) b) i
```
