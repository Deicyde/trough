# Modal Logic for Lean

`Cslib.Logics.Modal.Lean.Basic`, in [Cslib/Logics/Modal/Lean/Basic.lean](https://github.com/leanprover/cslib/blob/86d560b6cbb379bd82512424cbcd2a915a1565e7/Cslib/Logics/Modal/Lean/Basic.lean), by Fabrizio Montesi.

> This module develops the interplay between modal logic and Lean's propositional language, in order
> to enable the use of modal logic to reason about standard Lean relations using `Prop`.

`Cslib.Logic.Modal.Model.ofPredicates` (abbreviation, [line 29](https://github.com/leanprover/cslib/blob/86d560b6cbb379bd82512424cbcd2a915a1565e7/Cslib/Logics/Modal/Lean/Basic.lean#L29))

> Given a frame `f` on `α`, constructs the modal model whose worlds are elements of `α`
> and whose atoms are Lean predicates on `α` (`α → Prop`).
>
> Valuation checks that a world satisfies a predicate. For example, under `Model.ofPredicates r`, `□P`
> at `a : α` means that `P a'` holds at every `a'` such that `r a a'`.

```lean
abbrev ofPredicates (f : Frame α τ) : Model α τ (α → Prop)
```

> Given a frame `f` on `α` and a container type `β` for `α` (`Membership α β`), constructs the
> modal model whose worlds are elements of `α` and whose atoms are of type `β`.
>
> Valuation is membership. For example, under `Model.ofContainers r`, `□b` at `a : α` means that
> `a' ∈ b` holds for every `a'` such that `r a a'`.

> Under `Model.ofPredicates r`, an atomic proposition `P` holds at `a` iff `P a`.

```lean
theorem Satisfies.ofPredicates_atom_iff {P : α → Prop} (f : Frame α τ) :
    ⇓Modal[ofPredicates f,a ⊨ P] ↔ P a
```

> In the predicate model generated by `f`, `P → ∇[op]Ps` holds everywhere iff `op`
> preserves the predicate map `Ps` from `P`.

```lean
theorem Satisfies.ofPredicates_preservesMap_iff {P : α → Prop} {Ps : τ.B op → α → Prop}
    (f : Frame α τ) :
    (∀ w, ⇓Modal[ofPredicates f,w ⊨ P → ∇[op](fun i => (Ps i : Proposition τ (α → Prop)))]) ↔
      f.PreservesMap op P Ps
```

> Logically equivalent propositions under `Equiv.OfPredicates f` have the same denotation in the
> Lean modal model induced by `ofPredicates f`.

```lean
theorem Proposition.equivOfPredicates_denotation_eq {f : Frame α τ}
    {φ₁ φ₂ : Proposition τ (α → Prop)} :
    (φ₁ ≡[Equiv.OfPredicates f] φ₂) ↔
      φ₁.denotation (ofPredicates f) = φ₂.denotation (ofPredicates f)
```

`Cslib.Logic.Modal.Proposition.equivOfPredicates_and` (theorem, [line 119](https://github.com/leanprover/cslib/blob/86d560b6cbb379bd82512424cbcd2a915a1565e7/Cslib/Logics/Modal/Lean/Basic.lean#L119))

> Pointwise conjunction of Lean predicates is logically equivalent to their modal conjunction in
> the predicate model induced by `f`.

```lean
theorem Proposition.equivOfPredicates_and
    {f : Frame α τ} {P Q : α → Prop} :
    (fun a => P a ∧ Q a) ≡[Equiv.OfPredicates f] (P ∧ Q)
```

`Cslib.Logic.Modal.Proposition.ofContainers_inf_equiv` (theorem, [line 127](https://github.com/leanprover/cslib/blob/86d560b6cbb379bd82512424cbcd2a915a1565e7/Cslib/Logics/Modal/Lean/Basic.lean#L127))

> Under `Equiv.OfContainers f`, if membership in the infimum of two containers is equivalent to
> membership in both containers, then atomic infimum is logically equivalent to modal conjunction.

```lean
theorem Proposition.ofContainers_inf_equiv
    [Membership α β] [Min β] (f : Frame α τ) (p q : β)
    (h : ∀ x, x ∈ p ⊓ q ↔ x ∈ p ∧ x ∈ q) :
    (↑(p ⊓ q) : Proposition τ β) ≡[Equiv.OfContainers f] (p ∧ q)
```
