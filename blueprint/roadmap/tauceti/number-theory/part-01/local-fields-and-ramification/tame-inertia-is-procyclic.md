# Tame inertia is procyclic

it is topologically generated by the class of an element of the
inertia subgroup.

```lean
TauCeti.exists_topologicalClosure_zpowers_eq_tameInertia.{u} (K : Type u) [Field K] [ValuativeRel K]
  [TopologicalSpace K] [IsNonarchimedeanLocalField K] :
  ∃ τ ∈ TauCeti.inertiaSubgroup K,
    (Subgroup.zpowers ((TauCeti.toTameQuotient K) τ)).topologicalClosure = TauCeti.tameInertia K
```
