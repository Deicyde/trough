# Proximity Gap

A code $\mathcal{C}$ has a proximity gap at distance $d$ with bound $b$ if, for all words $u,v$ whose proximity measure exceeds $b$, the pair $(u,v)$ is within distance $d$ of the 2-fold interleaved code of $\mathcal{C}$.
