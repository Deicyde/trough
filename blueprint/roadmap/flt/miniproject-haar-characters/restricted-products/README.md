Say $\phi_i:A_i\to B_i$ are functions with the property that $\phi_i(C_i)\subseteq D_i$ for all but finitely many $i$. It is easily checked that the $\phi_i$ induce a function $\phi:=\prod'_i\phi_i:A\to B$.
