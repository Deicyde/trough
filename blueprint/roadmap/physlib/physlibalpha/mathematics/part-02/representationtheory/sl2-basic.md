# The standard sl₂ Lie module

The module `PhyslibAlpha.Mathematics.RepresentationTheory.Sl2.Basic`, [PhyslibAlpha/Mathematics/RepresentationTheory/Sl2/Basic.lean](https://github.com/leanprover-community/physlib/blob/2a1dfe43134b49b643642f13d33031754021bb5d/PhyslibAlpha/Mathematics/RepresentationTheory/Sl2/Basic.lean): 18 declarations, 7 with a docstring.

> Packages the standard module as a Lie module for the subalgebra generated by an `IsSl2Triple`.

## i. Overview

> An `IsSl2Triple` generates a three-dimensional Lie subalgebra of endomorphisms. This file
> uses the explicit standard-module operators to equip `StandardSl2Module` with a Lie module
> structure for that subalgebra and records its action on coordinate vectors.

## ii. Key results

> - `standardSl2ModuleLieRingModule` supplies the Lie module structure.
> - Generator action lemmas give the raising, lowering, and weight formulas on the standard basis.
> - `isSl2Triple_sub` packages the three generators as a triple inside their subalgebra.

## A. The generated Lie subalgebra

**`PhyslibAlpha.Sl2.Φ_leibniz`**, a lemma, [line 53](https://github.com/leanprover-community/physlib/blob/2a1dfe43134b49b643642f13d33031754021bb5d/PhyslibAlpha/Mathematics/RepresentationTheory/Sl2/Basic.lean#L53).

> The action map satisfies the Leibniz rule, since `Φ` preserves brackets.

```lean
lemma Φ_leibniz [CharZero K] (t : IsSl2Triple h e f) (x y : ↥(t.toLieSubalgebra (R := K)))
    (v : StandardSl2Module K n) :
    Φ (n := n) t x (Φ t y v) = Φ t ⁅x, y⁆ v + Φ t y (Φ t x v)
```

**`PhyslibAlpha.Sl2.standardSl2ModuleLieRingModule`**, a def, [line 65](https://github.com/leanprover-community/physlib/blob/2a1dfe43134b49b643642f13d33031754021bb5d/PhyslibAlpha/Mathematics/RepresentationTheory/Sl2/Basic.lean#L65).

> Standard module `V(n)`, module structure.
> Given an `sl₂`-triple `(h,e,f)` in `L`, `StandardSl2Module K n` carries a
> `LieRingModule` structure for the generated subalgebra, with
> `h ⬝ v k = (n - 2k) • v k`, `f ⬝ v k = v (k+1)` (and `f ⬝ v n = 0), and
> `e ⬝ v k = (k * (n - k + 1)) • v (k-1)` (and `e ⬝ v 0 = 0`).

```lean
def standardSl2ModuleLieRingModule [CharZero K] (t : IsSl2Triple h e f) :
    LieRingModule (↥(t.toLieSubalgebra (R := K))) (StandardSl2Module K n)
```

> Standard module `V(n)`, module structure, continued.

```lean
lemma standardSl2ModuleLieModule [CharZero K] (t : IsSl2Triple h e f) :
```

**`PhyslibAlpha.Sl2.isSl2Triple_sub`**, a lemma, [line 192](https://github.com/leanprover-community/physlib/blob/2a1dfe43134b49b643642f13d33031754021bb5d/PhyslibAlpha/Mathematics/RepresentationTheory/Sl2/Basic.lean#L192).

> `hSub t`, `eSub t`, `fSub t` themselves form an `IsSl2Triple` within the subalgebra
> `↥(t.toLieSubalgebra K)` (as opposed to `t` itself, whose `h, e, f` live in the ambient `L`).
> Useful for restricting sl2-representation-theory results (e.g.
> `IsSl2Triple.exists_hasPrimitiveVectorWith`) to a submodule that is invariant under the
> subalgebra generated by `t` but not necessarily under all of `L`.

```lean
lemma isSl2Triple_sub (t : IsSl2Triple h e f) :
    IsSl2Triple (hSub (K := K) t) (eSub (K := K) t) (fSub (K := K) t)
```
