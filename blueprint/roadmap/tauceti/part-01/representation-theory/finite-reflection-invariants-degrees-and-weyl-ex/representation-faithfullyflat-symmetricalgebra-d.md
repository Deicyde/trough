# Representation.faithfullyFlat_symmetricAlgebra_dual_of_finrank_quotient_eq_one

Polynomial functions on a vector space are faithfully flat over their invariants when the
group is generated by elements with codimension-one fixed spaces and its order is invertible
in the field. No assumption of finite-dimensionality or faithfulness of the action is needed.

```lean
Representation.faithfullyFlat_symmetricAlgebra_dual_of_finrank_quotient_eq_one.{u_1, u_2, u_3, u_4}
  {G : Type u_1} [Group G] [Fintype G] {K : Type u_2} {V : Type u_3} [Field K] [AddCommGroup V]
  [_root_.Module K V] (ρ : Representation K G V) [Invertible ↑(Fintype.card G)] {ι : Type u_4}
  {s : ι → G} (hs : Subgroup.closure (Set.range s) = ⊤)
  (hcodim : ∀ (i : ι), Module.finrank K (V ⧸ (ρ (s i)).fixedSubmodule) = 1) :
  Module.FaithfullyFlat (↥ρ.dual.symmetricAlgebraInvariants) (SymmetricAlgebra K (Module.Dual K V))
```
