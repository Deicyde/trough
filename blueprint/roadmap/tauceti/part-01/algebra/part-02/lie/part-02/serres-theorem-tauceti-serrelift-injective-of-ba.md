# Serre's theorem (`TauCeti.serreLift_injective_of_base`)

Let `L` be a split semisimple Lie algebra, generated by a Serre system of
simple-root `sl₂` triples for a base of its root system. Then the surjection onto `L` from the Lie
algebra presented by Serre's relations for the transposed Cartan matrix of the base is
injective.

```lean
TauCeti.serreLift_injective_of_base.{u_1, u_2} {K : Type u_1} {L : Type u_2} [Field K] [CharZero K]
  [LieRing L] [LieAlgebra K L] [FiniteDimensional K L] [LieAlgebra.IsKilling K L]
  {H : LieSubalgebra K L} [H.IsCartanSubalgebra] [LieModule.IsTriangularizable K (↥H) L]
  {b : (LieAlgebra.IsKilling.rootSystem H).Base} [DecidableEq ↥b.support] {e f : ↥b.support → L}
  (hS :
    TauCeti.IsSerreSystem K b.cartanMatrix.transpose
      (fun i => ↑((LieAlgebra.IsKilling.rootSystem H).coroot ↑i)) e f)
  (hspan : LieSubalgebra.lieSpan K L (Set.range e ∪ Set.range f) = ⊤) :
  Function.Injective ⇑(TauCeti.serreLift hS)
```
