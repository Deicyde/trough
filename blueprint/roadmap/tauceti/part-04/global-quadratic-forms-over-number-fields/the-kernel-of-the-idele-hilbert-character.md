# The kernel of the idele Hilbert character

Let `b ∈ Kˣ` be a nonsquare at some finite place
or negative at some real place, and let `L` be a number field over `K` in which `b` is a square.
Suppose that the idele-class norm group `N_{L/K}(C_L)` has index dividing two in `C_K`, as the norm
index theorem gives for `L = K(√b)`. Then the kernel of `φ_b` is `Kˣ · N_{L/K}(𝕀_L)`, the
subgroup of `𝕀_K` generated by the principal ideles and the idele norms.

```lean

  {K : Type u_1} [Field K] [NumberField K] {L : Type u_2} [Field L] [NumberField L] [Algebra K L]
  {b : Kˣ} (hb : IsSquare ((algebraMap K L) ↑b))
  (hidx : (TauCeti.GlobalNumberFields.ideleClassNormMap K L).range.index ∣ 2)
  (hns :
    (∃ v, ¬IsSquare (v.unitAtFinitePlace b)) ∨
      ∃ w, (NumberField.InfinitePlace.embedding_of_isReal ⋯) ↑b < 0) :
  NumberField.IdeleGroup.principalSubgroup (NumberField.RingOfIntegers K) K ⊔
      (TauCeti.GlobalNumberFields.ideleNormMap K L).range =
    (TauCeti.NumberField.QuadraticForm.ideleHilbertCharacter b).ker
```
