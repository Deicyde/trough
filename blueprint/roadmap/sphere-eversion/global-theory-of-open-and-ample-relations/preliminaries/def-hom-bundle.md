# hom_bundle

Let $E → B$ and $F → B$ be two vector bundles over some smooth manifold $B$. The bundle $\operatorname{Hom}(E, F) → B$ is the set of linear maps from $E_b$ to $F_b$ for some $b$ in $B$, with the obvious projection map.
