# ind₁ to coind₁

There is a morphism of representations $\mathrm{ind}_1(G,A) \to \mathrm{coind}_1(G,A)$, which takes a finitely supported function $f : G \to_0 A$ to the function $f$. If the group $G$ is finite then this map is an isomorphism. More precisely, this is an isomorphism of functors $\mathrm{ind}_1(G,-) \cong \mathrm{coind}_1(G,-)$.
