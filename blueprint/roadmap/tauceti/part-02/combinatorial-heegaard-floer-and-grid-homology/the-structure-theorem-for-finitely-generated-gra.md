# The structure theorem for finitely generated graded `k[X]`-modules

Let `X` lower degree
by `d ≠ 0` in a finitely generated graded `k[X]`-module `M` over a field. Then `M` is the internal
direct sum of cyclic submodules `k[X] ∙ t i` generated by homogeneous elements `t i`, indexed by
the disjoint union of two finite types: for `i` in the first, `t i` has zero annihilator, so
`k[X] ∙ t i` is a free `X`-tower; for `j` in the second, `t j` has annihilator `(X ^ m j)` with
`m j ≠ 0`, so `k[X] ∙ t j ≅ k[X] ⧸ (X ^ m j)`.

```lean
TauCeti.InternalGrading.exists_isInternal_span_singleton.{u, u_1} {k : Type u_1} {M : Type u}
  [Field k] [AddCommGroup M] [_root_.Module k M] [_root_.Module (Polynomial k) M]
  [IsScalarTower k (Polynomial k) M] {G : TauCeti.InternalGrading k M ℤ} {d : ℕ}
  [Module.Finite (Polynomial k) M] (hd : d ≠ 0)
  (hX : ∀ ⦃p : ℤ⦄ ⦃x : M⦄, x ∈ G.piece ℤ p → Polynomial.X • x ∈ G.piece ℤ (p - ↑d)) :
  ∃ ι κ,
    ∃ (_ : Finite ι) (_ : Finite κ),
      ∃ t deg m,
        (∀ (i : ι ⊕ κ), t i ∈ G.piece ℤ (deg i)) ∧
          (∀ (i : ι), Ideal.torsionOf (Polynomial k) M (t (Sum.inl i)) = ⊥) ∧
            (∀ (j : κ), m j ≠ 0) ∧
              (∀ (j : κ),
                  Ideal.torsionOf (Polynomial k) M (t (Sum.inr j)) =
                    Ideal.span {Polynomial.X ^ m j}) ∧
                DirectSum.IsInternal fun i => Polynomial k ∙ t i
```
