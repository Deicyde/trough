# Params.minimal

The tuple $(\mathbb N, {\lt _{\mathbb N}}, \aleph_1, \beth_{\omega_1})$ is a collection of model parameters, where the symbols $\aleph_1$ and $\beth_{\omega_1}$ represent particular types of that cardinality.
