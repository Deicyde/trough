# The congruence description of the narrow Picard group

A ray class of the narrow conductor
modulus maps to the trivial narrow Picard class exactly when it is the ray class of an ideal of
`𝓞 K` generated by a totally positive element of the order.

```lean
TauCeti.GlobalNumberFields.NumberFieldOrder.mem_ker_rayClassToNarrowPic.{u_1} {K : Type u_1}
  [Field K] [NumberField K] (O : TauCeti.GlobalNumberFields.NumberFieldOrder K)
  {c : TauCeti.GlobalNumberFields.RayClassGroup O.narrowConductorModulus} :
  c ∈ O.rayClassToNarrowPic.ker ↔
    ∃ J,
      (TauCeti.GlobalNumberFields.idealClass O.narrowConductorModulus) J = c ∧
        ∃ β ∈ O.toRingOfIntegers, NumberField.IsTotallyPositive ↑β ∧ ↑J = Ideal.span {β}
```
