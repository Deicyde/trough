# The converse of the Chevalley–Shephard–Todd theorem

Let a finite group `G` act faithfully
and linearly on a finite-dimensional vector space `V` over a field `K` of characteristic zero. If
the polynomial invariants `Sym(V*)^G` form a polynomial algebra on homogeneous invariants, then `G`
is generated by its pseudoreflections, the elements whose fixed space is a hyperplane.

```lean
Representation.pseudoreflectionSubgroup_eq_top_of_bijective_aeval_symmetricAlgebraInvariants_dual.{u_1,
    u_2, u_3, u_4}
  {K : Type u_1} {G : Type u_2} {V : Type u_3} [Field K] [CharZero K] [Group G] [Finite G]
  [AddCommGroup V] [_root_.Module K V] [FiniteDimensional K V] (ρ : Representation K G V)
  (hρ : Function.Injective ⇑ρ) {ι : Type u_4} [Finite ι]
  {f : ι → ↥ρ.dual.symmetricAlgebraInvariants} {d : ι → ℕ}
  (hf : ∀ (i : ι), ↑(f i) ∈ TauCeti.SymmetricAlgebra.homogeneousSubmodule K (Module.Dual K V) (d i))
  (hbij : Function.Bijective ⇑(MvPolynomial.aeval f)) : ρ.pseudoreflectionSubgroup = ⊤
```
