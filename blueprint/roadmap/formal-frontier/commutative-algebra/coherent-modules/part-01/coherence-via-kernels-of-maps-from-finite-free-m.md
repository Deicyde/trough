# Coherence via kernels of maps from finite free modules

For any unital, possibly noncommutative ring R and any left R-module M, M is coherent (finitely generated with every finitely generated submodule finitely presented) if and only if M is finitely generated and the kernel of every R-linear map Rⁿ → M is finitely generated for every natural number n, including zero.
