## `Green92.green_92`

Open: stated without proof.

> I have a string $x \in \{0,1\}^n$. Let $\tilde{x}$ be the random string obtained by deleting bits
> from $x$ independently at random with probability $\frac{1}{2}$ (thus, for example, if $n = 8$ and
> $x = 00110110$, it might be the case that $\tilde{x} = 0111$, generated by deleting bits
> $2, 3, 5, 8$.) An instance of $\tilde{x}$ is called a 'trace'. How many independent traces
> $\tilde{x}_1, \dots, \tilde{x}_m$ are needed before one can reconstruct $x$ with probability $0.9$?
>
> This is the trace reconstruction problem. `numTraces n` is the least $m$ for which some decoder
> succeeds with probability at least $0.9$ for every $x$. Replacing $0.9$ by another constant in
> $(1/2, 1)$ changes $m$ by at most a constant factor (repeat and take a majority vote), so we ask
> for `numTraces n` up to constant factors.

```lean
theorem green_92 : (fun n ↦ (numTraces n : ℝ)) =Θ[atTop] green_92.answer
```

## `Green92.green_92.variants.chase_upper`

Solved: stated here without proof.

> **Chase's upper bound.** For every deletion probability $q \in (0, 1)$ and every $\delta > 0$
> there is $C > 0$ such that every $x \in \{0,1\}^n$ can be reconstructed with probability at least
> $1 - \delta$ from $\exp(C n^{1/5} \log^5 n)$ independent traces of $x$ [Ch20, Theorem 1]. We
> state it for $q = 1/2$ and $\delta = 1/10$, with the number of traces rounded up, for large $n$.
> It improves the bound $\exp(C n^{1/3})$ of [NP17] and [DOS19].

```lean
theorem green_92.variants.chase_upper :
    ∃ C : ℝ, 0 < C ∧ ∀ᶠ n : ℕ in atTop,
      numTraces n ≤ ⌈Real.exp (C * (n : ℝ) ^ (1 / 5 : ℝ) * Real.log n ^ 5)⌉₊
```

## `Green92.green_92.variants.chase_lower`

Solved: stated here without proof.

> **Chase's lower bound.** For every deletion probability $q \in (0, 1)$ and every
> $\delta \in (0, 1)$ there is $c > 0$ such that at least $c n^{3/2} / \log^7 n$ traces are required
> to distinguish between $x_n = (01)^k 1 (01)^{k+1}$ and $y_n = (01)^{k+1} 1 (01)^k$ with
> probability at least $1 - \delta$, where $n = 4k + 3$ [Ch21, Theorem 1]. A decoder that recovers
> every string distinguishes these two. We state it for $q = 1/2$ and $\delta = 1/10$, for large
> $n \equiv 3 \pmod 4$. [Gr24] quotes the bound $n^{3/2} (\log n)^{-16}$ of the first arXiv
> version of [Ch21]; the published version has $(\log n)^{-7}$.

```lean
theorem green_92.variants.chase_lower :
    ∃ c : ℝ, 0 < c ∧ ∀ᶠ n : ℕ in atTop, n % 4 = 3 →
      c * (n : ℝ) ^ (3 / 2 : ℝ) / Real.log n ^ 7 ≤ numTraces n
```
