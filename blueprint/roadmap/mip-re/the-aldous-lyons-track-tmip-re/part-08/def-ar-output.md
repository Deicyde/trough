# The output verifier of the answer reduction

For a parameter routine, an input tailored verifier and $(\lambda, \mu, \sigma)$, the *output verifier* has the answer-reduced sampler, the answer-length calculator of Lemma [The answer-length calculator](../part-07/lem-ar-len.md) and the linear-constraints processor of Definition [The linear-constraints processor of the answer-reduced verifier](def-ar-lp.md).
