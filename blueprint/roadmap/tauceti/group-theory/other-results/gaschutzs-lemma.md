# Gaschütz's lemma

Let `f : G →* H` be a surjective homomorphism from a finite group, and
let `G` be generated by an `ι`-tuple. Then every generating `ι`-tuple of `H` lifts along `f` to a
generating `ι`-tuple of `G`.

```lean
MonoidHom.exists_comp_eq_and_closure_range_eq_top_of_surjective.{u_1, u_2, u_3} {G : Type u_1}
  {H : Type u_2} {ι : Type u_3} [Group G] [Group H] (f : G →* H) [Finite G] [Finite ι]
  (hf : Function.Surjective ⇑f) {g : ι → G} (hg : Subgroup.closure (Set.range g) = ⊤) {h : ι → H}
  (hh : Subgroup.closure (Set.range h) = ⊤) :
  ∃ g', ⇑f ∘ g' = h ∧ Subgroup.closure (Set.range g') = ⊤
```
