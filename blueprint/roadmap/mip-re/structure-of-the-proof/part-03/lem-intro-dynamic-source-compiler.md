# Uniform executable cross-introspection compiler

The pair and triple parsers now take binary $Q,R$ as inputs; requested slices are capped by the actual input length before unary scanning. A closed program computes the canonical bounds from binary $(\lambda,n)$, queries the source sampler's dimension at $2^n$, checks the outer and inner answer cuts and exact zero padding, projects both questions to the source dimension, and runs the source decider at $2^n$. Both source calls are clocked. The program halts on every raw input even for arbitrary source program texts. For a bounded source and $n\geq1$, its acceptance is exactly the guard conjunction with original source acceptance on the projected questions. The actual compiler has polynomial compilation time and description length in both source sizes and binary $\lambda$. A composed execution bound includes all parameter, query, parsing and simulation costs. Parameter admissibility, absorption of this bound into one universal introspection budget, and the other typed-test branches remain separate obligations.

## Proof

Compute bounded slices with binary counters and check exact re-encoding. The canonical arithmetic programs generate the actual register and answer bounds. A clocked ordinary sampler query supplies the dimension; boundedness proves that this query fits the exponent-five clock. The guard proves exact source-question lengths and zero-tail membership before the source call. Compose the routing and clocked simulation programs, use determinism for acceptance equivalence, and compose their cost bounds. The AST constructors and specialization compiler establish the binary description bound.
