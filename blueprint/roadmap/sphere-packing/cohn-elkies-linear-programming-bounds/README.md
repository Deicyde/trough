# Cohn-Elkies linear programming bounds

In 2003 Cohn and Elkies (2) developed linear programming bounds that apply directly to sphere packings. The goal of this section is to formalize the Cohn–Elkies linear programming bound.

The following theorem is the key result of (2). (Note that the original theorem is stated for a class of functions more general then Schwartz functions.)
