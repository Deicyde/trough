# SpherePacking

Note that a sphere packing is uniquely determined by a given set of centres (provided it comes with an appropriate separation radius). Therefore, in this blueprint, we define everything that depends on sphere packings in terms of `SpherePacking`, a `structure` that bundles all the identifying information of a packing, but not the actual balls themselves. For the purposes of this blueprint, however, we will refrain from making this distinction.
