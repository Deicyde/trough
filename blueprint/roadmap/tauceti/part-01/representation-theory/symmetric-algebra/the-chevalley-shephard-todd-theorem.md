# The Chevalley–Shephard–Todd theorem

Let a finite group `G`, whose order is invertible in
the field `K`, act linearly on a finite-dimensional vector space `V`, and suppose that `G` is
generated by pseudoreflections, the elements whose fixed space is a hyperplane. Then the
polynomial invariants `Sym(V*)^G` form a polynomial algebra on `dim V` homogeneous invariants
`f₁, …, fₙ` of positive degree: `K[X₁, …, Xₙ] → Sym(V*)^G`, `Xᵢ ↦ fᵢ`, is an isomorphism.

```lean
Representation.exists_bijective_aeval_symmetricAlgebraInvariants_dual_of_pseudoreflectionSubgroup_eq_top.{u_1,
    u_2, u_3}
  {K : Type u_1} {G : Type u_2} {V : Type u_3} [Field K] [Group G] [Fintype G] [AddCommGroup V]
  [_root_.Module K V] [FiniteDimensional K V] (ρ : Representation K G V)
  [Invertible ↑(Fintype.card G)] (hG : ρ.pseudoreflectionSubgroup = ⊤) :
  ∃ f,
    (∀ (i : Fin (Module.finrank K V)),
        ∃ d, 0 < d ∧ ↑(f i) ∈ TauCeti.SymmetricAlgebra.homogeneousSubmodule K (Module.Dual K V) d) ∧
      Function.Bijective ⇑(MvPolynomial.aeval f)
```
