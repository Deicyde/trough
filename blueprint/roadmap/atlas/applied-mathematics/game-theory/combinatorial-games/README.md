# Combinatorial game theory

466 results of ATLAS's vault, 236 proved and 230 stated but not proved, in this branch's topics.

Combinatorial game theory studies two-player games of perfect information without chance: impartial games such as Nim and its variants (P-positions, Sprague–Grundy values, remoteness), partizan games such as Snort, and Maker–Breaker positional games.
