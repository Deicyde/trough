# base support

A *base support* is a pair $S = (S^{\mathcal A}, S^{\mathcal N})$ where $S^{\mathcal A}$ is an enumeration of atoms and $S^{\mathcal N}$ is an enumeration of near-litters. There are precisely $\#\mu$ base supports.
